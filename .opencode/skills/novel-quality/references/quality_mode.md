# 模式 C：质量检测需求分析（quality）

**适用阶段**：P9（质量检测）

## 分析维度

| 维度 | 说明 | 示例值 |
|------|------|--------|
| 检查类型 | 需要进行的检查 | AI味道/一致性/节奏/逻辑/世界观 |
| 检查深度 | 检测详细程度 | 快速检查/完整评估/专项优化 |
| 读者定位 | 目标读者画像 | 老白/小白/考据党/情感党/剧情党 |
| 优先级设置 | 问题严重性分级 | 致命/重要/轻微 |
| 检查范围 | 检测覆盖范围 | 单章/多章/全本 |

## 执行流程

```
阶段一：需求解析
  解析检查类型 → 识别检查维度 → 确定读者定位

阶段二：参数设置
  设定检查深度 → 设置优先级 → 界定检查范围

阶段三：需求输出
  生成需求报告（YAML）→ 传递给下游协调器
```

## 产出格式

```yaml
质量检测需求报告:
  检查类型:
    - AI味道检测
    - 一致性检查
    - 节奏分析
    - 文风增强
    - 读者反馈模拟
  检查深度: [快速检查/完整评估/专项优化]
  读者类型: [玄幻迷/言情粉/悬疑爱好者/严肃读者/休闲读者]
  优先级设置:
    高优先级: [角色不一致, 情节逻辑空隙, 旁白叙述]
    中优先级: [情感空洞, 缺乏细节, 重复套路]
    低优先级: [风格过于正式]
  检查范围: [章节范围/全本]
  输出格式: [YAML报告/修复建议/优化文本]
  预期成果: [质量评分/问题清单/优化建议]
```
