# AI味道检测规则库（增强版）

本文件定义了AI生成文本的典型特征模式，供文笔优化时使用。
是从 novel-quality-review
  references 中移植并扩展的增强版本。

---

## 概览

AI生成的文本有8种典型特征，优化时应逐项对照检查并修复：

| 类型 | 严重程度 | 核心关键词 | 优化优先级 |
|------|---------|-----------|-----------|
| 情感空洞 | 中等 | 非常、十分、特别、很 | 2 |
| 角色不一致 | 高 | 突然、竟然、反常 | 1 |
| 情节逻辑空隙 | 高 | 刚好、恰巧、就在这时 | 1 |
| 风格过于正式 | 低 | 由此可见、综上所述 | 3 |
| 重复套路 | 中等 | 地说、地想、地看 | 2 |
| 缺乏具体细节 | 中等 | 东西、物品、地方 | 2 |
| 旁白叙述 | 高 | 感到、觉得、意识到 | 1 |
| 通用描述 | 中等 | 美丽的、英俊的 | 2 |

---

## 类型1：情感空洞

### 检测关键词
`非常`、`十分`、`特别`、`很`、`实在`、`极其`、`相当`、`太过`

### 问题描述
情感描述抽象空洞，缺乏具体感官细节。读者无法产生共鸣，只能"知道"而不能"感受到"。

### 修复原则
将抽象情感词替换为具体感官体验，让读者"看到"和"感受到"。

### 修复方法

| 原表达 | 优化后 | 感官通道 |
|--------|--------|---------|
| 非常生气 | 手指捏得发白，嘴唇紧抿成一条线 | 视觉+触觉 |
| 特别生气 | 额头青筋暴起，胸口剧烈起伏 | 视觉 |
| 十分伤心 | 眼眶发红，声音哽咽，肩膀微微颤抖 | 视觉+听觉 |
| 很伤心 | 低下头，泪水无声滑落 | 视觉 |
| 非常开心 | 嘴角上扬，眼睛弯成月牙，脚步轻快 | 视觉+动觉 |
| 特别开心 | 欢呼雀跃，像个孩子一样蹦跳 | 动觉 |
| 极其恐惧 | 手心渗出冷汗，不自觉后退一步 | 触觉+动觉 |
| 相当害怕 | 声音发颤，双腿像灌了铅 | 听觉+动觉 |
| 非常着急 | 来回踱步，拳头攥紧又松开 | 动觉 |
| 特别紧张 | 咽了口唾沫，喉咙发干 | 触觉 |
| 相当疲惫 | 靠在墙上，半天缓不过劲来 | 动觉 |
| 极其失望 | 沉默良久，起身离开，脚步沉重 | 动觉 |
| 非常感动 | 鼻子一酸，眼眶发热 | 触觉 |
| 很无奈 | 叹了口气，摇了摇头 | 听觉+动觉 |

## 类型2：角色不一致

### 检测关键词
`突然`、`竟然`、`反常`、`一反常态`、`不知为何`、`莫名其妙`、`居然`

### 问题描述
角色行为不符合设定性格或缺乏动机，转变过于突兀。读者会感到"这个角色不会这样做"。

### 修复原则
添加行为背后的心理动机，让角色转变有迹可循。

### 修复方法

| 原表达 | 优化后 | 心理动机 |
|--------|--------|----------|
| 他突然决定了 | 他犹豫片刻，想起过去的承诺，终于下定决心 | 记忆触发 |
| 她竟然哭了 | 她再也忍不住，泪水夺眶而出 | 情感累积 |
| 他一反常态 | 他沉默了片刻，往日的骄傲全卸了下来 | 内心挣扎 |
| 不知为何 | 他想起三年前的那件事，心里隐隐作痛 | 记忆关联 |
| 莫名其妙 | 似乎是触动了某根看不见的弦 | 潜意识 |
| 竟然同意 | 过了良久，他叹了口气，终于点头 | 无奈接受 |
| 突然大笑 | 他愣了愣，随即笑得苦涩："有意思。" | 讽刺反应 |
| 突然哭泣 | 眼眶一红，她慌忙转身，不想让他看见 | 隐藏情感 |
| 突然沉默 | 话到嘴边，又被咽了回去 | 犹豫 |

## 类型3：情节逻辑空隙

### 检测关键词
`就在这时`、`刚好`、`恰巧`、`忽然`、`瞬间`、`转眼间`、`突然`

### 问题描述
情节发展依赖巧合，缺乏合理铺垫，因果链断裂。读者会感到"凭什么？"。

### 修复原则
添加因果关联或伏笔，使情节发展自然合理。

### 修复方法

| 原表达 | 优化后 | 因果关联 |
|--------|--------|----------|
| 刚好路过 | 想起昨天的约定，他特意绕路经过 | 意图驱动 |
| 恰巧遇见 | 处理完事情，他习惯性地走向那条街 | 习惯/日程 |
| 就在这时 | 话音未落，门外传来脚步声 | 时间线接续 |
| 忽然出现 | 按照计划好的时间，他推门而入 | 计划驱动 |
| 瞬间消失 | 他迅速闪身，消失在巷口 | 训练有素 |
| 转眼间 | 几个呼吸间，局面已经完全改变 | 节奏描写 |
| 突然有人来 | 敲门声响起，三长一短，是他约定的信号 | 信号识别 |
| 恰好赶上 | 最后一秒，他抓住了缰绳 | 目标驱动 |
| 正好听见 | 风把话吹进耳朵，他停住了脚步 | 环境辅助 |

## 类型4：风格过于正式

### 检测关键词
`由此可见`、`综上所述`、`换言之`、`概言之`、`易言之`、`本质上`

### 问题描述
文风过于正式或学术化，不符合小说语境。像是论文而非小说。

### 修复原则
转换为自然叙述语调，适应小说文体。

### 修复方法

| 原表达 | 优化后 | 语体转换 |
|--------|--------|----------|
| 由此可见 | 这样看来 | 学术→口语 |
| 综上所述 | 总而言之 | 学术→口语 |
| 换言之 | 也就是说 | 学术→口语 |
| 概言之 | 说白了 | 学术→口语 |
| 易言之 | 说白了就是 | 学术→口语 |
| 总的来说 | 总的来看 | 正式→日常 |
| 从这个角度 | 说起来 | 正式→日常 |
| 基于以上 | 这么一来 | 正式→日常 |
| 事实上 | 说实在的 | 正式→日常 |
| 客观来说 | 按道理讲 | 正式→日常 |

## 类型5：重复套路

### 检测关键词
`地说`、`地想`、`地看`、`地走`、`地笑`（过度使用"地"结构）

### 额外模式
- "X道："（他说道）
- "X说："（她说）
- "X问："（他问）
- 连续3次以上的相同句式开头

### 问题描述
句式结构重复，缺乏变化，语言单调。读起来像是流水线产品。

### 修复原则
变换句式结构，增加语言多样性。

### 修复方法

| 原表达 | 优化后 | 变化方式 |
|--------|--------|----------|
| 他慢慢地说 | 他放缓语速，一字一句道 | 动作替代 |
| 她轻轻地笑 | 她唇角微扬 | 动作替代 |
| 他高兴地说 | 他眉眼带笑 | 神态替代 |
| 伤心地想 | 心里像压了块石头 | 比喻替代 |
| 快速地跑 | 他拔腿就跑 | 口语化 |
| 仔细地看 | 他眯起眼睛，打量着 | 动作分解 |
| 默默地走 | 他一声不坑地走着 | 状态描写 |
| 缓缓地点头 | 他沉思片刻，缓缓颔首 | 细节丰富 |
| 他说："... | "...。"他开口 | 句式变化 |
| 她问："... | "...？"她的声音 | 问号在句内 |
| 他道："... | 他："... | 简化提示词 |

## 类型6：缺乏具体细节

### 检测关键词
`东西`、`物品`、`地方`、`时候`、`事情`、`人`、`那些`

### 问题描述
使用模糊词汇，缺乏具体指代，读者无法形成清晰画面。好像在雾里看花。

### 修复原则
将模糊词汇具体化，提供清晰意象。

### 修复方法（按场景分类）

**室内场景**:
| 原表达 | 优化后 |
|--------|--------|
| 拿起东西 | 抓起桌上的青铜匕首 |
| 拿着物品 | 握紧那封泛黄的信 |
| 看着东西 | 盯着那面斑驳的铜镜 |
| 放下东西 | 把褪色的绣囊放在桌上 |

**室外场景**:
| 原表达 | 优化后 |
|--------|--------|
| 去了地方 | 穿过东市场的石板路 |
| 那个地方 | 那座废弃的祠堂 |
| 来到地方 | 在城西的破庙前停下 |
| 找个地方 | 躲进巷子里的阁楼里 |

**时间描述**:
| 原表达 | 优化后 |
|--------|--------|
| 这个时候 | 暮色四合时分 |
| 那天 | 冬至后的第三个傍晚 |
| 过了一会儿 | 两炷香的时间 |
| 早上 | 天蒙蒙亮的时候 |
| 晚上 | 入夜后，城里上更 |

**事件描述**:
| 原表达 | 优化后 |
|--------|--------|
| 事情 | 三日前的那场赌约 |
| 那件事 | 让他们反目成仇的真相 |
| 买东西 | 购置了一批粮草和药物 |
| 处理事情 | 办妥了城里的那批货 |
| 重要的事 | 关系到全家性命的密信 |

**人物描述**:
| 原表达 | 优化后 |
|--------|--------|
| 有些人 | 穿灰衣的家丁 |
| 那个人 | 脸上有刀疤的镖师 |
| 这个 人 | 当年救过他的老丈 |
| 来了人 | 官差打扮的两个人 |

## 类型7：旁白叙述（Tell not Show）

### 检测关键词
`感到`、`觉得`、`意识到`、`注意到`、`发现`、`知道`、`理解`

### 问题描述
通过旁白直接告诉读者情感，而不是通过行为展现。剥夺了读者"体会"的权利。

### 修复原则
通过动作、神态、环境变化展现情感，让读者自己体会。

### 修复方法

| 原表达 | 优化后 | 展现方式 |
|--------|--------|----------|
| 他感到恐惧 | 他后退一步，手心渗出冷汗 | 动作+触觉 |
| 她觉得难过 | 她低下头，嘴唇微微颤抖 | 动作 |
| 他意识到危险 | 他瞳孔微缩，立即闪身 | 反应动作 |
| 她注意到 | 她的目光在人群中搜寻 | 动作 |
| 他发现 | 他的话说到一半，戛然而止 | 中断动作 |
| 感到惊讶 | 微微挑眉，眼中闪过一丝意外 | 神态 |
| 觉得开心 | 方才的阴霾一扫而空 | 环境描写 |
| 感到失望 | 他沉默了片刻，起身离开 | 动作 |
| 感到寒冷 | 她缩了缩脖子，呼出的气变成了白雾 | 感官细节 |
| 觉得恶心 | 胃里一阵翻涌，她别过头去 | 生理反应 |
| 感到疲惫 | 他揉了揉眉心，重量全压在椅子上 | 动作+状态 |
| 觉得害怕 | 他咽了口唾沫，不着痕迹地后退 | 动作 |

## 类型8：通用描述

### 检测关键词
`美丽的`、`英俊的`、`可怕的`、`恐怖的`、`惊奇的`、`可爱的`
`很好的`、`很坏的`、`很特别的`

### 问题描述
使用通用形容词，缺乏独特细节，人物形象扁平。好像网红脸，没有辨识度。

### 修复原则
提供独特视角和细节，让描述更有辨识度。

### 修复方法（按对象分类）

**人物外貌**:
| 原表达 | 优化后 | 辨识特点 |
|--------|--------|----------|
| 美丽的女孩 | 眼角的泪痣让她平添几分倔强 | 细节特征 |
| 英俊的小伙 | 眉宇间透着英气，身姿挺拔 | 整体气质 |
| 可怕的眼神 | 目光如刀，仿佛能穿透人心 | 感受描写 |
| 可爱的笑容 | 两个酒窝，笑起来像月牙 | 具体化 |
| 美丽的眼睛 | 眸若秋水，眼角微微上挑 | 细节描写 |

**场景描写**:
| 原表达 | 优化后 | 感官描写 |
|--------|--------|----------|
| 恐怖的气氛 | 空气凝固，寒意从脊背升起 | 身体反应 |
| 美丽的风景 | 落日把湖面染成了金色 | 视觉 |
| 恐怖的声音 | 指甲划过玻璃般的刺耳 | 听觉 |
| 难闻的味道 | 腐肉混着血腥，直冲脑门 | 嗅觉+反应 |
| 好吃的东西 | 酥脆的外皮，入口即化 | 味觉 |

**情绪反应**:
| 原表达 | 优化后 | 展现方式 |
|--------|--------|----------|
| 惊奇地发现 | 微微挑眉，露出玩味的笑 | 表情 |
| 善良的人 | 宁可自己吃亏，也不愿亏欠他人 | 行为 |
| 聪明的办法 | 灵机一动，计上心头 | 过程 |
| 巨大的变化 | 整个人瘦了一圈，眼窝深陷 | 具体 |
| 恐怖的力量 | 单手就能举起石磨 | 对比 |

## 修复优先级指引

当需要对整篇文本进行优化时，建议按以下优先级处理：

### 第一优先级（高）
影响阅读体验和故事可信度：
1. **角色不一致** - 角色行为要有内在逻辑
2. **情节逻辑空隙** - 事件要有因果关联
3. **旁白叙述** - 避免直接告诉读者怎么想

### 第二优先级（中）
影响文笔质量和阅读沉浸感：
4. **情感空洞** - 让情感可感知
5. **缺乏细节** - 让场景清晰
6. **重复套路** - 让句式多样
7. **通用描述** - 让人物景物辨识度高

### 第三优先级（低）
影响整体风格统一性：
8. **风格过于正式** - 调整语体

## 快速检查清单

优化时可以用以下快速检查项：

- [ ] 没有连续3个以上"地说/地说"
- [ ] 没有连续3个以上"X道："
- [ ] 没有出现"非常/十分/特别/很+形容词"模式
- [ ] 没有出现"感到/觉得/意识到"
- [ ] 没有"东西/物品/地方/事情"单独出现
- [ ] 没有"美丽/英俊/可怕"等通用词单独修饰
- [ ] 没有"突然/刚好/恰巧/就在这时"
- [ ] 没有"由此可见/综上所述"
