# 焦点类型：note — 总纲/叙事策略/灵感记录指南

## 适用任务

| 子类型 | 标签 | 描述 |
|--------|------|------|
| 总纲/故事框架 | tag:总纲 | 故事全局骨架设计 |
| 叙事策略 | tag:叙事策略 | 视角/信息分配/笔法设计 |
| 灵感记录 | (无特殊标签) | 创作过程中的意外发现 |

---

## 总纲设计（tag:总纲）

总纲写入 note 类型的叙事单元，content 为结构化 JSON。

**核心字段：**

1. **基本信息**：项目名称、类型、目标字数、预计章节数、目标读者、故事时间范围、时间体系
2. **核心概念**：一句话概述(≤30字)、核心卖点、主题关键词、主题（核心/呈现）
3. **人物与世界的关系**：
   - 主角与世界的关系（生于此世/魂穿/重生等）
   - 主角的特殊性
   - 世界规则对主角的约束
   - 主角打破/利用规则的方式
   - 初始境况
4. **故事结构**：结构类型（三幕/五幕/自定义）+ 幕列表（幕号/名称/章节范围/主线/关键节点/主角状态）
5. **分卷概览**：每卷的卷号/卷名/章节范围/核心问题/主角转变
6. **节奏与结局**：前期/中期/后期基调、章节分布比例、结局类型（开放式/圆满/悲壮/反转）

## 叙事策略（tag:叙事策略）

叙事策略是总纲的组成部分，关注"怎么写"而非"写什么"。

**核心维度：**

1. **视角选择**：
   - 主视角类型（第一人称/第三人称限制/第三人称全知/客观视角）
   - 主视角锚定角色
   - 辅助视角（角色/功能/使用频率）
   - 切换规则（每章最多切换次数/切换方式/禁止行为）

2. **叙事手法**：
   - 主要手法（顺序/倒叙/插叙/多线并行）
   - 辅助手法（闪回/闪前）——使用场景/频率限制/标记方式
   - 禁忌手法

3. **信息分配**：
   - 戏剧反讽：是否启用/使用场景/限制
   - 悬疑管理：每卷主要悬念数量/解答周期/章节钩子
   - 误导策略：是否启用/使用场景/揭示方式/限制

4. **展示与讲述**：
   - 展示优先场景：情感高潮/动作场景/角色转变时刻/世界观首次展现
   - 讲述适用场景：背景交代/时间跳跃/过渡段落/次要情节概括
   - 比例建议：展示70/讲述30

5. **笔法控制**：
   - 冷笔场景：动作场景/紧张时刻/信息传递/章节开头
   - 热笔场景：情感高潮/内心独白/氛围营造/角色回忆
   - 切换规则：冷→热通过情感触发事件；热→冷通过动作/对话打断

## 灵感记录（无标签）

灵感是最轻量的 note 类型，只要求：
- 单元名称简明
- content 自由文本
- 用 tags 标记关联阶段（如 tag:伏笔 / tag:角色 / tag:情节）

灵感的价值在于"立即记录、之后处理"。不需要结构化。
