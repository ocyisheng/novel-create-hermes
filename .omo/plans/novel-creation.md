# 小说创作工作流计划

## 多项目协作须知

所有小说项目共用小说根目录下的 `.venv` 环境。
切换项目时 Agent 按 novel-writer.md §二 项目发现与选择 协议更新 `.omo/notepads/novel-context.md`。

```
小说根目录/
├── .venv/              ← 共享环境
├── 小说1/              ← 每个项目独立
├── 小说2/
├── 小说3/
└── ...
```

## 阶段检查清单

> 按 novel-writer.md 触发优先级排列。P-1 先于所有阶段执行。

### P-1：环境初始化

- [ ] Python 环境检测
- [ ] .venv 虚拟环境创建（小说根目录下）
- [ ] 依赖安装
- [ ] setup.py 验证

### P-2：项目管理

- [ ] 新建/导入/切换/续写/查看状态/删除
- [ ] config.yaml 生成
- [ ] 标准目录结构创建
- [ ] 多项目共存检查

### P-3：需求发现 — Grill（按需）

> 仅在 P1/P6/P8 用户需求模糊时触发，作为 task() 调度的前置步骤。使用 `skill()` 交互式追问，非 `task()`。

- [ ] 识别目标阶段（P1 创意 / P6 角色 / P8 章节）
- [ ] 加载已有上下文（创意方案 / 总纲 / 分纲 / 角色）
- [ ] 多轮追问收敛需求
- [ ] 输出需求 YAML 到 `quality/grill/`
- [ ] 注入对应 P 阶段的 task() prompt

### P1：创意构思

- [ ] 需求分析完成（mode=ideation）
- [ ] 约束应用
- [ ] 类型分析（如需要）
- [ ] 模板生成
- [ ] 创意发散（3-5 个方向）
- [ ] 创意评估
- [ ] 整合输出创意方案 YAML

### P2：总纲撰写

- [ ] 故事结构规划（三幕/五幕结构类型选取）
- [ ] 总纲撰写 → `outline/总纲.yaml`（幕列表、分卷概览、节奏说明）

### P3：分卷大纲生成

- [ ] 各卷大纲生成 → `outline/分卷/卷{N}_{名称}.yaml`（每卷 N 个文件）
- [ ] 每卷内容填充：核心冲突 / 叙事任务 / 微弧分割 / POV 分布
- [ ] 每卷内容填充：主角状态变化 / 关键事件清单 / 角色发展
- [ ] 每卷间奏章节、本卷节奏、卷末钩子
- [ ] 各实体运行 `rebuild_project_index.py` 索引

### P4：主/支线情节构建

- [ ] 主线设计 → `outline/情节线/主线.yaml`
- [ ] 支线穿插 → `outline/情节线/支线_{名称}.yaml`

### P5：世界观建设（按 worldview.yaml 模板）

- [ ] 基本信息 / 核心规则
- [ ] 力量体系 / 势力格局
- [ ] 地理位置 / 历史 / 文化
- [ ] 各实体写入 `worldbuilding/` 目录

### P6：角色创建（按 character.yaml 模板）

- [ ] 主角档案（基本信息 / 性格 / 背景 / 目标 / 能力 / 关系 / 弧线）
- [ ] 重要配角档案
- [ ] 各角色写入 `characters/` 目录

### P7：分纲构建

- [ ] 分纲撰写 → `outline/分纲/卷{卷号}/第{N}章.yaml`
- [ ] 各实体运行 `rebuild_project_index.py` 索引

### P8：章节写作

- [ ] 分纲读取
- [ ] 角色档案读取
- [ ] 章节正文生成
- [ ] 元数据更新（auto_update.py）

### P9：质量检测

> 全章写作完成后自动触发。检测项目同 P1，附加修订调度。

- [ ] 检测项目同 P1（AI 味道 / 情节逻辑 / 角色一致性 / 世界观漏洞）
- [ ] 节奏分析（条件执行）
- [ ] 风格一致性检查（条件执行）
- [ ] 综合质量报告
- [ ] 根据报告调度 novel-chapter-editor 修订

### P10：风格提取

- [ ] 用户提供参考文本
- [ ] 7 维度风格分析 → write styles/{名称}.yaml
- [ ] style_manager.py validate → register → activate
- [ ] config.yaml active_style 已设置

### P11：格式化导出（按需）

> 用户要求导出章节正文（EPUB/PDF/HTML/TXT/DOCX）时触发。调度 novel-export。

- [ ] 解析导出格式和作者名
- [ ] 调用 `export.py` 脚本执行导出
- [ ] 确认脚本 exit code 为 0
- [ ] 报告输出路径


### P12：章节编辑（按需）

> 用户要求修改已有章节正文（文笔优化 / 反馈修订 / 内容修改）时触发。调度 novel-chapter-editor。

- [ ] 读取目标章节正文 + 对应分纲
- [ ] 读取出场角色档案（摘要优先）
- [ ] 读取 `last_100.py` 衔接上下文
- [ ] 明确修改范围（文笔 / 反馈 / 内容）
- [ ] 执行修改 → 写回 `chapters/第{N}章.txt`

### P13：实体编辑（按需）

> 用户要求修改已有 YAML 实体（角色档案 / 世界观设定）时触发。调度 novel-entity-editor。

- [ ] entity_schema.py detect 确认实体类型
- [ ] 读取当前实体文件全文
- [ ] 执行修改 → edit 写回
- [ ] 后处理：fix_yaml_indent → validate_consistency → rebuild_index
- [ ] entity_diff.py 展示变更摘要

### P14：意图澄清

> 用户输入不匹配任何已注册触发词时触发。

- [ ] 询问用户意图
- [ ] 引导到 P1-P10 或按需技能之一

---

> **说明**：P-1/P-2/P-3 由 Agent 通过 skill() 直接执行；P1-P14 创作阶段由 novel-writer.md 按触发词自动识别，Agent 通过 task() 调度对应技能。
