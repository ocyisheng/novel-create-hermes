# V2 叙事单元数据格式标准

## 统一结构

所有叙事单元的 `content` 字段遵循以下三层结构：

```json
{
  "标准创作字段": "...",    // schemas.py 定义的必填/可选字段
  "_display": {...},        // 展示层（自由格式，HTML 面板读取）
  "扩展字段": "..."         // 任何额外字段，不做限制
}
```

**原则**：
- 标准创作字段：写作时 LLM 填写，`schemas.py` 校验必填项
- `_display`：展示用，自由格式，HTML 面板根据值类型自动渲染
- 扩展字段：任何不在 schema 中的字段都可以存在，不会报错

### HTML 面板渲染

| `_display` 值类型 | 渲染方式 | 示例字段 |
|------------------|---------|---------|
| `string` < 50字 | 键值对标签 | 身份, 修为, 阵营 |
| `string` > 50字 | 文本块 | 描述 |
| `string[]` | 标签云 | 核心特质 |
| `{事件, 时间?}[]` | 时间线 | 关键事件 |
| `{目标, 关系}[]` | 关系列表 | 人物关系 |

## 四、世界观（WORLD_RULE）

### 标准 schema

```json
{
  "实体子类型": "location | faction | rule | power_system | world_overview | history | culture | ...",
  "二级类型": "大陆 | 宗门 | 家族 | 秘境 | 海域 | 组织 | ...",
  "核心设定": "天南大陆修仙界的核心区域...",
  "_display": {
    "类型": "地点 或 势力",
    "二级类型": "大陆",
    "描述": "天南大陆修仙界的核心区域..."
  }
}
```

**地点类 (location) 的二级分类**：
大陆、国家、城市、海域、秘境、地域、宗门驻地、沿海、内陆

**势力类 (faction) 的二级分类**：
宗门、家族、商行、组织、阵营、联盟、族群、群体

**规则类 (rule / power_system)**：无二级分类

## 五、笔记（NOTE）

### 标准 schema

```json
{
  "note_type": "总纲 | 叙事策略 | 灵感 | 笔记 | 纪年事件",
  "_display": {
    "类型": "总纲 / 纪年事件 / 伏笔规划 / 时间线",
    "事件": "韩致飞升灵界",
    "时间": "凡人历2047年",
    "备注": "韩致以化神期修为飞升..."
  }
}
```

**纪年事件**：tags 含 `["纪年事件"]`，`_display` 含事件/时间/备注，自动关联到相关角色

## 展示层值类型渲染对照表

| `_display` 值类型 | 判断条件 | 渲染方式 | 示例 |
|------------------|---------|---------|------|
| `string` 短文本 | `typeof val === 'string' && val.length < 50` | 键值对标签 | `身份: 韩门门主` |
| `string` 长文本 | `typeof val === 'string' && val.length >= 50` | 文本块 | `描述: 韩门少年...` |
| `string[]` | `Array.isArray(val) && typeof val[0] === 'string'` | 标签云 | `[隐忍, 坚韧]` |
| `{target, relation}[]` | `Array.isArray(val) && val[0]?.target` | 关系列表 | `韩松 (族叔)` |
| `{事件, 时间?}[]` | `Array.isArray(val) && (val[0]?.事件 \|\| val[0]?.event)` | 时间线 | `8岁 离家学医` |

## 筛选层级

```
全部
├── 角色         → CHARACTER_ARC
├── 场景         → SCENE
├── 情节线       → PLOT_THREAD
├── 世界观       → WORLD_RULE
│   ├── ↳ 地点   → WORLD_RULE + _display.类型=地点
│   └── ↳ 势力   → WORLD_RULE + _display.类型=势力
├── 笔记         → NOTE
└── 正文         → CHUNK
```

---

## 设计原则

1. **`_display` 是自由格式**——没有固定字段名，LLM 根据小说类型自动决定展示什么
2. **HTML 面板不关心字段名**——只根据值类型自动渲染，新字段自动适配
3. **标准 schema 只约束创作字段**——`_display` 无校验
4. **类型无关的内容自动适配**——仙侠小说显示"修为/功法"，都市小说显示"职业/社会关系"，无需改代码
