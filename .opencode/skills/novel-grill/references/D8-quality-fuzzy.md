# D8. 质量检测 — 模糊入口引导

根节点：你想重点看哪个方面？

用于 P9 质量检测前置需求发现。**仅当检测请求完全模糊时触发**（如"看看写得怎么样""帮我 review 一下"）。用户已明确指定检测类型（"检测 AI 味""检查角色一致性"）时跳过，直接执行对应检测。

本文件不是多级决策树，只是一个快速入口选择器。

```
└── 只有 1 个问题
    └── 你想重点看哪个方面？
        ├── AI味道 → 单路 AI 味道检测
        ├── 情节逻辑 → 单路情节逻辑检测
        ├── 角色一致性 → 单路角色一致性检查
        ├── 世界观漏洞 → 单路世界观漏洞检测
        ├── 全部检测 → 4-6 路并行完整质量检测
        └── 先全部扫一遍，再看问题多的 → 4-6 路并行 + 重点关注排名
```

**交互方式**：
- 展示为快速列表选择，不逐层追问
- 用户选择后立即执行对应 quality 检测
- 如果用户说"不知道选哪个" → 推荐默认"全部检测"
