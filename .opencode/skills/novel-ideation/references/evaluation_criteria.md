  4维度评估矩阵

> **本文档整合了以下内容**：评估阈值配置、评估使用场景、评估输出示例。

## 1. 原创性 (Originality, 0-5分)

**评估标准**: 概念的新颖程度和创造性
```
5分 - 前所未见的全新概念
4分 - 已有概念的显著创新组合
3分 - 基本概念的适度创新
2分 - 轻度调整的传统概念
1分 - 明显的套路化设定
0分 - 完全复制已有概念
```

## 2. 可行性 (Feasibility, 0-5分)

**评估标准**: 概念的可执行度和实现难度
```
5分 - 清晰且易于执行的概念
4分 - 思路清晰但有适度挑战
3分 - 概念尚可但实现较复杂
2分 - 概念模糊执行难度大
1分 - 概念混乱难以实现
0分 - 完全不可行的概念
```

## 3. 吸引力 (Attractiveness, 0-5分)

**评估标准**: 对目标读者的吸引程度
```
5分 - 一眼就有强烈阅读冲动
4分 - 有明确兴趣点吸引读者
3分 - 有兴趣但不够突出
2分 - 吸引力一般需要改进
1分 - 平淡无吸引力
0分 - 完全无吸引力
```

## 4. 独特性 (Uniqueness, 0-5分)

**评估标准**: 在当前市场上的差异化程度
```
5分 - 市场上独一无二的存在
4分 - 有显著区别于同类的特色
3分 - 有自身特点但不够突出
2分 - 同质化较严重
1分 - 高度同质化
0分 - 完全复制现有作品
```

## 评估阈值配置

### 三档阈值模式

| 模式 | 总分要求 | 原创性 | 吸引力 | 其他维度 |
|------|---------|--------|--------|----------|
| 严格模式 | ≥18/20 | ≥4 | ≥4 | ≥3 |
| 标准模式 | ≥16/20 | ≥4 | ≥4 | ≥2 |
| 宽松模式 | ≥12/20 | ≥3 | ≥3 | ≥1 |

### 类型调整建议

- **男性向玄幻**: 原创性阈值 ≥4
- **女性向都市**: 吸引力阈值 ≥4
- **硬核科幻**: 可行性阈值 ≥4
- **悬疑推理**: 原创性阈值 ≥4

### 通用规则

1. 原创性≥4分，避免常见套路
2. 吸引力≥4分，确保有读者市场
3. 可行性不能为0分
4. 独特性体现市场竞争优势

## 评估输出示例

### 批量评估报告（YAML）

```yaml
创意质量评估报告:
  评估时间: 2026-05-05 10:00
  创意总数: 6
  通过筛选: 3
  拒绝创意: 3

  通过的创意:
    创意A (ID: creative_001):
      评分: 原创性:4/5, 可行性:4/5, 吸引力:5/5, 独特性:4/5
      总分: 17/20
      状态: 推荐

  评估建议:
    - 推荐选择创意A进行深度开发
    - 创意B需要提高可行性
```

### 单创意深度评估

```yaml
创意深度评估报告:
  创意ID: creative_001
  创意概述: "在末法时代用科学方法重新解读并再造修仙体系"
  维度评分详情:
    原创性: 4/5 — "科学修仙概念有创新，但近年有类似作品"
    可行性: 4/5 — "科学方法可执行，但需要考虑科学严谨性"
    吸引力: 5/5 — "融合科学与玄学，对两类读者都有吸引力"
    独特性: 4/5 — "在科学修仙领域有自身特色"
  总体评估: "总分17/20，优秀创意，建议优先选择"
```

## 评估使用场景

### 场景1：批量筛选
对多个创意方向进行4维度评分，按总分排序，标记最佳选项。

### 场景2：深度评估
对单个创意进行深入分析，提供具体改进建议。

### 场景3：对比评估
对2-3个竞争性创意对比分析各维度优劣，给出推荐建议。
