# 模式 A：创意需求分析（ideation）

**适用阶段**：P2（无创意）

## 分析维度

| 维度 | 说明 | 示例值 |
|------|------|--------|
| 类型与融合 | 主类型 + 可选子类型 | 玄幻/仙侠融合 |
| 创作基调 | 故事氛围 | 黑暗深沉/轻松幽默/史诗宏大 |
| 主题方向 | 核心主题 | 成长/复仇/救赎/探索 |
| 核心元素 | 必须包含的创意要素 | 系统流/反套路/群像 |
| 排斥元素 | 绝对要避免的方向 | 后宫/重生/虐主 |
| 创新诉求 | 突破常规的程度 | 保守/适度/大胆 |

## 执行流程

```
1. 确认小说类型与融合方向
2. 确定创作基调
3. 明确主题方向
4. 收集核心创意要素
5. 了解排斥元素
6. 确定创新诉求程度
7. 生成创意需求简报
```

## 产出格式

```yaml
创意需求简报:
  类型与融合: [主类型 + 子类型/融合方向]
  创作基调: [基调类型]
  主题方向: [主题列表]
  核心元素: [创意要素列表]
  排斥元素: [禁忌方向列表]
  创新诉求: [保守/适度/大胆]
  创意约束: [与基调/主题/创新诉求一致的约束方向]
```
