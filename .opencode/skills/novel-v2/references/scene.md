# scene — 场景/章节写作方法论

## 结构由脚本保障

content JSON 的字段结构由 `schemas.py` 自动校验，创建时脚本会检查：
- 章节类型（推进/过渡/高潮/结局/转折/收尾）必填
- 结构规划（开篇/发展/转折/收尾）必填
- 场域规划、张力曲线等可选，但填写时会校验类型

你不必记忆字段清单——脚本会提示。

## 创作方法论（需 LLM 判断）

- **场域是写作的基本单位**。每章 3-5 个场域，每个场域是一个时间×地点×POV 切片
- **张力曲线不必完美抛物线**。推进章追求效率，间奏章允许散漫闲笔
- **前章衔接**从同一场景/情绪自然延续
- **角色自动性**：角色开始做你没想到的事时，区分"文势所逼"（好）与"粗暴干预"（差）
- **语言尸体**："暮色从四面八方袭来"是尸体，"光线从窗帘边缘挤进来"可能是观察
- **伏笔**不必全部兑现。支持精准/落空/误解/悬置四种回收
- **章尾钩子**不限于因果驱动——可以是一个意象的回落
