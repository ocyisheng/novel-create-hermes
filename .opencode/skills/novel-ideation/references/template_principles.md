# 工作原理

## 基于约束的模板化

```
输入: 创意概念 + 类型背景 + 约束条件
处理: 分析核心要素，匹配最佳模板结构
输出: 定制化的故事框架模板
```

## 智能匹配算法

1. **类型诊断**：识别故事类型，优先匹配类型专用模板
2. **结构适配**：根据篇幅和目标选择最适合的叙事结构
3. **元素融合**：将创意特色与传统模板有机结合
4. **节奏优化**：根据字数要求和读者预期调整节奏密度

## 定制化参数

- **目标字数**：调整模板详细程度和复杂度
- **类型偏向**：强化特定类型的经典元素和模式
- **风格偏好**：喜剧/悲剧/正剧风格指导
- **节奏要求**：快节奏/慢节奏/中等节奏建议
- **特殊需求**：指定的结构元素或排斥项
