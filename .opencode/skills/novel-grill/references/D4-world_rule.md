# D4. 世界观设定 — 需求发现树

根节点：你这个世界大概是什么样的？

用于 focus_type=world_rule（世界观设定/规则建设）前置需求发现。Grill 通过 novel-tool 自行查询已有世界观设定。

```
├── D4.0 已有背景锚定（有已有设定时自动展示摘要后进入 D4.1）
│   ├── 根据之前的设定，这个世界已经有：[世界观概述]
│   ├── 是在这个基础上细化，还是想调整方向？
│   └── （如无已有设定）→ 展开：
│       ├── 故事发生在一个什么样的世界？
│       │   （现实隐藏另一面/完全虚构异世界/未来星际/过去历史/其他）
│       └── 整体氛围是？
│           （光明热血/黑暗压抑/灰色博弈/幽默搞笑/史诗庄严）

├── D4.1 世界观规模
│   ├── 物理规模大概多大？
│   │   （一片大陆/多大陆多国/星际多星球/平行宇宙/箱庭/跟现实差不多）
│   └── 地图需要多详细？
│       （粗略几个地名/完整地理体系/想到哪写到哪）

├── D4.2 核心规则体系
│   ├── 力量体系是哪一类？
│   │   （等级晋升/血脉觉醒/科技装备/无超自然/混搭）
│   ├── 读者需要知道多少设定？
│   │   （完全量化/部分神秘感/读者和角色一起发现）
│   └── 力量有什么限制或代价？
│       （消耗体力/反噬风险/特定条件触发/无明确限制）

├── D4.3 势力与格局
│   ├── 主要势力有几个？
│   │   （两方对峙/多方博弈/一家独大/单一内部斗争）
│   ├── 关系基调是什么？
│   │   （公开战争/和平角力/表面和谐/互不干涉）
│   └── 主角与这些势力的关系？

├── D4.4 特殊偏好（可跳过）
│   ├── 有什么绝对不想出现的设定？
│   ├── 有什么一定要包含的设定？
│   └── 用一句话说，这个世界最特别的地方是什么？

└── D4.5 编辑与调整（当修改请求模糊时展开）
    ├── 当前设定内容是：[摘要]
    ├── 哪方面不对？（规则本身/等级划分/限制条件/势力关系）
    ├── [影响告知] 修改会影响已有章节和关联设定
    └── [执行] 先出方案 / 直接改
```

**交互规则**：
- D4.0 有已有设定时自动跳过
- D4.1 规模影响 D4.3 势力数量的默认推荐值
- D4.2 选"无超自然"时跳过规则后续追问
- 快速模式压缩为 D4.1 + D4.2 + D4.3 三问
