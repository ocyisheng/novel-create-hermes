# D8. 主题/母题/伏笔 — 需求发现树

根节点：你想通过这个故事表达什么？

用于 focus_type=thematic_motif（主题/母题/伏笔规划）前置需求发现。Grill 通过 novel-tool 自行查询已有设定和章节概览。

```
├── D8.0 已有主题锚定（展示已有主题设定）
│   ├── 当前已明确的主题方向：[摘要]
│   ├── 在这个基础上深化，还是加新的主题层？
│   └── （无已有设定）→ 展开以下分支：

├── D8.1 核心主题
│   ├── 这个故事最想表达的是什么？
│   │   （成长与代价/正义与代价/自由与束缚/爱与牺牲/权力与腐化/宿命与抗争/其他）
│   ├── 有多层主题吗？（表层主题/深层主题/个人理解）
│   └── 故事的整体道德底色是？
│       （理想主义/现实主义/灰色地带/黑色幽默）

├── D8.2 母题与象征
│   ├── 有没有想用的核心意象或象征物？
│   │   （比如"笼中鸟"象征束缚，"剑"象征传承）
│   ├── 这些母题在故事中如何呈现？
│   │   （反复出现的意象/角色的标志物/世界观的一部分）
│   └── 母题的使用强度？
│       （贯穿始终的象征/特定章节出现/点到为止让读者自己发现）

├── D8.3 象征呼应
│   ├── 有没有贯穿全文的象征或意象？
│   ├── 它们在故事中如何演变？
│   │   （初次出现→发展变化→转化升华→最终定格）
│   ├── 它们在什么时刻获得新的意义？
│   │   （角色关键抉择/情节重大转折/全书终局时刻）
│   └── 象征的显隐程度？
│       （反复强调让读者注意到/自然融入不易察觉/介于两者之间）

└── D8.4 编辑与调整（当修改请求模糊时展开）
    ├── 当前主题方向：[摘要]
    ├── 哪方面想调整？（核心主题/母意象/伏笔设计）
    └── 改动幅度？（微调/重新规划）
```

**交互规则**：
- D8.3 象征呼应需要基于已有章节概览，grill 自行搜索已有 chunk 信息
- 快速模式只问 D8.1 一个核心问题

## 与 plot_thread 的边界

- **plot_thread 的伏笔**：情节层面的因果伏笔——"这条线索什么时候设下、什么时候回收"，是情节设计的一部分
- **thematic_motif 的象征呼应**：主题层面的意象呼应——"这个意象在故事中如何演变、在什么节点获得新意义"，是母题设计的一部分
- 当用户的意图是"设计伏笔/埋伏笔"时，编排层应路由到 plot_thread；当意图是"设计象征/意象呼应"时，路由到 thematic_motif
