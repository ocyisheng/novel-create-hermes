# 输出格式示例

创意方向和深度开发的 YAML 格式示例。


## 创意方向格式

```yaml
创意方向:
  - 编号: 1
    一句话概述: "修仙版饥饿游戏，宗门选拔中的生存竞赛"
    核心冲突: "底层弟子对抗宗门高层的阴谋"
    主角设定: "林默，外门弟子（表面）/ 古魔传承者（真实）"
    亮点卖点: "将生存竞技与修仙结合，反转传统套路"
    适用约束: ["三幕结构", "系统副作用", "身份颠覆"]

  - 编号: 2
    一句话概述: "..."
    核心冲突: "..."
    主角设定: "..."
    亮点卖点: "..."
    适用约束: [...]
```

## 创意深度开发格式

```yaml
创意深度开发:
  世界观设定:
    核心规则: "灵气会衰退，每百年一次大衰退"
    地理版图: "九州大陆，九大势力割据"
    时代背景: "末法时代，上古大能陆续苏醒"
    势力格局: "正道联盟 vs 魔道复苏 vs 古魔传承"

  角色档案:
    主角:
      姓名: "林默"
      身份: "外门弟子（表面）/ 古魔传承者（真实）"
      目标: "在选拔中活下来并揭露阴谋"
      冲突: "使用古魔力量会被正道追杀，不用就会死"
    关键配角:
      - 角色1: "苏清雪，内门天才，实为上古大能转世"
      - 角色2: "王长老，选拔负责人，阴谋主使"

  情节大纲:
    序章: "宗门选拔开始，林默险些丧命"
    发展: "林默发现古魔传承，实力大增但被追杀"
    高潮: "选拔决赛，林默揭露阴谋，正魔大战爆发"
    结局: "林默选择第三条路，建立新秩序"

  主题方向:
    核心主题: "在绝境中寻找第三条路"
    情感基调: "压抑中带着希望，黑暗中闪烁光明"
    价值取向: "不盲从正邪二分，走自己的道"
```

---

## 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 编号 | 创意序号 | 是 |
| 一句话概述 | 15-30字核心概念 | 是 |
| 核心冲突 | 主要矛盾 | 是 |
| 主角设定 | 身份/特点/目标 | 是 |
| 亮点卖点 | 独特优势 | 是 |
| 适用约束 | 使用的约束编号 | 否 |
