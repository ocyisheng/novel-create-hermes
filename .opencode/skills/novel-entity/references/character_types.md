# 角色类型

| 类型 | 特征 |
|------|------|
| 主角 | 有明确目标和成长弧线 |
| 反派 | 有合理动机，非单纯邪恶 |
| 导师 | 帮助主角成长 |
| 盟友 | 支持主角 |
| 对手 | 与主角竞争 |
| 次要角色 | 丰富世界观 |

## 设计原则

### 1. 主角设计原则
- 有清晰的成长弧线
- 有明确的内心恐惧和深层动机
- 行为决定符合性格设定

### 2. 反派设计原则
- 有合理的动机（非单纯邪恶）
- 有自己的价值观和底线
- 与主角有实质冲突

### 3. 配角设计原则
- 有明确的功能定位
- 性格特点鲜明
- 与主角形成互补或对比

## 角色档案字段说明

### 核心字段

| 字段 | 说明 |
|------|------|
| 基本信息 | 姓名、性别、年龄、身份 |
| 外貌 | 身高、体型、特征、习惯动作 |
| 性格 | 核心性格、优点、缺点、隐藏面 |
| 背景 | 出身、成长经历、重要事件、心理创伤 |
| 目标 | 表面目标、深层动机、内心恐惧 |
| 能力 | 技能、特长、弱点 |
| 关系 | 家人、朋友、敌人、恋人 |
| 角色弧线 | 起始状态、变化过程、最终状态 |
| 语言风格 | 说话方式、口头禅、常用词汇 |
| 出场场景 | 首次出场、关键场景 |

## 关系网络

### 关系类型

| 关系类型 | 说明 | 设计要点 |
|----------|------|----------|
| 家人 | 血缘关系 | 影响角色价值观 |
| 朋友 | 友情关系 | 提供支持或背叛 |
| 敌人 | 对立关系 | 制造冲突和压力 |
| 恋人 | 爱情关系 | 情感线和成长催化剂 |
| 导师 | 指导关系 | 传授技能和智慧 |

### 关系动态设计

```
关系发展 = 初始状态 + 事件影响 + 变化结果
             ↓
       关系会随着情节发展变化
       关键事件导致关系转折
```
