# 读者反馈指标定义

## 核心功能表

### 1. 情感曲线预测

| 曲线类型 | 描述 |
|---|---|
| 愉悦度曲线 | 读者情感愉悦度的变化趋势 |
| 紧张度曲线 | 悬念/紧张感的起伏变化 |
| 好奇度曲线 | 读者好奇心的维持与消耗 |
| 代入感曲线 | 读者角色代入感的变化 |

### 2. 弃书点识别

| 弃书点类型 | 描述 |
|---|---|
| 节奏弃书点 | 节奏过于拖沓导致的流失 |
| 逻辑弃书点 | 情节/人物行为不合逻辑导致的流失 |
| 情感弃书点 | 角色塑造失败导致的流失 |
| 疲劳弃书点 | 重复类型内容导致的流失 |

### 3. 章节吸引力评分

| 评分项 | 描述 |
|---|---|
| 钩子强度 | 章首钩子吸引读者的能力 |
| 信息密度 | 有价值信息的传递效率 |
| 冲突演进 | 冲突是否有效推进 |
| 情感触点 | 引发读者情感共鸣的能力 |

### 4. 读者类型关注点

| 读者类型 | 关注点 |
|---|---|
| 玄幻迷 | 升级体系、世界观、战斗描写 |
| 言情粉 | 情感互动、角色魅力、cp感 |
| 悬疑爱好者 | 悬念铺设、线索埋设、逻辑严谨 |
| 严肃读者 | 文笔、深度、主题表达 |
| 休闲读者 | 轻松阅读、节奏明快 |

## 读者反馈报告格式

```yaml
读者反馈报告:
  反馈时间: "2026-05-05 10:00"
  模拟范围: "第1-10章"
  目标读者: "玄幻迷"

  情感曲线评估:
    愉悦度: "第1-3章高，第4章下降，第5章回升"
    紧张度: "第4章、第8章出现峰值"
    好奇度: "总体维持良好，结尾钩子有效"
    代入感: "主角塑造成功，代入感强"

  弃书点评估:
    总弃书风险: "中低"
    高风险区域:
      - 位置: "第6章中段"
        类型: "节奏弃书点"
        描述: "节奏过于拖沓，信息密度低"
        严重程度: "重要"

    低风险区域:
      - 位置: "第2章"
        类型: "逻辑弃书点"
        描述: "配角行为略有不合理"
        严重程度: "轻微"

  章节吸引力评分:
    - 章节: "第1章"
      评分: 8/10
      钩子强度: 9/10
      问题: "无"
    - 章节: "第2-5章"
      评分: 7/10
      问题: "信息密度偏低"
    - 章节: "第6章"
      评分: 5/10
      问题: "需增加冲突事件"

  改进建议优先级:
    - 优先级1: "优化第6章节奏，增加冲突事件"
    - 优先级2: "调整第2章配角行为逻辑"
    - 优先级3: "增强第7章情感触点"
```

## 评分标准

### 章节吸引力评分标准

| 评分 | 等级 | 说明 |
|------|------|------|
| 8-10 | 优秀 | 钩子强劲，信息密度高，冲突推进有效 |
| 6-7 | 良好 | 整体可读，有小问题需要优化 |
| 4-5 | 一般 | 存在明显问题，需要较大调整 |
| 1-3 | 较差 | 严重问题，可能导致读者流失 |

### 弃书风险等级

| 风险等级 | 说明 |
|----------|------|
| 高 | 很可能导致读者弃书 |
| 中 | 可能影响读者阅读意愿 |
| 低 | 轻微问题，不影响整体阅读 |
