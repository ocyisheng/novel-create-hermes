# 情节逻辑问题示例

## 输出格式

### 情节逻辑检测报告（YAML）
```yaml
情节逻辑检测报告:
  检测范围: "[章节/全文/特定情节]"
  检测维度: "[因果/转折/伏笔/节奏/结局]"
  检测时间: "[ISO时间]"

  问题列表:
    - 问题: "[问题描述]"
      位置: "[出现位置]"
      维度: "[因果/转折/伏笔/节奏/结局]"
      严重程度: "[致命/重要/轻微]"
      建议: "[修复方案]"

  统计:
    致命问题: X个
    重要问题: X个
    轻微问题: X个

  总体评估: "[总体评价]"
```

---

## 问题示例

### 示例1：因果合理性

```yaml
- 问题: "主角突然获得神器，无任何铺垫"
  位置: "第15章"
  维度: "因果合理性"
  严重程度: "致命"
  建议: "在前文增加主角与神器的伏笔关联，如血脉传承、遗迹指引等"
```

### 示例2：转折动机

```yaml
- 问题: "反派突然洗白，无合理动机"
  位置: "第30章"
  维度: "转折动机"
  严重程度: "重要"
  建议: "增加反派洗白的心理转变过程，如亲情打动、利益权衡"
```

### 示例3：伏笔逻辑

```yaml
- 问题: "第5章埋下的伏笔在结尾未回收"
  位置: "第5章 vs 第50章"
  维度: "伏笔逻辑"
  严重程度: "重要"
  建议: "在结局章呼应第5章的伏笔，或解释未回收的原因"
```

### 示例4：节奏逻辑

```yaml
- 问题: "连续8章无高潮，节奏过于拖沓"
  位置: "第20-27章"
  维度: "节奏逻辑"
  严重程度: "重要"
  建议: "在第23章增加小高潮，调整章节节奏"
```

### 示例5：结局逻辑

```yaml
- 问题: "主角获胜过于偶然，缺乏必然性"
  位置: "最终章"
  维度: "结局逻辑"
  严重程度: "致命"
  建议: "强化主角获胜的必然因素，如实力积累、智慧取胜"
```

## 统计示例

```yaml
统计:
  致命问题: 1个
  重要问题: 4个
  轻微问题: 3个

总体评估: "整体情节逻辑较好，主要问题集中在转折动机的铺垫不足，建议加强伏笔设计。"
```
