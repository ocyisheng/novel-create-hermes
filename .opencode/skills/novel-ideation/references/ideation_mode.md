# 创意方案内容构成

每个方案的篇幅控制在 10-20 行，语言为自然中文，无需 YAML。

## 概念方向（divergent）

每个方向 6-10 行，速写轮廓：

- **一句话概述**（15-30 字）
- **核心冲突**（一句话点明主要矛盾）
- **角色速写**（身份 + 核心特质，2-3 行）
- **亮点**（与常规类型的区别，1-2 行）
- **适用约束**（约束编号，可选）

## 方案生成（focused）

每个方案 10-18 行，结构固定：

**标题** — 简短命名
**一句话定位** — 这个方案要创造什么

**内容（按焦点类型，见下表）** — 只勾勒轮廓，不填充细节

**兼容性** — 一句话说明与已有设定不冲突

**入口** — 一句话说明从哪里切入

### 各焦点类型的内容要点

| 焦点类型 | 必须包含的要点（3-5 行） |
|----------|--------------------------|
| character_arc | 身份定位、核心动机、关键关系、主要冲突点 |
| scene | 场景目标、冲突层次、节奏基调、伏笔锚点 |
| world_rule | 规则定义、影响范围、一个具体体现场景 |
| plot_thread | 起点事件、发展的关键驱动、预期转折 |
| structure | 结构框架、卷/章分布、节奏密度标记 |
| narrative_voice | 腔调特征、视角选择、笔法约定 |
| thematic_motif | 象征意象、首次出现场景、演变路径 |

## 输出示例（focused / character_arc）

```
## 方案：前朝遗孤

定位：一个与主角立场对立但价值观有交叉点的谋士型反派。

内容：
身份是前朝皇室后裔，表面为当朝国子监博士，暗中经营情报网络。
动机不是简单复仇，而是认为当朝背离"天道"，要重建秩序。
与主角形成镜像：主角为"守护"而隐忍，他为"颠覆"而克制。
关键冲突：他多次暗中"帮"主角，但目的截然不同——最终立场对决。

兼容性：与当前"宗门格局"不冲突，可归入散修联盟背景。

入口：第 5 章城市场景以 NPC 身份首次亮相。
```
