# 世界观详细示例

本文件包含世界观构建的详细工作流示例，供实际构建时参考。

---

## 示例一：玄幻修仙世界观

```
需求：
  类型：玄幻修仙
  背景：末法时代
  核心：灵气衰退

基础构建：
  - 时代：近古（灵气衰退期）
  - 规则：境界越高，所需灵气越多

力量体系：
  - 境界：练气→化神（五层）
  - 资源：灵石/功法/丹药
  - 法宝：法器→仙器

势力格局：
  - 青云宗（正道）+ 天魔殿（魔道）+ 万宝阁（中立）
  - 关系：正邪千年对立

地理：
  - 九州大陆
  - 万魔渊（封印中）

历史：
  - 上古盛世 → 万仙大战 → 灵气衰退 → 末法将至

输出：
  → worldbuilding/基本信息.yaml
  → worldbuilding/力量体系.yaml
  → worldbuilding/势力格局.yaml
  → worldbuilding/地理位置.yaml
  → worldbuilding/历史.yaml
```

## 示例二：都市异能世界观

```yaml
worldview:
  basic:
    name: "都市异界"
    type: "都市异能"
    era: "现代都市"
    core_rule: "能力觉醒，秩序与隐匿"

  power_system:
    能力类型:
      - 元素控制（火/水/风/雷）
      - 身体强化（力量/速度/防御）
      - 感知系（读心/预知/通灵）
      - 召唤系（契约兽/亡灵）

    管理组织:
      - "官方机构（超管局）"
      - "地下势力（暗网）"
      - "家族势力（传承者）"

  factions:
    - name: "超管局"
      type: "官方"
      role: "管理觉醒者，维护社会稳定"

    - name: "暗网"
      type: "地下"
      role: "黑色交易，能力黑市"

  geography:
    主要城市:
      - "京城（总部）"
      - "魔都（金融中心）"
      - "特区（试验区）"
```

## 示例三：科幻星际世界观

```yaml
worldview:
  basic:
    name: "星际联邦"
    type: "科幻星际"
    era: "公元2500年"
    core_rule: "星际航行，能源为王"

  power_system:
    科技体系:
      - 星际航行（跃迁引擎）
      - 人工智能（AI伴侣）
      - 能量武器（高斯炮/等离子）
      - 维度防护（护盾技术）

    势力:
      - 人类联邦（主体）
      - 赛德文明（盟友）
      - 奥罗克斯（中立）
      - 高维意志（敌对/未知）

  factions:
    - name: "人类联邦"
      type: "政府"
      capital: "地球"

    - name: "赛德联邦"
      type: "盟友"
      capital: "赛德星"

  geography:
    核心星系:
      - "太阳系（人类发源地）"
      - "赛德星系（盟友）"
    争议区域:
      - "中立带"
      - "无人区"
```

## 目录结构参考

```
worldbuilding/
├── 基本信息.yaml        # 基本信息（名称/类型/时代/核心规则）
├── 核心规则.yaml        # 核心规则（魔法/灵气/科技限制）
├── 力量体系.yaml       # 力量体系（境界/资源/法宝）
├── 势力格局.yaml   # 势力格局（势力/关系/冲突）
├── 地理位置.yaml  # 地理（疆域/险地/交通）
├── 历史.yaml    # 历史（时代/事件/更替）
├── 文化.yaml   # 文化（风俗/语言/信仰）
├── 经济体系.yaml   # 经济（货币/资源/贸易）
├── 政治制度.yaml   # 政治（政权/治理/外交）
└── 社会阶层.yaml   # 社会（阶层/流动/矛盾）
```
