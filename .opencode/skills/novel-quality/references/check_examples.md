# 角色一致性检测示例

## 输出格式

### 角色一致性检测报告（YAML）
```yaml
角色一致性检测报告:
  检测范围: "[章节/全文/特定角色]"
  检测时间: "[ISO时间]"

  问题列表:
    - 角色: "[角色名]"
      问题: "[问题描述]"
      位置: "[出现位置]"
      维度: "[性格/行为/语言/能力/关系]"
      严重程度: "[致命/重要/轻微]"
      建议: "[修复方案]"

  统计:
    致命问题: X个
    重要问题: X个
    轻微问题: X个

  总体评估: "[总体评价]"
```

---

## 示例输出

### 示例1：性格一致性检测

```yaml
问题列表:
  - 角色: "林动"
    问题: "第5章表现出的懦弱性格与第1章塑造的勇敢形象矛盾"
    位置: "第5章第3节"
    维度: "性格一致性"
    严重程度: "重要"
    建议: "在第4章增加林动性格转变的铺垫，如家族变故的心理冲击"
```

### 示例2：行为一致性检测

```yaml
  - 角色: "萧炎"
    问题: "作为炼药师，对药材的基本常识表现无知"
    位置: "第8章"
    维度: "行为一致性"
    严重程度: "致命"
    建议: "补充萧炎作为炼药师的专业知识背景"
```

### 示例3：语言风格检测

```yaml
  - 角色: "小医仙"
    问题: "山村少女使用过于书面的文言表达"
    位置: "第3章对话"
    维度: "语言风格"
    严重程度: "轻微"
    建议: "将文言表达改为口语化表达"
```

### 示例4：能力边界检测

```yaml
  - 角色: "主角"
    问题: "斗之气阶段使用出斗者技能"
    位置: "第15章"
    维度: "能力边界"
    严重程度: "致命"
    建议: "修改为斗之气阶段的合理技能"
```

### 示例5：关系动态检测

```yaml
  - 角色: "主角与导师"
    问题: "关系从敌对直接跳到生死之交，无过渡"
    位置: "第20-25章"
    维度: "关系动态"
    严重程度: "重要"
    建议: "增加中间章节的关系转变铺垫"
```

## 统计示例

```yaml
统计:
  致命问题: 2个
  重要问题: 5个
  轻微问题: 8个

总体评估: "角色整体塑造良好，主要问题集中在能力边界检测，建议加强能力设定的系统性检查。"
```
