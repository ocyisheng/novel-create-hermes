# 都市异能类型指南

本文档提供完整的都市异能类型创作参考。

## 核心元素

```yaml
元素:
  - 系统类型: 签到/加点/任务/商城/抽卡
  - 典型副本: 都市怪谈/组织对抗/国际争斗/超凡战争
  - 成长线: 校园→职场→商圈→国际→超凡
```

## 系统类型详解

### 签到系统

| 类型 | 描述 | 奖励 |
|------|------|------|
| 每日签到 | 连续登录获得 | 基础资源 |
| 连续签到 | 累积天数 | 额外奖励 |
| 特殊签到 | 节日/成就触发 | 稀有奖励 |
| 地点签到 | 特定位置触发 | 专属奖励 |

### 加点系统

```yaml
属性:
  力量: 物理攻击、体力
  敏捷: 速度、闪避
  智力: 技能效果、法力
  魅力: 社交、隐藏

技能:
  战斗系: 攻击、防御、位移
  生活系: 采集、制造
  专业系: 医疗、工程
  特殊系: 稀有、唯一
```

### 任务系统

| 类型 | 频率 | 奖励 | 重要性 |
|------|------|------|--------|
| 主线任务 | 一次性 | 高 | 核心剧情 |
| 支线任务 | 一次性 | 中 | 丰富内容 |
| 日常任务 | 重复 | 稳定 | 资源来源 |
| 隐藏任务 | 触发 | 特殊 | 惊喜 |

### 商城系统

```yaml
货币:
  - 金币: 日常获得
  - 钻石: 付费/成就
  - 荣誉点: 任务获得
  - 成就点: 里程碑获得

商品:
  - 装备: 武器、防具
  - 技能: 技能书
  - 道具: 消耗品
  - 情报: 信息
```

## 典型情节

### 经典模式

| 模式 | 核心公式 | 适用场景 |
|------|---------|---------|
| 系统觉醒 | 普通人→系统激活→开始变强 | 开篇 |
| 组织对抗 | 加入组织→执行任务→对抗敌人 | 主线 |
| 身份隐藏 | 双重身份→平衡生活→危机爆发 | 冲突 |
| 都市怪谈 | 日常→灵异事件→解决 | 副本 |
| 国际争端 | 国内→国际→超凡战争 | 高潮 |

### 创新方向

- **反向系统**：系统带来麻烦而非便利
- **共享系统**：多人共享同一系统
- **系统战争**：不同系统之间的对抗
- **无系统**：靠努力和悟性变强
- **古武复兴**：传统武术+现代都市

## 成长线设计

```
阶段一：校园期（E-D级）
  场景：高中/大学
  重点：能力觉醒、同学关系
  冲突：校园霸凌、考试压力

阶段二：职场期（C-B级）
  场景：初入职场
  重点：职场竞争、能力应用
  冲突：工作挑战、职业发展

阶段三：商圈期（B-A级）
  场景：商业领域
  重点：资源积累、势力建立
  冲突：商业对手、财富争夺

阶段四：国际期（A-S级）
  场景：国际舞台
  重点：国家对抗、超凡战争
  冲突：国际危机、终极敌人

阶段五：超凡期（S级以上）
  场景：法则层面
  重点：世界真相、终极挑战
  冲突：世界危机、末世
```

## 创作建议

### 现实平衡

- **现实感**：保持都市生活的真实感
- **约束机制**：能力有限制，避免无敌
- **代价设定**：强大能力需付出相应代价
- **法律约束**：超凡者需要遵守的规则

### 情感描写

- **人际关系**：能力变化带来关系变化
- **内心挣扎**：道德选择与力量诱惑
- **社会责任**：能力带来的责任与选择
- **身份认同**：超凡者与普通人的界限

### 常见套路

- 退婚流：能力觉醒后打脸
- 系统流：任务奖励变强
- 组织流：加入官方或地下
- 隐藏流：双重身份
- 都市流：日常+灵异
