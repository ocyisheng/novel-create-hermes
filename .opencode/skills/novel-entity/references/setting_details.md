## 规则闭环检查

### 常见漏洞

| 漏洞 | 解决方案 |
|------|----------|
| 力量膨胀 | 设置上限/代价 |
| 无限制能力 | 增加限制条件 |
| 物资无限 | 稀缺设计 |
| 时间线矛盾 | 仔细校验 |

### 闭环检查清单

- [ ] 境界提升有明确条件？
- [ ] 力量使用有代价？
- [ ] 资源是否稀缺？
- [ ] 时间线是否一致？
- [ ] 势力关系是否合理？
- [ ] 地理设定是否矛盾？
