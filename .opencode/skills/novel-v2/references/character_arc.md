# 焦点类型：character_arc — 角色创作指南

## 适用任务

创建新角色、编辑已有角色档案。

## 角色档案结构

角色档案写入 graph 时，content 字段为 JSON 结构化数据，包含以下层级：

**索引信息（必填）：**
- 实体ID、名称、别名/外号、角色类型（主角/反派/导师/盟友/对手/次要角色）
- 势力/阵营、状态（active/inactive/deceased/departed）、首次出场章节

**摘要（必填，下游 P7/P8 快速加载用）：**
- 一句话描述(≤30字)、当前境况(≤50字)、核心特质(≤5)、当前目标、关键关系

**完整档案：**

1. **基本信息**：性别、年龄、出生时间、身份、外貌（身高/体型/特征/习惯动作/服饰风格）
2. **性格**：核心特质、优点、缺点、价值观、口头禅、语气风格
3. **背景**：出身、成长经历(多段正文)、关键事件、心理创伤、动机根源
4. **目标与冲突**：公开目标、隐藏目标、内心渴望、核心恐惧、主要障碍
5. **能力设定**：技能专长、天生才能、能力限制、成长潜力
6. **关系网络**：开放式标签系统（不再限死家人/师门/朋友/敌人/恋人分类）——每条关系含角色名、标签列表（如["父子","决裂","潜在和解"]）、强度1-10、变化趋势、关键事件
7. **角色弧线（必填）**：起始状态 → 成长阶段 → 关键转变 → 最终状态。弧线完整性标记
8. **与主线关系**：主线参与度（核心/重要/次要/背景）、对主线影响、主线对其影响
9. **创作笔记**：注意事项、避免踩坑、扩展建议

## 角色设计原则

**扁平 vs 圆形人物：**
- 主角和关键配角必为圆形——圆形人物的检验标准是"能否以令人信服的方式让读者感到意外"
- 功能性配角可用扁平——基于单一观念或品质塑造，易辨识、易记忆
- 好的小说同时需要两者。复杂人物注入作者的浩瀚活力后也可获得深度（狄更斯证明了这点）

**为"自动性"预留空间：**
- 角色一旦被请进小说便有自身意志，作者无法随意驱遣
- 如果角色开始"反抗"你的安排、表现出预料之外的言行——通常是角色成功的标志
- 区分"角色成长"（有内在逻辑的自动演化）与"性格突变"（作者的粗暴干预）

**角色不必讨好读者：**
- 世事一无可知（契诃夫），艺术家不做裁判官，做公平的证人
- 好的角色往往"由不得作者操控"

**关系网络使用开放式标签：**
- 不要用预设的封闭类别穷尽人际关系。《红楼梦》中贾宝玉与妙玉是"灵性上的共鸣者"
- 每条关系标注强度1-10和变化趋势（恶化→缓和/稳定→深化等）
