# 分纲示例

本文件包含不同类型小说的详细分纲示例。

---

## 示例流程

```
1. 用户触发：「请基于总纲.yaml生成所有章节的详细分纲」
2. 技能执行：
   - 读取总纲.yaml，解析故事结构（幕列表）和50章章节列表
   - 为第1章生成：建置阶段、日常世界建立
   - 为第25章生成：第二幕中点、重大转折
   - 为第50章生成：第三幕解决、结局
   - 创建 outline/分纲/卷{N} 目录（卷数由 config.yaml 结构配置决定）
   - 写入第1章.yaml 到第50章.yaml
3. 完成：50个分纲文件已生成
```
