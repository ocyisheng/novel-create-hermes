# 模式 B：写作需求分析（writing）

**适用阶段**：P4（有创意需总纲）

## 分析维度

| 维度 | 说明 | 示例值 |
|------|------|--------|
| 小说类型 | 已确认的类型 | 玄幻/科幻/都市 |
| 目标受众 | 读者群体 | 男频/女频/混合 |
| 篇幅目标 | 字数/章节数 | 长篇（100万字+）/300章 |
| 核心元素 | 从创意简报确认的生产要素 | 升级/战斗/奇遇 |
| 排斥元素 | 写作中避免的内容 | 后宫/虐主/无敌流 |
| 写作目标 | 创作目的 | 商业/个人/网络连载 |
| 更新频率 | 发布节奏 | 日更/周更/月更 |

## 执行流程

```
1. 确认小说类型
2. 明确目标受众
3. 确定篇幅目标
4. 核心元素（从创意简报确认）
5. 排斥元素
6. 写作目标
7. 更新频率
8. 生成写作需求报告
```

## 产出格式

```yaml
写作需求报告:
  小说类型: [玄幻/科幻/都市/悬疑/历史]
  目标受众: [男频/女频/混合]
  篇幅目标: [短篇/中篇/长篇/具体字数]
  核心元素: [从创意简报确认的生产要素列表]
  排斥元素: [写作中避免的内容列表]
  写作目标: [商业/个人/练习/网络连载]
  预期成果: "成果描述"
  约束建议: [基于生产参数的约束方向]
  更新频率: [日更/周更/月更]
```
