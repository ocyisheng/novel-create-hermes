# 总纲设计指导

在 P4 总纲撰写阶段，将创意方案提炼为故事全局骨架。输出见 `assets/outline.yaml`。

---

## 1. 从创意到总纲

输入 `ideation/最终创意方案.yaml`，提取以下字段映射到总纲：

| 创意方案字段 | 总纲映射 | 说明 |
|-------------|---------|------|
| `最终方案.一句话概述` | `核心概念.一句话概述` | 直接继承，保持一致 |
| `最终方案.核心冲突` | `核心概念.核心卖点` | 扩展为吸引读者的亮点描述 |
| `最终方案.主角设定` | `人物与世界` | 展开为主角与世界的具体关系 |
| `最终方案.世界观概述` | `人物与世界.世界规则对主角的约束` | 提取对主角构成限制的规则 |
| `最终方案.情节主线` | `故事结构.幕` | 分解为各幕主线和关键节点 |

**原则**：总纲不创造新内容，而是把创意方案里的概念**结构化和具体化**。

---

## 2. 故事结构设计

### 选择幕数

| 结构 | 章节分布 | 适合 |
|------|---------|------|
| **三幕** | 25%/50%/25% | 标准网文结构，大部分类型通用 |
| **五幕** | 15%/25%/20%/15%/25% | 情节复杂、多反转的故事 |
| **自定义** | 任意比例 | 非标准结构（如单元剧、群像叙事） |

### 设计各幕

每幕填写三项核心内容：

```yaml
幕:
  - 幕号: 1
    名称: "开端"
    章节范围: "第1章 - 第30章"    # ← 与章节分布比例对齐
    主线: "主角穿越异界，建立生存基础"
    关键节点:
      - "主角穿越（第1章）"
      - "觉醒金手指（第5章）"
      - "离开新手村（第15章）"
      - "第一次生死危机（第25章）"
    主角状态: "从懵懂求生到站稳脚跟"
```

- **主线**：本幕的核心叙事线，1-2 句话
- **关键节点**：4-6 个关键事件，标注章节号，覆盖本幕的起承转合
- **主角状态**：本幕结束时主角的变化，要有明确的前后对比

## 3. 分卷概览设计

分卷概览是 P6 分卷大纲的输入。每卷只需定义最核心的字段：

```yaml
分卷:
  - 卷号: 1
    卷名: "开端"
    章节范围: "第1章 - 第30章"
    核心问题: "主角如何在异世界活下来？"
    主角转变: "从普通人到具备基本生存能力"
```

设计要点：

- **卷名**：用 2-4 字概括，能提示本卷核心内容（如"惊变"、"崛起"、"决战"）
- **核心问题**：每卷回答一个问题，问题之间要有递进关系
- **主角转变**：每卷有明确的变化，不可原地踏步

### 卷间递进示例

```
卷1 "初临"：  如何在异世界活下来？         → 从普通人到站稳脚跟
卷2 "崛起"：  如何建立自己的势力？         → 从孤身一人到初具班底
卷3 "争锋"：  如何在多方势力中周旋？       → 从被动应对到主动布局
卷4 "决战"：  如何击败最终敌人？           → 从弱势到逆转胜局
卷5 "新章"：  胜利之后世界走向何方？       → 从战斗到建设新秩序
```

## 4. 人物与世界关系设计

这是总纲区别于简单"故事大纲"的核心——它定义了主角在这个世界中的独特位置。

```yaml
人物与世界:
  主角与世界的关系: "生于此世的废柴少年"     # 基本定位
  主角的特殊性: "唯一拥有双灵根的人"         # 独一无二的特质
  世界规则对主角的约束:
    - "灵根决定修炼速度"
    - "宗门等级森严，底层弟子资源匮乏"
    - "上古禁制限制境界突破"
  主角打破/利用世界规则的方式: "通过双灵根强行吸收两种属性的灵力"
  初始境况: "被判定为废灵根的低阶弟子，受尽白眼"
```

约束与突破的对应关系：每个"约束"都应该有一个"打破方式"或"代价"。

## 5. 时间线设计

`outline/时间线设计.yaml` 是总纲的补充，规划故事世界的历史背景和主线时间轴。

### 内容来源

| 时间线阶段 | 数据来源 | 作用 |
|-----------|---------|------|
| 远古/背景时代 | 世界观设定（势力历史、力量体系起源） | 为伏笔和揭秘提供锚点 |
| 主线前期 | 创意方案的"主角设定" | 主角的成长基础 |
| 主线时期 | 故事结构各幕 | 全局时间概念 |

### 设计要点

- **时间锚点**：每个重要事件标注具体时间或相对时间
- **因果链**：背景事件 → 当前冲突 → 未来发展的因果关系要可追溯
- **预留弹性**：写作中时间线可能调整，保持事件顺序正确即可，不必精确到天

## 6. 节奏与结局

```yaml
节奏:
  前期基调: "舒缓探险"                     # 建置世界和角色
  中期基调: "紧凑对抗"                     # 冲突升级
  后期基调: "高潮收束"                     # 决战和结局
  章节分布: [25, 50, 25]                  # 与幕数对齐
```

- **章节分布**：决定 P6 分卷的章节数分配。过于偏向前期（如 40/40/20）会导致高潮部分篇幅不足
- **结局设计**：结局类型和设计思路要能在创意方案中找到依据，避免空降结局
