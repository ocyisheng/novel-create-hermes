# character_arc — 角色创作方法论

## 结构由脚本保障

content JSON 的字段结构由 `schemas.py` 自动校验：
- 角色类型（主角/反派/导师/盟友/对手/次要角色）必填
- 性格（核心特质/优点/缺点）必填
- 角色弧线（起始状态→最终状态）必填
- 关系网络使用开放式标签列表

你不必记忆字段清单——脚本会提示。

## 创作方法论（需 LLM 判断）

- **扁平 vs 圆形**：主角和关键配角必为圆形（标准：能否令人信服地让读者意外）。功能性配角可用扁平。好小说同时需要两者
- **自动性空间**：角色一旦被请进小说便有自身意志。如果角色开始"反抗"你的安排，通常是成功的标志。区分"文势所逼"（成长）与"粗暴干预"（突变）
- **角色不必讨好读者**：世事一无可知（契诃夫），艺术家不做裁判官
- **关系用开放标签**：不要用预设分类穷尽关系。贾宝玉与妙玉不是家人/师门/朋友/敌人/恋人中的任何一个——是"灵性上的共鸣者"
