## 六维速查表

| # | 维度 | 冲突本质 | 回响 | 一句话辨维 |
|:-:|:-----|:---------|:-----|:-----------|
| ① | 个体竞技层 | 该拼还是该换？ | 天赋决定上限，但努力决定下限。你在天赋者放弃的时候，还在跑。 | 角色在跟"别人"比 |
| ② | 社会结构层 | 该争还是该造？ | 你没有管道，但你有移动的自由；你没有生态位，但你有重新定义赛道的能力。 | 角色在跟"结构"斗 |
| ③ | 系统规则层 | 该守还是该破？ | 你一旦看懂筛子的构造，就不再是被筛的那粒谷。 | 角色在跟"规则"绕 |
| ④ | 时间消磨层 | 该熬还是该跳？ | 温水煮不沸的，是那些还在心里记着沸水温度的人。 | 角色在跟"时间"耗 |
| ⑤ | 组织异化层 | 该从还是该飞？ | 系统只想让你做一颗螺丝钉，但螺丝钉可以自己长出翅膀。 | 角色在跟"系统"扛 |
| ⑥ | 心智代际层 | 该认还是该改？ | 你用尽一生填一个坑，但那个坑从来就不存在。 | 角色在跟"自己"过不去 |

## 选维决策树

```
角色/情节的冲突核心是什么？
│
├─ 能力/天赋的差距？ → ① 个体竞技层
│
├─ 资源/靠山/出身的不公？ → ② 社会结构层
│
├─ 制度/流程/潜规则的压制？ → ③ 系统规则层
│
├─ 长期消耗/麻木/初心不再？ → ④ 时间消磨层
│
├─ 被系统替代/被组织格式化？ → ⑤ 组织异化层
│
└─ 童年烙印/身份认同/配得感？ → ⑥ 心智代际层
```

## 注入模板

在 novel-writer/ideation prompt 中使用：

```markdown
### 六维冲突设计参考
加载技能：novel-six-dimensions

核心冲突维度：① 个体竞技层
不处理的后果：（引用框架内容）
事实：（引用框架内容）
处理方式：（引用框架内容，注明角色做得到或做不到）
```

只注入当前相关的维度，不投喂完整框架。
