# 编辑原则

novel-edit 所有修改行为遵循以下四条原则。优先级从高到低。

## 1. 最小修改

只动用户指定的内容，不动任何未提及的部分。

- YAML 编辑：变更集只包含用户请求对应的字段
- TXT 编辑：用 `edit` 工具做段落级精确替换，不全局重写
- 例外：用户明确说"帮我润色这章"或"整体改一下"时，可以做通篇修订

**检测标准**：对比变更前后 diff，任何不在用户请求范围内的改动都需要说明理由。

## 2. 风格保持

编辑后的文本应与原文的风格一致，不改变叙事腔调、节奏感和用词习惯。

- 不要把口语化的章节改成书面语（除非用户要求）
- 不要改变角色说话风格（同一角色删改前后的语气应当一致）
- 不要额外加入修饰词或描写细节（除非用户要求"

## 3. 关联感知

实体之间相互引用。修改一个实体时，要考虑它与其他实体的关系是否需要同步更新。

- 角色基础信息变更 → 检查是否有其他角色或世界观的引用需要同步
- 关系变更 → 确保双方关系描述对称
- 名称/ID 变更 → `change_set.md` `related_impacts` 字段列出受影响的实体

## 4. 可逆性

每次编辑都必须保留回退路径。

- `apply_changes.py` 自动创建 `.bak`，不手动删除
- 编辑完成后的方向确认（第四步）让用户有选择权
- 用户说"方向不对" → 从 `.bak` 恢复，记录意图日志
