# D7. 叙事风格/视角 — 需求发现树

根节点：你想用什么方式来讲这个故事？

用于 focus_type=narrative_voice（叙事风格/视角/语调确认）前置需求发现。Grill 通过 novel-tool 自行查询已有风格配置。

```
├── D7.0 已有风格锚定（展示当前活跃风格）
│   ├── 当前风格为：[风格名称]
│   ├── 你满意这个风格，还是想调整？
│   └── （无已有风格）→ 展开以下分支：

├── D7.1 视角选择
│   ├── 你希望用什么视角讲述故事？
│   │   推荐：第三人称限制（网文主流，兼顾亲密感和灵活性）
│   │   选项：[第一人称] [第三人称限制] [第三人称全知] [多视角切换]
│   └── 是否需要多视角？
│       （单视角/双视角/多视角≤3/群像）

├── D7.2 叙事手法
│   ├── 主要使用什么叙事顺序？
│   │   推荐：顺序叙事（读者友好）
│   │   选项：[顺序] [倒叙] [插叙] [多线并行]
│   ├── 如何处理角色背景信息？
│   │   推荐：闪回 + 对话透露
│   │   选项：[闪回] [对话透露] [内心独白] [第三方叙述]
│   └── 如何处理读者与角色的信息差？
│       （悬疑跟随/戏剧反讽/误导/混合）

├── D7.3 语言风格偏好
│   ├── 文风倾向？
│   │   （简洁利落/细腻描写/幽默风趣/严肃庄重/诗意华丽）
│   ├── 对话风格？
│   │   （口语化自然/文雅正式/特色方言/简洁干练）
│   └── 有没有参考的作家风格？

└── D7.4 编辑与调整（当修改请求模糊时展开）
    ├── 当前叙事方式：[摘要]
    ├── 哪方面想调整？（视角/叙事手法/语言风格/参考风格切换）
    └── 改动幅度？（微调/整体切换）
```

**交互规则**：
- 风格切换请求明确时（"用凡人修仙风写"）跳过整个决策树
- 快速模式只问 D7.1 视角选择
