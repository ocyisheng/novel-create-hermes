# 伏笔设计详解

本文件包含从 SKILL.md 移出的伏笔设计详细内容。

---

## 伏笔公式

```
伏笔强度 = 隐蔽度 × 重要性 × 时效
```

好的伏笔：
1. **隐蔽**：不明显但事后能回想
2. **重要**：与主线或角色相关
3. **适时**：在关键时刻回收

---

## 伏笔类型

### 1. 人物伏笔

| 类型 | 说明 | 示例 |
|------|------|------|
| 身份埋设 | 隐藏身份 | 神秘人的真实身份 |
| 实力埋设 | 隐藏实力 | 老人的真实境界 |
| 关系埋设 | 隐藏关系 | 实为父子 |
| 动机埋设 | 隐藏目的 | 另有企图 |

### 2. 物品伏笔

| 类型 | 说明 | 示例 |
|------|------|------|
| 法宝埋设 | 关键道具 | 玉佩是神器 |
| 信物埋设 | 身份凭证 | 玉镯是信物 |
| 遗物埋设 | 关键线索 | 遗书是线索 |
|  普通物品变宝 | 意外宝贝 | 石头是灵石 |

### 3. 场景伏笔

| 类型 | 说明 | 示例 |
|------|------|------|
| 地点埋设 | 关键地点 | 禁地有密道 |
| 环境埋设 | 环境异常 | 花香有问题 |
| 建筑埋设 | 建筑玄机 | 祠堂有密室 |

### 4. 对话伏笔

| 类型 | 说明 | 示例 |
|------|------|------|
| 言语暗示 | 话中有话 | "小心身边的人" |
| 诺言埋设 | 未来呼应 | "我会回来的" |
| 誓言埋设 | 誓言应验 | "绝不背叛" |

### 5. 细节伏笔

| 类型 | 说明 | 示例 |
|------|------|------|
| 动作细节 | 细微动作 | 小动作暴露身份 |
| 神态细节 | 表情异常 | 紧张/高兴/不安 |
| 物品细节 | 物品特征 | 特殊符号 |
| 时间细节 | 时间线埋设 | 特定日期 |

## 伏笔埋设技巧

### 隐蔽度技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 日常化 | 看似普通 | "今天的茶有点苦" |
| 对话中隐藏 | 混入聊天 | 无意间提起 |
| 误导 | 转移注意 | 让读者以为是别的 |
| 重复强调 | 多次出现 | 但不重要 |
| 细节植入 | 不起眼细节 | 衣服破了 |

### 埋设位置

| 位置 | 优点 | 缺点 |
|------|------|------|
| 开篇 | 铺垫充分 | 容易遗忘 |
| 中段 | 记忆清晰 | 铺垫不足 |
| 卷首 | 新卷提醒 | 中间间隔长 |
| 章节末 | 悬念感强 | 需要伏笔钩子 |

## 伏笔回收公式

```
伏笔回收 = 揭示 + 呼应 + 深化
```

### 回收方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 直接揭示 | 明确说 | "我是..." |
| 物品使用 | 使用伏笔 | 用玉佩救命 |
| 场景重现 | 回到伏笔地点 | 回到禁地 |
| 对话呼应 | 呼应前文 | "我回来了" |
| 反转揭示 | 完全相反 | 不是父子 |

### 回收时机

| 时机 | 说明 |
|------|------|
| 章节内 | 即时呼应 |
| 章节间 | 下一章 |
| 卷末 | 卷结束时 |
| 中点 | 全书中点 |
| 高潮 | 最高潮 |

## 伏笔管理

### 伏笔记录格式

```yaml
伏笔:
  - 描述: "身份伏笔"
    章节: 5
    状态: "待回收"
```

> 字段说明：
> - `描述`：伏笔内容
> - `章节`：埋设章节
> - `状态`：待回收 / 已回收

### 伏笔检查

- [ ] 伏笔是否自然、隐蔽但可见？
- [ ] 伏笔是否与主线相关？
- [ ] 回收时机是否合理？
- [ ] 是否有多个伏笔？
- [ ] 是否需要调整伏笔顺序？
