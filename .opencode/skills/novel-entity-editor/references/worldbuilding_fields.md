# 世界观实体可编辑字段指南

## 文件定位

- **路径**: `worldbuilding/{实体ID}.yaml`
- **多层结构**: 按子类型有不同的字段模块
- **schema 版本**: 1.0

## 可编辑字段总览

### 索引+摘要层（所有子类型通用）

| 字段路径 | 可修改？ | 说明 |
|---------|---------|------|
| `索引信息.名称` | ✅ | 显示名（如"灵气淬体体系""剑阁"） |
| `索引信息.实体子类型` | ✅ | location/faction/rule/power_system/history/culture/world_overview |
| `索引信息.状态` | ✅ | active / draft / archived |
| `索引信息.实体ID` | ❌ | 唯一标识，修改会断链 |
| `摘要.一句话描述` | ✅ | ≤30 字 |
| `摘要.章节关联` | ✅ | 关联章节号列表 |
| `摘要.关键词` | ✅ | ≤5 个关键词 |

### 完整档案（按子类型分类）

#### world_overview（世界观概览）
- `完整档案.世界名称`
- `完整档案.时代背景`
- `完整档案.核心设定`

#### rule（世界规则）
- `完整档案.物理法则`
- `完整档案.禁忌与限制`
- `完整档案.因果规律`

#### power_system（力量体系）
- `完整档案.体系名称`
- `完整档案.等级划分` — 等级列表（等级名+描述）
- `完整档案.力量来源`

#### faction（势力）
- `完整档案.势力名称`
- `完整档案.领袖`
- `完整档案.性质` — 正派/中立/反派
- `完整档案.核心目标`
- `完整档案.势力平衡`

#### location（地理位置）
- `完整档案.地点名称`
- `完整档案.区域描述`
- `完整档案.气候`
- `完整档案.交通要道`
- `完整档案.危险区域`

#### history（历史）
- `完整档案.纪元划分` — 纪元列表
- `完整档案.重大事件` — 事件列表

#### culture（文化）
- `完整档案.种族或民族` — 列表
- `完整档案.宗教与信仰`
- `完整档案.社会结构`
- `完整档案.风俗习惯`

### 通用字段（所有子类型）
- `完整档案.注意事项`
- `完整档案.扩展建议`

## 子类型切换注意事项

用户可能要求把实体从一个子类型改为另一个（如 rule → power_system）。

切换时需要：
1. 保留原子类型的通用字段（摘要层、索引信息）
2. 移除原子类型特有的字段
3. 补充新子类型所需字段
4. 不需要的字段可以留空或移除

## 编辑技巧

### 力量体系修改
- 等级划分是数组，新增/删除等级后应检查角色档案中的能力设定是否对齐
- 修改力量来源可能会影响多个角色的能力设定

### 势力修改
- 修改势力性质（正派→反派）后，主角与该势力的关系可能需同步调整
- 修改领袖后，与旧领袖相关的剧情线可能需要调整

### 规则修改
- 修改世界规则后，应检查是否有违反新规则的已写章节
- 新增规则时，确保它不与已有规则矛盾

### 历史修改
- 修改纪元划分或重大事件后，时间线相关设置可能需同步
- 重大事件的修改可能影响角色背景中的关键事件

## 编辑后检查清单

- [ ] YAML 格式正确
- [ ] 子类型字段与实际内容匹配（如 power_system 有等级划分）
- [ ] 所有章节关联与实际引用一致
- [ ] 如果修改了力量体系 → 关联角色是否需同步更新能力设定
- [ ] 如果修改了势力性质 → 相关角色的关系网络是否需更新
