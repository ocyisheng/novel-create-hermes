# 创意生成技术

本技能使用的5种核心创意生成技术。


## 1. 约束驱动创意法

```
基本公式：创意 = 约束 + 元素 + 角度
典型流程：限制 → 激发 → 发散 → 优化
```

---

## 2. 元素重组法

```
方法：将不相关的元素强制融合
示例："修仙 + 星际 + 烹饪" → 星际美食修仙
```

---

## 3. 反转颠覆法

```
方法：将传统设定完全反转
示例："灵气复苏" → "灵气衰退" → 末法时代修仙
```

---

## 4. 视角创新法

```
方法：更换叙述视角产生新意
示例：从反派视角重写传统故事
```

---

## 5. 形式突破法

```
方法：改变故事讲述形式
示例：聊天体小说、游戏系统小说、短视频体小说
```

---

## 使用建议

- **初期发散**：使用元素重组法+反转颠覆法快速生成概念
- **深化优化**：使用约束驱动法+视角创新法完善细节
- **形式突破**：使用形式突破法创造差异化卖点
