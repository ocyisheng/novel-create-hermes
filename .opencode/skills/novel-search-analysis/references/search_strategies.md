# 搜索策略参考

## 关键词搜索策略

### 基础关键词匹配
- 精确匹配：搜索完整关键词（如"天道宗"）
- 模糊匹配：对中文字词自动支持子串匹配
- 大小写：默认不区分，可配置

### 文件类型感知
- **TXT 文件**（章节正文）：全文搜索，重点标注行号
- **YAML 文件**（设定/档案）：搜索所有字段值，跳过 `_meta` 字段中的时间戳等噪音数据
- **索引文件**（project_index.yaml）：搜索名称和 one_line 描述

### 排序策略
搜索结果按以下优先级排序：
1. 章节文件（chapters/）优先——用户最常在这些文件中搜索
2. 按文件修改时间倒序——最新的内容优先
3. 同一文件内按行号升序

### 中文搜索注意事项
- Python 的 `in` 操作符对中文子串搜索已经足够（如"天" in "天道宗" → True）
- 不需要分词，中文关键词直接按字符子串匹配
- YAML 文件中的注释行（`#` 开头）应包含在搜索范围内

## 实体引用分析策略

### 实体类型识别
- **角色**：从 `project_index.yaml` 的 `characters` 段读取实体 ID 和名称
- **世界观实体**：从 `project_index.yaml` 的 `worldbuilding` 段读取
- **地点/势力**：从 `worldbuilding/*.yaml` 的 `索引信息.名称` 字段提取

### 引用链构建
1. **搜索实体名称在所有文件中的出现**
2. **区分引用上下文**：
   - 章节正文中的出现 → "参演"
   - 分纲中的出场角色 → "计划出场"
   - 其他实体档案中的提及 → "关联引用"
   - 自身档案文件 → "本体"
3. **统计引用频率**：按章节/文件计算

### 实体状态推断
- 首次出场章节：引用链中最早的章节
- 最近出场章节：引用链中最晚的章节
- 活跃状态：最近 5 章内有过出场

## 搜索模式与参数组合

| 用户意图 | mode | keyword | scope | 说明 |
|---------|------|---------|-------|------|
| "找一下所有提到天道宗的地方" | search | 天道宗 | all | 全范围搜索 |
| "查查第5章写了什么" | search | — | chapters | 关键词为空时返回章节概览 |
| "林昭在第3章说了什么" | entity-search | 林昭 | chapters | 指定实体+范围 |
| "有哪些角色还没出场" | gap | — | — | 角色使用率分析 |
| "检查设定有没有冲突" | cross-ref | — | — | 交叉引用检测 |

## 搜索性能优化

- 对小项目（<50 文件）：全量扫描，无性能顾虑
- 对中等项目（50-200 文件）：按 scope 缩小范围
- 对大项目（>200 文件）：优先搜索 chapters/，其他目录按需搜索
- 结果截断：默认最多返回 50 条匹配（可通过 max_results 调整）
