# D5. 实体编辑 — 需求发现树

根节点：我读一下当前版本，你看看哪里不符合设想

用于 P13 实体编辑（novel-entity-editor）前置需求发现。仅当修改请求模糊（不含具体字段/方向/值）时触发。
执行前 skill() 上下文中已 read 目标实体文件的完整内容，编排层已注入 `{已有实体摘要}` 和 `{故事背景摘要}`。

```
├── D5.0 现状展示（新增）
│   ├── 当前[实体类型]的核心内容是：
│   │   → [摘要/核心字段列表]
│   ├── 你看了之后，整体感觉怎么样？
│   │   （基本符合/部分不对/完全不对/说不上来）
│   └── 有哪些部分是你觉得OK的，想保留的？

├── D5.1 差异定位（基于 D5.0 展开）
│   ├── [性格/核心特质] 哪方面不对？
│   │   → 强度/倾向/丰富度/与预期反差
│   ├── [背景/经历] 哪里不对？
│   │   → 出身/成长经历/关键事件/动机根源
│   ├── [关系/网络] 和谁的关系不对？
│   │   → 关系类型/亲密度/权力关系
│   ├── [设定/规则] 哪里不合理？
│   │   → 规则本身/等级划分/限制条件
│   └── [其他] 请描述你的设想

├── D5.2 修正方向
│   ├── 你希望改成什么样？（给具体描述/给参考/让我出方案）
│   ├── 改动幅度？（微调/中等改写/大幅调整）
│   └── 有什么是绝对不能动的？

├── D5.3 冲突检查（AI 主动分析，新增）
│   ├── [AI分析] 根据你的描述，我检查了关联实体：
│   │   → 关联角色 xxx：关系网络需要同步更新
│   │   → 第 N 章描写：相关内容需要重写
│   │   → 世界观规则：存在潜在冲突
│   ├── 这些联动影响你知情吗？
│   └── 需要一起处理还是先改目标实体？

└── D5.4 执行决策
    ├── 希望我先出一个修改方案给你看，对比确认后再改？
    └── 还是直接改，改完再 review？
```
