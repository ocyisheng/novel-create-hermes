# note — 灵感记录方法论

## 定位

笔记（NOTE）焦点类型的方法论文档。灵感记录、碎片捕捉、本体论触发的轻量笔记。

## 何时加载

- FOCUS TYPE=note 时自动加载

## 结构由脚本保障

note 类型的 content 最自由——可以是任何结构化或无结构化文本。
`note_type` 字段可选（灵感/笔记），但脚本不强制。

## 创作方法论（需 LLM 判断）

### 灵感记录
最轻量——不需要结构化。核心是"立即记录、之后处理"。

### 本体论核心问题
小说本体不是传递思想或反映现实，而是"一个词在时间中的奇遇"。

自问：我的小说从一个什么"词"开始？这个词展开后能构筑一整个世界吗？
