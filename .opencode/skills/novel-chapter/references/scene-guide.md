# 场景写作指南

从分纲情节点到具体场景的写作技巧参考。

## 五幕场景结构

```
起始（10%）：
  - 场景建立（时间、地点、环境）
  - 人物出场
  - 与前情衔接

行动（30%）：
  - 核心事件发生
  - 人物互动
  - 信息传递

冲突（25%）：
  - 矛盾出现
  - 紧张感建立
  - 角色心理变化

转折（20%）：
  - 情况逆转
  - 新信息出现
  - 决定性行动

结束（15%）：
  - 场景收尾
  - 悬念/过渡
  - 情感基调奠定
```

## 场景要素

### 1. 环境描写

| 要素 | 内容 | 示例 |
|------|------|------|
| 时间 | 季节、天气、昼夜 | 深夜、月圆之夜 |
| 地点 | 场景位置、特点 | 山巅古寺、血色荒原 |
| 氛围 | 情绪、感觉 | 诡异、压抑、热血 |
| 细节 | 标志性物品 | 残碑、孤灯、血迹 |

### 2. 人物状态

```yaml
人物状态:
  人物: [角色名]
  生理状态:
    - 动作: [肢体语言]
    - 表情: [面部变化]
    - 声音: [语调变化]
  心理状态:
    - 情绪: [当前情绪]
    - 想法: [内心活动]
    - 意图: [行动目的]
```

### 3. 感官描写

| 感官 | 描写内容 | 示例 |
|------|----------|------|
| 视觉 | 颜色、光影、形状 | 血红残阳、幽蓝鬼火 |
| 听觉 | 声音、音效、静音 | 脚步声、呼啸声 |
| 嗅觉 | 气味 | 血腥味、梅花香 |
| 触觉 | 温度、质感 | 刺骨寒风、粗糙石壁 |
| 味觉 | 味道（用于回忆/内心） | 苦涩、回甘 |

## 场景类型

### 对话场景

```
结构：
  1. 说话者 + 动作 + 表情
  2. 对话内容
  3. 动作反应

技巧：
  - 用动作代替"说"
  - 对话中夹杂反应
  - 潜台词制造张力
  - 打断制造冲突
```

### 战斗场景

```
结构：
  1. 环境铺垫
  2. 双方对峙
  3. 招式往来（短句）
  4. 关键转折
  5. 结果

技巧：
  - 动作要具体
  - 节奏要快
  - 感官配合
  - 心理描写
```

### 情感场景

```
结构：
  1. 环境渲染
  2. 人物回忆/内心
  3. 情感爆发
  4. 行动表达
  5. 余韵

技巧：
  - 细节触动
  - 对比强化
  - 留白意境
  - 动作代替语言
```

## 场景转换技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 时间跳转 | 直接切换时间 | 「三日后...」「深夜...」 |
| 空间转移 | 地点切换 | 「另一边的战场上...」 |
| 意象承接 | 相同元素过渡 | 从「飘落的雪花」到「花白的头发」 |
| 人物关联 | 通过人物连接 | 「就在张三绝望之际...」 |
| 事件衔接 | 因果关系连接 | 「而在另一边，李四...」 |

### 无缝转场示例

```
原场景结尾：
  月光洒在剑锋上，映出一片寒芒。

新场景开头：
  寒芒闪过，人头落地。

（直接跳转，无需过渡）
```

## 章节检查清单

- [ ] 开篇是否衔接上文？
- [ ] 场景顺序是否合理？
- [ ] 人物状态是否明确？
- [ ] 感官描写是否到位？
- [ ] 节奏变化是否有效？
- [ ] 伏笔是否埋设？
- [ ] 结尾是否有悬念？
