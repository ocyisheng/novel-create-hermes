## 必填字段清单

| 字段路径 | 类型 | 必填 | 说明 |
|---------|------|------|------|
| `索引信息.章节号` | 数字 | 是 | 如 46 |
| `索引信息.所属分卷` | 数字 | 是 | 对应卷号 |
| `摘要.一句话描述` | 字符串 | 是 | ≤30 字 |
| `摘要.出场角色` | 列表 | 是 | 本章出场角色名 |
| `摘要.核心情节点` | 列表 | 是 | ≥2 条 |
| `完整档案.基本信息.字数目标` | 数字 | 是 | 默认 3000 |
| `完整档案.结构规划` | 对象 | 是 | 开篇/发展/转折/收尾 |
| `完整档案.伏笔处理` | 对象 | 是 | 回收/新设/延续 |

## 总纲阶段对应参考

| 总纲阶段 | 章节类型 | 情节点特点 |
|----------|----------|------------|
| 第一幕-建置 | 第1-25%章 | 日常建立、触发事件、跨越门槛 |
| 第二幕-对抗 | 第26-75%章 | 上升行动、中点、失败、灵魂黑夜 |
| 第三幕-解决 | 第76-100%章 | 最终对决、问题解决、回归 |

---

## 情节点设计要点

### 每个章节应包含的情节点类型：

1. **建置阶段**（第一幕）：
   - 日常场景
   - 触发事件
   - 门槛跨越

2. **对抗阶段**（第二幕）：
   - 上升行动
   - 中点转折
   - 失败挫折
   - 灵魂黑夜

3. **解决阶段**（第三幕）：
   - 最终对决
   - 问题解决
   - 回归日常
