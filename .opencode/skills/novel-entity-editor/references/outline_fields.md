# 大纲类实体可编辑字段指南

## 大纲类实体类型

编辑器覆盖 4 种大纲实体：

| 实体类型 | 文件路径 | 有三层结构？ |
|---------|---------|------------|
| outline_synopsis (总纲) | `outline/总纲.yaml` | ❌ 元文档 |
| volume (分卷大纲) | `outline/分卷/卷{N}_{名称}.yaml` | ❌ 元文档 |
| plot_thread (情节线) | `outline/情节线/*.yaml` | ✅ 三层 |
| chapter_outline (分纲) | `outline/分纲/卷{卷号}/第{N}章.yaml` | ✅ 三层 |

---

## 一、总纲 (outline/总纲.yaml)

### 可编辑字段

**基本信息：**
- `项目名称` — 小说标题
- `类型` — 玄幻/都市/科幻/悬疑/仙侠/武侠/历史/言情/奇幻/其他
- `目标字数` — 整数
- `预计章节数` — 整数
- `目标读者` — 男频/女频/混合

**核心概念（高频修改）：**
- `核心概念.一句话概述` — ≤30 字核心卖点
- `核心概念.核心卖点` — 吸引读者的亮点
- `核心概念.主题关键词` — 数组
- `核心概念.主题.核心` — 核心主题
- `核心概念.主题.呈现` — 主题如何呈现

**人物与世界（高频修改）：**
- `人物与世界.主角与世界的关系`
- `人物与世界.主角的特殊性`
- `人物与世界.世界规则对主角的约束`
- `人物与世界.主角打破/利用世界规则的方式`
- `人物与世界.初始境况`

**故事结构（谨慎修改）：**
- `故事结构.结构类型` — 三幕/五幕/自定义（改后需同步修改幕数组）
- `故事结构.幕` — 整个幕数组（含幕号/名称/章节范围/主线/关键节点/主角状态）

**分卷概览：**
- `分卷` — 整个分卷数组

**节奏与结局：**
- `节奏.前期基调/中期基调/后期基调`
- `节奏.章节分布` — 百分比数组
- `结局类型` — 开放式/圆满/悲壮/反转
- `结局设计`

### 联锁影响

修改总纲时，以下关联文件可能需要同步更新：

| 修改内容 | 影响 |
|---------|------|
| 修改 `项目名称` | 所有文件路径、config.yaml、索引 |
| 修改卷数或章节范围 | `outline/分卷/` 下的所有文件 |
| 修改幕结构 | 各分卷的 `所属阶段` 字段 |
| 修改主角设定 | `characters/` 下的角色档案 |

## 二、分卷大纲 (outline/分卷/卷{N}_{名称}.yaml)

### 可编辑字段

- `卷信息.卷名` — 显示名
- `卷信息.章节范围` — 字符串
- `卷信息.时间跨度` — 字符串
- `卷信息.核心冲突` — ≤50 字
- `叙事任务` — 3-5 条字符串数组
- `主角状态.起点/终点/年龄`
- `微弧分割` — 整个微弧数组（2-4 个微弧，每弧含章节范围/核心事件/高潮）
- `POV分布` — POV 角色列表
- `间奏章节` — 列表
- `关键事件清单` — 按类型分类
- `角色发展` — 列表
- `本卷节奏.整体基调/情感曲线`
- `卷末钩子` — 下卷悬念

### 不可修改字段
- `卷信息.卷号` — 唯一标识，与文件名一致

### 编辑技巧

- **微弧分割**是最常修改的区域。修改时保持 2-4 个微弧，每个微弧有明确的起始/结束事件
- **叙事任务**修改后应检查 `outline/分纲/` 下的对应章节分纲是否仍满足任务
- 修改卷的章节范围后，需要通知编排层更新 `config.yaml` 和 `project_index.yaml`

## 三、情节线 (outline/情节线/{主线|支线_名称}.yaml)

### 可编辑字段

**索引+摘要层：**
- `索引信息.名称` — 显示名
- `索引信息.类型` — main / sub / character_arc
- `索引信息.状态` — active / resolved / on_hold
- `摘要.一句话描述` — ≤30 字
- `摘要.当前境况` — ≤50 字
- `摘要.核心特质` — ≤5 个关键词
- `摘要.当前目标`
- `摘要.关键关系`
- `摘要.当前区间` — 如 "拍卖会篇（44-48章）"
- `摘要.区间情节点`
- `摘要.关联角色`

**完整档案：**
- `完整档案.描述` — 100-200 字概述
- `完整档案.类型` — 主线/支线/事件链
- `完整档案.冲突核心`
- `完整档案.关键事件` — 事件链数组（最常修改）
- `完整档案.关联支线`
- `完整档案.终局设计`
- `完整档案.伏笔清单.已埋伏笔/待回收伏笔`
- `完整档案.角色参与.涉及角色/角色推动作用`
- `完整档案.创作笔记.注意事项/节奏提示`

### 不可修改
- `_meta` 层全部（entity_type, schema_version, created_at）
- `索引信息.实体ID` — 唯一标识
- `索引信息.起始章节` — 首次出现章节
- `索引信息.当前章节位置` — 自动维护

### 编辑注意事项

1. **状态切换**: 将 active 改为 resolved/on_hold 时，检查相关伏笔是否已回收
2. **关键事件**: 增删事件节点后，时间线逻辑应保持连贯
3. **关联支线**: 修改关联支线列表时，目标支线的关联列表也应更新

## 四、分纲 (outline/分纲/卷{卷号}/第{N}章.yaml)

### 可编辑字段

**索引+摘要层：**
- `索引信息.名称` — 显示名（如"第46章"）
- `索引信息.状态` — draft / writing / complete
- `摘要.一句话描述` — ≤30 字
- `摘要.当前境况` — ≤50 字
- `摘要.核心特质` — ≤5 个关键词
- `摘要.当前目标`
- `摘要.关键关系`
- `摘要.出场角色` — 角色名列表
- `摘要.核心情节点` — 关键情节点（≤5 条）
- `摘要.关键转折` — boolean

**完整档案（最常修改的区域）：**
- `完整档案.基本信息.章节名/类型/字数目标`
- `完整档案.结构规划.开篇/发展/转折/收尾` — 场景结构
- `完整档案.情节点` — 场景列表
- `完整档案.出场角色` — 含角色名+状态+场景作用
- `完整档案.伏笔处理.回收伏笔/新设伏笔/延续伏笔`
- `完整档案.时间线事件`
- `完整档案.涉及地点`
- `完整档案.情感节奏.情感基调/高潮点`
- `完整档案.世界观补充`
- `完整档案.写作笔记.注意事项`

### 不可修改
- `_meta` 层全部
- `索引信息.实体ID` — 如 "chapter_46"
- `索引信息.章节号` — 整数序号
- `完整档案.基本信息.实际字数` — 由 auto_update.py 维护

### 编辑注意事项

- **出场角色增减**: 增删角色后应运行 `validate_entity_consistency.py` 检查角色状态一致性
- **结构规划修改**: 开篇方式从"场景切入"改为"悬念"，应检查上章衔接
- **伏笔处理**: 新增/回收伏笔后应同步更新 `outline/追踪/伏笔.yaml`
- **时间线事件**: 事件时间点应与其他章节一致
