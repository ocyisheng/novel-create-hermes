# world_rule — 世界观建设方法论

## 定位

世界观规则（WORLD_RULE）焦点类型的方法论文档。世界建构、规则设定、自洽性设计。

## 何时加载

- FOCUS TYPE=world_rule 时自动加载

## 结构由脚本保障

V2 项目中世界观规则直接创建为 `WORLD_RULE` 叙事单元，无需模板文件。
content JSON 的 `子类型` 字段必填，脚本会校验。

## 创作方法论（需 LLM 判断）

### 方法论选择
| 路径 | 适用 | 方式 |
|------|------|------|
| **体系化建置** | 玄幻、西幻、科幻 | 按10个模板输出完整体系 |
| **笔记传统** | 现实主义、文艺向 | 散点随笔，随闻随记，不设检索方式。这不是体系化的替代品，是与体系化平起平坐的本体论选择 |
| **混合方案** | 多数长篇 | 宏观架构体系化 + 微观细节笔记 |

### 自洽性标准
判断标准："在这个世界里它是否自洽"——不是在现实中是否可能。
区分"开放区的矛盾"（刻意保留的洪荒/未知）与"粗心的矛盾"（失误）。

### 延迟创建
核心设定（力量体系、基本规则）早些完成；扩展设定（经济体系、政治制度）写到需要时再补。
