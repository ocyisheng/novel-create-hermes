# note — 总纲/叙事策略/灵感记录方法论

## 结构由脚本保障

note 类型的 content 最自由——可以是任何结构化或无结构化文本。
`note_type` 字段可选（总纲/叙事策略/灵感/笔记），但脚本不强制。

## 创作方法论（需 LLM 判断）

### 总纲的核心决策
- **人物与世界的关系**：主角怎么进入这个世界？他有什么特殊？什么规则限制他？他怎么突破？
- **故事结构**：三幕/五幕/自定义——每幕的核心主线是什么
- **节奏**：前期/中期/后期基调，结局类型（开放式/圆满/悲壮/反转）

### 叙事策略的核心决策
- **视角**：谁在看这个故事？第一人称还是第三人称？限制还是全知？切换规则？
- **信息分配**：哪些信息让读者先知道（戏剧反讽）？哪些要藏到最后一刻？
- **笔法**：冷笔用于动作/紧张/信息传递，热笔用于情感高潮/内心独白

### 灵感记录
最轻量——不需要结构化。核心是"立即记录、之后处理"。
