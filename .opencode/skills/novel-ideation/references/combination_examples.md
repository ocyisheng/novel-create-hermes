 约束组合示例

## 玄幻约束组合

```
1. 【角色约束】主角天赋极差，靠系统逆袭
2. 【设定约束】修为有代价（失去亲情/记忆/人性）
3. 【内容约束】反派有令人同情的动机
```

## 科幻约束组合

```
1. 【设定约束】所有科技必须有科学依据
2. 【结构约束】多线叙事（科技线、政治线、伦理线）
3. 【主题约束】探讨科技对社会的冲击
```

## 悬疑约束组合

```
1. 【结构约束】单一视角，利用视角欺骗读者
2. 【形式约束】非线性叙事，打乱时间线
3. 【内容约束】案件背后是社会问题
```

## 最佳实践

### 选择约束原则
1. **匹配类型**: 根据小说类型选择合适约束
2. **适度挑战**: 约束要有挑战性但可执行
3. **激发创新**: 善用反转、融合类约束
4. **用户喜好**: 考虑用户的偏好和限制

### 组合建议
1. 结构约束通常作为基础
2. 内容约束提供创新点
3. 角色约束增强故事动力
4. 设定约束创造独特世界
5. 形式和主题约束营造特色
