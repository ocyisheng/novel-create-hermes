# 焦点类型：scene — 场景/章节写作指南

## 适用任务

| 路由映射 | 描述 |
|---------|------|
| 写第N章 | 生成章节正文 |
| 分卷大纲 | 设计一卷的整体结构 |
| 分纲/章节大纲 | 设计单章的详细分纲 |

## 章节正文输出规范

章节正文写入 `chapters/第{N}章.txt`，纯文本格式。同时在 graph 中创建 CHUNK 单元。

质量标准（取决于 WRITING MODE）：
- draft：追求完稿速度和叙事流畅，风格可宽松
- polish：逐句精修，风格一致性严格
- rewrite：根据检测报告定向修复

## 分纲（chapter）设计要点

分纲不是扁平的情节点罗列，而是结构化创作蓝图。

**索引层（必填）：**
- 实体ID、名称、章节号、所属分卷、状态、字数

**摘要层（必填）：**
- 一句话描述(≤30字)：本章讲什么
- 当前境况(≤50字)：本章在情节中的位置
- 故事时间、时间跨度
- 核心特质(≤5)、当前目标、关键关系
- 出场角色、核心情节点(≤5)、关键转折

**完整档案（创作时填写）：**
- 章节类型：推进/过渡/高潮/结局/转折/收尾
- 结构规划：开篇方式/上章衔接 → 发展核心冲突 → 转折事件 → 收尾结果/下章铺垫
- **场域规划**（替代扁平情节点）：每个场域包含——
  - 场域名、POV角色、持续时间（预期字数）
  - 功能：信息/冲突/角色塑造/转折/铺垫
  - 氛围：情感基调 + 感官锚点(3-5个) + 环境要素
  - 节奏控制：开场张力1-10 / 中场张力1-10 / 高潮张力1-10 / 笔法（冷笔/热笔/对话/叙述混合）
  - 对话规划（可选）：密度/关键节拍/潜台词
  - 进入方式、退出方式
  - 涉及角色、出场角色状态
  - 默认每章 3-5 个场域
- **张力曲线**：开场/第一场域高潮/中点转折/章节高潮/结尾（均1-10）+ 下章悬念
- **对话规划**（可选）：对话节拍/意图/要点 + 声线提醒 + 潜台词提示
- 出场角色：角色名/状态/场景作用
- 伏笔处理：回收伏笔/新设伏笔/延续伏笔
- 涉及地点、情感节奏、世界观补充

**松散度的正当性：**
- 间奏章节（非推进型）可以存在——"专在无事中生事"是书场美学
- 张力曲线不必追求完美抛物线。张力推进章追求效率，间奏章允许散漫闲笔

## 分卷大纲（volume）设计要点

**必填字段：**
- 卷信息：卷号、卷名、所属阶段、章节范围、时间跨度、核心冲突(≤50字)
- 叙事任务：3-5条本卷必须完成的叙事目标
- 主角状态：起点/终点/年龄
- **微弧分割**：2-4个微弧，每弧含章节范围、核心事件、高潮
- POV分布：主视角范围 + POV角色列表（角色/类型/章节/功能）
- 间奏章节：非推进主线的回忆/风景/情感/战场间隙
- 关键事件清单：按类型分类（军事/政治/经济/情报）
- 角色发展：每个角色在本卷内的弧线
- 本卷节奏：整体基调、情感曲线
- 卷末钩子

## 写作要点

1. **前章衔接**：从同一场景/情绪自然延续，"只是生活细节"的事让读者停留
2. **角色自动性**：如果角色开始做你没想到的事，区分"文势所逼"（好）与"粗暴干预"（差）
3. **速度感**：真正的速度感来自角色意志碰撞，不是外力强加的节奏表。慢节奏来源于角色意志（好）还是啰嗦（差）
4. **语言尸体**：逐句检查——"暮色从四面八方袭来"是尸体，"光线从窗帘边缘挤进来"可能是观察
5. **伏笔**：不必全部"兑现"。支持精准型/落空型/误解型/悬置型四种回收方式
6. **章尾钩子**：不限于因果驱动——可以是一个意象/词语的回落
