# 章节写作技法指南

本文件为 novel-chapter 技能提供具体写作技法指导，覆盖视角管理、对话设计、自由间接引语、象征运用、冷热笔法五个核心维度。

---

## 1. 视角管理（POV）

### 1.1 视角类型与适用场景

| 视角类型 | 特征 | 适用场景 | 网文常见度 |
|---------|------|---------|-----------|
| **第一人称** | "我"的视角，信息受限于叙述者感知 | 悬疑/惊悚/代入感强的类型 | 中等 |
| **第三人称限制** | 跟随单一角色的感知，但用"他/她"叙述 | 网文主流，兼顾亲密感和灵活性 | 最高 |
| **第三人称全知** | 叙述者知道所有角色的想法 | 史诗/群像/需要宏观视角 | 较低 |
| **客观视角** | 只描写外在行为，不进入任何角色内心 | 动作场景/电影化叙事 | 低 |

### 1.2 视角切换规则

**硬约束**：
- 同一场景内禁止切换视角（场景 = 连续时间 + 连续空间）
- 切换必须通过场景分隔（空行 + 时间/空间转换标记）
- 每章最多切换 2 次视角（网文阅读习惯）

**切换标记**：
```
---  （场景分隔线）

（时间转换）三天后 / 黄昏时分 / 次日清晨

（空间转换）与此同时 / 另一边 / 远在千里之外
```

### 1.3 视角锚定检查

写作时自检：
- [ ] 本章的视角锚定角色是谁？（分纲中已定义）
- [ ] 是否描写了锚定角色不可能知道的信息？
- [ ] 是否进入了非锚定角色的内心？
- [ ] 视角切换是否有明确的场景分隔？

### 1.4 常见错误

| 错误类型 | 示例 | 修正 |
|---------|------|------|
| 视角越界 | "林逸不知道的是，王长老正在密室中谋划..."（第三人称限制中） | 改为林逸视角可感知的内容 |
| 隐形全知 | "张三心想...同时李四也在想..." | 选择一个角色锚定 |
| 视角漂移 | 段落开头是林逸视角，结尾变成旁观者视角 | 保持锚定角色的感知边界 |

## 2. 对话设计

### 2.1 对话的功能性

每段对话必须承载至少一个功能：

| 功能 | 说明 | 示例 |
|------|------|------|
| **推进情节** | 对话导致事件发生 | "我们今晚就行动。" → 触发行动计划 |
| **揭示性格** | 通过说话方式体现角色 | 暴躁角色："废话少说，直接上！" |
| **营造氛围** | 对话建立场景情绪 | 低语："嘘...他们来了。" → 紧张感 |
| **传递信息** | 交代背景/设定（慎用） | "你是说，那个禁地已经有三百年没人进去过了？" |
| **制造冲突** | 角色之间的分歧/对抗 | "你根本不懂！" "那你教我啊？" |

### 2.2 对话节奏

**长短交替**：
```
短句（紧张/冲突）：
"走。"
"去哪？"
"别问。"

长句（舒缓/解释）：
"这个地方是我小时候常来的，那时候爷爷还在，每年夏天都会带我到这棵老槐树下乘凉。"
```

**乒乓球式问答**（避免连续超过 5 轮无动作插入）：
```
❌ 不好：
"你来了。"
"嗯，来了。"
"坐吧。"
"好。"
"喝点什么？"
"都行。"

✅ 好：
"你来了。" 他头也不抬，继续擦着手中的刀。
"嗯。" 她在他对面坐下，目光扫过桌上的地图，"计划改了？"
```

### 2.3 潜台词

角色说的 ≠ 角色想的。好的对话有表面意思和深层意思。

```
表面："你最近挺忙的。"
深层：（你怎么都不来找我）

表面："我没事。"
深层：（我有事，但不想说）

表面："随便你。"
深层：（我很生气，但不想吵架）
```

### 2.4 方言/口音

通过对话体现角色背景，但要节制：
- 老人角色："老朽"、"且慢"、"这事儿嘛..."
- 少年角色："靠"、"牛逼"、"整！"
- 文人角色："此言差矣"、"容在下思量"
- 江湖角色："阁下"、"承让"、"后会有期"

## 3. 自由间接引语

### 3.1 定义

自由间接引语（Free Indirect Discourse）是第三人称叙述中融入角色的思想和语言风格的技法。

**三种叙述模式对比**：

| 模式 | 示例 | 效果 |
|------|------|------|
| **直接引语** | 他想："完了，这下死定了。" | 距离感强，像引用 |
| **间接引语** | 他想，这下完了，死定了。 | 距离适中，但略显平淡 |
| **自由间接引语** | 完了。这下死定了。他看着越来越近的黑影，腿开始发软。 | 亲密感强，角色声音融入叙述 |

### 3.2 使用场景

- **情感高潮**：角色情绪激动时，用自由间接引语让读者"进入"角色
- **紧张时刻**：动作场景中，用角色的感知碎片加速节奏
- **内心独白**：避免"他想"、"她觉得"等标记词，直接呈现角色思维
- **幽默/讽刺**：通过角色的偏见/误解制造反讽

### 3.3 示例

```
第三人称限制 + 自由间接引语：

剑光劈来。他侧身闪避，脚下却踩到一块松动的石板。
完了。
身体失去平衡的瞬间，他看到对方嘴角浮现一丝笑意。
不能倒。他咬牙稳住身形，反手一剑刺出。
管他呢，拼了。
```

### 3.4 注意事项

- 不要过度使用，否则变成意识流
- 保持视角锚定——只能融入锚定角色的思想
- 切换回客观叙述时要有明确标记（动作、对话）

## 4. 象征与意象

### 4.1 象征的选择原则

- **自然融合**：象征物必须是故事世界中的自然元素，不能突兀
- **主题呼应**：象征物与小说主题有内在联系
- **节制使用**：一个核心意象反复出现 > 多个意象分散出现
- **避免说破**：不要在文中解释"这个象征了..."

### 4.2 网文中的常见象征

| 象征物 | 可能含义 | 使用场景 |
|--------|---------|---------|
| 断剑 | 失败/传承/牺牲 | 角色低谷/回忆 |
| 老树 | 生命力/根/传承 | 家族/宗门/故乡 |
| 雨/雪 | 悲伤/洗涤/转折 | 情感场景/转折点 |
| 火焰 | 希望/愤怒/重生 | 战斗/觉醒 |
| 镜子 | 自我认知/真相 | 内心戏/揭秘 |
| 门/窗 | 选择/机遇/分界 | 转折/门槛跨越 |

### 4.3 示例

```
❌ 直白象征（不好）：
那把断剑象征着他破碎的心。

✅ 隐含象征（好）：
他蹲下身，从废墟中捡起那把断剑。
剑身上的裂纹像极了他此刻的心情——曾经锋利，如今残破。
他握紧剑柄，站起身。
也许，该找个铁匠了。
```

## 5. 冷笔与热笔

### 5.1 定义

| 笔法 | 特征 | 适用场景 |
|------|------|---------|
| **冷笔** | 客观克制、节奏快、短句为主、少修饰 | 动作场景/紧张时刻/信息传递 |
| **热笔** | 情感充沛、节奏慢、长句为主、多感官描写 | 情感高潮/内心独白/氛围营造 |

### 5.2 切换技巧

**冷→热**（情感升温）：
```
冷笔：
剑光闪过。他侧身，拔剑，格挡。三招一气呵成。

热笔（切换）：
对手退后三步，喘着粗气。月光从窗棂间洒落，照在他苍白的脸上。
这张脸...他突然想起了什么。是那年冬天，在城门口卖馒头的老妇人。
她也有这样一双眼睛，浑浊，却透着不甘。
```

**热→冷**（情感收束）：
```
热笔：
泪水模糊了视线。父亲临终前的话在耳边回响——"活下去"。他跪在地上，双手深深陷入泥土。

冷笔（切换）：
他站起身。擦干脸上的泥和泪。
远处传来马蹄声。
该走了。
```

### 5.3 段落长度控制

| 笔法 | 段落长度 | 句子结构 |
|------|---------|---------|
| 冷笔 | 短段落（1-3句） | 短句、动词优先 |
| 热笔 | 长段落（4-8句） | 长句、形容词/副词丰富 |

### 5.4 网文节奏建议

- **章节开头**：冷笔切入（快速进入场景）
- **章节中段**：冷热交替（维持张力）
- **情感高潮**：热笔（让读者沉浸）
- **章节结尾**：冷笔收束 + 悬念钩子（让人想翻下一页）

## 6. 综合自检清单

写作完成后，按以下维度自检：

### 视角
- [ ] 视角锚定角色与分纲一致
- [ ] 无视角越界（未描写锚定角色不可能知道的信息）
- [ ] 视角切换有明确场景分隔

### 对话
- [ ] 每段对话至少承载一个功能
- [ ] 无连续 5 轮以上的纯对话（有动作/描写插入）
- [ ] 对话体现角色性格差异

### 笔法
- [ ] 冷热笔法有变化，不是一平到底
- [ ] 动作场景以冷笔为主
- [ ] 情感高潮有热笔渲染

### 象征
- [ ] 核心意象与主题呼应
- [ ] 象征物自然融入故事世界
- [ ] 未直接解释象征含义

### 自由间接引语
- [ ] 情感高潮处有使用（可选）
- [ ] 使用时保持视角锚定
- [ ] 未过度使用导致意识流
