# 节奏分析示例

## 分析维度表

| 分析项 | 描述 |
|---|---|
| 节奏类型 | 快节奏/中节奏/慢节奏 |
| 高潮频率 | 每10章的高潮点数量 |
| 高潮强度 | 每次高潮对故事走向的影响程度 |
| 情感曲线 | 愉悦度/紧张度/好奇度的变化 |

### 疲劳点检测

| 检测项 | 描述 |
|---|---|
| 节奏疲劳 | 连续慢节奏导致的阅读疲劳 |
| 信息疲劳 | 信息密度过低导致的无聊感 |
| 情感疲劳 | 情感渲染过度的反感 |

## 节奏分析报告示例

```yaml
节奏分析报告:
  分析时间: "2026-05-05 14:00"
  分析范围: "第1-50章"

  节奏分布:
    快节奏: "第1-5章, 第12-15章, 第30-35章"
    中节奏: "第6-11章, 第16-29章, 第36-45章"
    慢节奏: "第46-50章"

  高潮分布:
    总高潮数: 5
    分布评估: "前期密集，后期稀疏"
    问题: "第30章后无重要高潮"

  疲劳点:
    - 位置: "第46-50章"
      类型: "节奏疲劳"
      描述: "连续5章慢节奏，无重要事件"
      严重程度: "重要"
      优化建议: "增加第47章冲突事件"

  情感曲线:
    愉悦度: "第1-10章高，第11-20章下降，第21-35章回升，第36-50章低迷"
    紧张度: "第5章、第15章、第35章出现峰值"
    好奇度: "整体维持良好，第25章后下降"

  优化建议优先级:
    - 优先级1: "增加第47章冲突事件，打破慢节奏"
    - 优先级2: "优化第25章钩子，维持好奇度"
    - 优先级3: "第46-50章增加信息密度"
```

## 节奏类型判断标准

### 快节奏特征
- 信息密度高（每千字包含2+关键事件）
- 对话占比高（>40%）
- 动作描写密集
- 句子较短

### 中节奏特征
- 叙事与描写平衡
- 有铺垫和过渡
- 情感与事件交错

### 慢节奏特征
- 描写细腻（环境/心理）
- 信息密度低
- 铺垫章节
- 长句为主

## 高潮分布问题诊断

| 问题类型 | 表现 | 解决方案 |
|----------|------|----------|
| 高潮过密 | 连续3章以上高潮 | 增加缓冲章节 |
| 高潮过疏 | 10章以上无高潮 | 增加小高潮 |
| 高潮失衡 | 前期高潮多，后期少 | 重新规划分布 |
| 高潮乏力 | 高潮无实质推进 | 强化高潮转折 |
