```yaml

## 角色弧线 YAML 示例

```yaml
角色弧线:
  角色ID: ARC_001
  角色名: "林默"
  
  弧线类型: "成长型"
  
  起始状态:
    心理: "懵懂无知，只想过安稳日子"
    能力: "炼气期，基础剑法"
    关系: "孤独，只有村长照顾"
  
  转折事件:
    - 事件: "父母死亡真相揭露，宗门黑幕曝光"
      时间: "第50章"
      变化: "从服从到反抗，从信任到怀疑"
    - 事件: "古玉觉醒，获得上古传承"
      时间: "第30章"
      变化: "实力大增，但被正道追杀"
  
  最终状态:
    心理: "坚定自信，明确自己的道"
    能力: "元婴期，噬灵剑道"
    关系: "与宗门决裂，建立新秩序"
  
  主题关联: "成长与反抗，在绝境中寻找第三条路"
```

## 字段说明

| 层级 | 字段 | 说明 |
|------|------|------|
| _meta | entity_type | 固定值 `"character"` |
| _meta | schema_version | 契约版本 `"3.0"` |
| 索引信息 | 实体ID / 名称 / 别名/外号 / 角色类型 / 势力 / 状态 | 用于 project_index.yaml 索引 |
| 摘要 | 一句话描述 / 当前境况 / 核心特质 / 当前目标 / 关键关系 | AI 写章节时只加载此层（≤5个字段） |
| 完整档案 > 基本信息 | 性别 / 年龄 / 身份 / 外貌 / 服饰风格 | |
| 完整档案 > 性格 | 核心特质 / 优点 / 缺点 / 价值观 / 口头禅 / 语气风格 | |
| 完整档案 > 背景 | 出身 / 成长经历(\|) / 关键事件 / 心理创伤(\|) / 动机根源(\|) | `|` 标注字段必须用 YAML block scalar |
| 完整档案 > 目标与冲突 | 公开目标 / 隐藏目标 / 内心渴望 / 核心恐惧 / 主要障碍 | |
| 完整档案 > 能力设定 | 技能专长 / 天生才能 / 能力限制 / 成长潜力 | |
| 完整档案 > 关系网络 | 家人 / 师门 / 朋友 / 敌人 / 恋人 / 其他关系 | 每项含角色、关系类型、关系状态、关键事件 |
| 完整档案 > 角色弧线 | 起始状态(\|) / 成长阶段 / 关键转变(\|) / 最终状态(\|) | |
| 完整档案 > 与主线关系 | 主线参与度 / 对主线影响 / 主线对其影响 | |
| 完整档案 > 创作笔记 | 注意事项(\|) / 避免踩坑 / 扩展建议(\|) | |
