# 创意生成工具

本技能包含的工具方法。


## 1. 约束组合引擎

**功能**：评估约束的化学反应度

**使用方法**：
```yaml
输入:
  - 约束A: "系统流"
  - 约束B: "身份反转"
输出:
  组合建议: "系统与身份的隐藏身份绑定"
  化学反应度: 8.5
```

---

## 2. 创意评价算法

**功能**：基于4维度自动评分

**评分维度**：
| 维度 | 说明 | 权重 |
|------|------|------|
| 创意性 | 独特程度 | 25% |
| 可读性 | 吸引力 | 25% |
| 完整性 | 自洽程度 | 25% |
| 市场潜力 | 受众范围 | 25% |

**使用方法**：
```yaml
输入: 创意概念
输出:
  综合评分: 7.5
  各维度分数: [...]
  改进建议: [...]
```

---

## 3. 元素重组数据库

**功能**：提供创意元素的随机组合

**元素分类**：
- 题材元素：修仙、都市、科幻、悬疑...
- 设定元素：系统、灵气、魔法、科技...
- 身份元素：弟子、王者、凡人、穿越者...
- 冲突元素：复仇、争夺、生存、真相...

**使用方法**：
```yaml
输入: 随机组合
输出: 组合结果列表
```

---

## 4. 创意模板库

**功能**：存储已验证的创意范式

**模板类型**：
- 经典模板（如《斗破苍穹》系统流）
- 创新模板（如《诡秘之主》克苏鲁+蒸汽）
- 融合模板（多元素组合）

**使用方法**：
```yaml
输入: 模板需求
输出: 匹配模板列表
```
