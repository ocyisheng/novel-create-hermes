 4维度评估矩阵

## 1. 原创性 (Originality, 0-5分)

**评估标准**: 概念的新颖程度和创造性
```
5分 - 前所未见的全新概念
4分 - 已有概念的显著创新组合
3分 - 基本概念的适度创新
2分 - 轻度调整的传统概念
1分 - 明显的套路化设定
0分 - 完全复制已有概念
```

## 2. 可行性 (Feasibility, 0-5分)

**评估标准**: 概念的可执行度和实现难度
```
5分 - 清晰且易于执行的概念
4分 - 思路清晰但有适度挑战
3分 - 概念尚可但实现较复杂
2分 - 概念模糊执行难度大
1分 - 概念混乱难以实现
0分 - 完全不可行的概念
```

## 3. 吸引力 (Attractiveness, 0-5分)

**评估标准**: 对目标读者的吸引程度
```
5分 - 一眼就有强烈阅读冲动
4分 - 有明确兴趣点吸引读者
3分 - 有兴趣但不够突出
2分 - 吸引力一般需要改进
1分 - 平淡无吸引力
0分 - 完全无吸引力
```

## 4. 独特性 (Uniqueness, 0-5分)

**评估标准**: 在当前市场上的差异化程度
```
5分 - 市场上独一无二的存在
4分 - 有显著区别于同类的特色
3分 - 有自身特点但不够突出
2分 - 同质化较严重
1分 - 高度同质化
0分 - 完全复制现有作品
```
