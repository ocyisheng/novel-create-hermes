# 小说类型快速参考手册

本手册提供5大主流小说类型的核心信息快速查询。

## 1. 玄幻/修仙 (Fantasy)

### 一句话定义
**东方幻想修炼故事**，主角通过修炼获得力量，在修真界中成长、冒险、争霸。

### 核心三要素
1. **修炼体系** - 等级分明的力量系统（练气→筑基→金丹...）
2. **资源体系** - 灵石、丹药、功法、法宝等升级资源
3. **世界观** - 修真界、凡人界、仙界的多层次世界

### 典型读者期待
- 明确的等级提升和实力变化
- 精彩的战斗和功法对决
- 天地异宝和秘境探索
- 正邪对抗和门派斗争

### 创作检查清单
- [ ] 修炼体系是否清晰严谨？
- [ ] 主角成长是否有合理支撑？
- [ ] 世界各势力是否有差异化？
- [ ] 正邪对抗是否有深度？
- [ ] 是否有创新点突破套路？

---

## 2. 科幻/星际 (Sci-Fi)

### 一句话定义
**基于科学原理的未来幻想**，探索科技发展、宇宙文明和人类未来的可能性。

### 核心三要素
1. **科技设定** - 合理推测的先进技术
2. **文明建构** - 多元宇宙文明和价值观
3. **哲学思考** - 科技对人性、社会的影响

### 典型读者期待
- 逻辑严谨的科技设定
- 宏大震撼的宇宙图景
- 深刻的社会与人性探讨
- 出人意料又合理的反转

### 创作检查清单
- [ ] 科技设定是否合理（至少伪科学解释）？
- [ ] 不同文明是否有根本性差异？
- [ ] 是否有超越猎奇的思想深度？
- [ ] 时间线、因果逻辑是否严谨？
- [ ] 是否避免了过于拟人化的外星文明？

---

## 3. 都市/异能 (Urban Fantasy)

### 一句话定义
**现代都市背景下的超现实故事**，超能力者在现实与超自然之间平衡。

### 核心三要素
1. **现实基础** - 现代都市的真实感
2. **超能力体系** - 清晰的超能力规则和代价
3. **社会融合** - 超能力对现实社会的影响

### 典型读者期待
- 熟悉的现代都市环境
- 酷炫但有限制的超能力
- 超能力者的现实困境
- 表面世界下的秘密战争

### 创作检查清单
- [ ] 超能力是否有明确规则和代价？
- [ ] 现实社会对超能力反应是否合理？
- [ ] 主角身份转变是否有足够挣扎？
- [ ] 组织架构和势力平衡是否合理？
- [ ] 是否避免了无限开挂和力量体系崩坏？

---

## 4. 悬疑/推理 (Mystery)

### 一句话定义
**围绕谜题展开的逻辑游戏**，通过调查和推理揭示真相。

### 核心三要素
1. **谜题核心** - 吸引人的案件或秘密
2. **逻辑推理** - 从线索到真相的合理过程
3. **反转技巧** - 出人意料又合理的转折

### 典型读者期待
- 足够吸引人的谜团核心
- 公平的线索和推理过程
- 精彩的反转和真相揭露
- 深入的角色心理刻画

### 创作检查清单
- [ ] 是否在公平原则下给出线索？
- [ ] 真相揭露是否合乎逻辑且意外？
- [ ] 每个嫌疑人是否有足够动机和表现？
- [ ] 推理过程是否严密无漏洞？
- [ ] 反转是否避免了生硬和牵强？

---

## 5. 历史/穿越 (Historical/Time Travel)

### 一句话定义
**历史背景下的文化碰撞故事**，现代与古代的交汇融合。

### 核心三要素
1. **历史依据** - 真实或可信的历史背景
2. **文化碰撞** - 不同时代价值观的冲突
3. **生活细节** - 符合时代的生活方式和思维

### 典型读者期待
- 真实可感的历史氛围
- 古代生活的生动细节
- 现代与古代的智慧碰撞
- 对历史的尊重和创新解读

### 创作检查清单
- [ ] 重要历史事件和人物是否准确？
- [ ] 时代细节（服饰、礼仪、言语）是否考据？
- [ ] 穿越者适应古代的过程是否合理？
- [ ] 现代知识应用是否有时代局限性？
- [ ] 是否避免了过度篡改历史和现代优越感？

## 类型诊断工具

### 你的类型倾向测试
1. **问题1**: 你更关注故事的哪个方面？
   - A. 力量体系和成长路线 → **玄幻/都市**
   - B. 逻辑严谨和思想深度 → **科幻/悬疑**
   - C. 文化细节和时代氛围 → **历史**
   - D. 现实共鸣和社会批判 → **都市**

2. **问题2**: 你更擅长哪种描写？
   - A. 战斗和技能对决 → **玄幻**
   - B. 科技设定和宇宙想象 → **科幻**
   - C. 心理活动和推理过程 → **悬疑**
   - D. 日常生活和社会观察 → **都市/历史**

3. **问题3**: 你希望读者获得什么体验？
   - A. 畅快的升级感和成就感 → **玄幻**
   - B. 思想震撼和惊奇感 → **科幻**
   - C. 智力挑战和解谜快感 → **悬疑**
   - D. 情感共鸣和文化体验 → **都市/历史**

### 类型推荐矩阵
```
强逻辑性 + 弱情感性 = 科幻/悬疑
强情感性 + 弱逻辑性 = 玄幻/都市
强细节性 + 强逻辑性 = 历史/科幻
强调动性 + 弱系统性 = 玄幻/都市
```

## 类型创新指南

### 各类型的创新空间
1. **玄幻**: 修炼体系创新、世界观融合、反套路设计
2. **科幻**: 科技观念突破、文明形态创新、哲学深度
3. **都市**: 社会问题结合、能力体系创新、结构实验
4. **悬疑**: 叙事方式革新、谜题类型创新、心理深度
5. **历史**: 历史视角创新、穿越机制设计、文化解读

### 跨类型创新方案
- 玄幻+科幻 → **科学修仙**（用物理解释灵气）
- 都市+悬疑 → **超能力探案**（超能力者解决超自然案件）
- 历史+科幻 → **古代科技革命**（低科技水平下实现科幻概念）
- 玄幻+都市 → **现代修真**（修真体系在现代社会运行）
- 悬疑+科幻 → **科技悬疑**（高科技背景下的逻辑游戏）
