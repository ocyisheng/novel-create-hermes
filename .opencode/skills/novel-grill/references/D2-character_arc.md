# D2. 角色创建/编辑 — 需求发现树

根节点：你想要一个什么样的角色？

用于 focus_type=character_arc（角色创建/编辑）前置需求发现。Grill 通过 novel-tool 自行查询已有角色列表和故事背景。

```
├── D2.0 故事背景锚定（新增，已有角色时自动展示）
│   ├── 根据设定，这个角色大概在故事什么位置？
│   ├── 目前已创建的角色：[列表]
│   └── 这个角色和已有角色有关系吗？

├── D2.1 角色定位
│   ├── 这个角色在故事中负责推动哪部分剧情？
│   │   （主线核心/支线补充/关系张力/气氛调节）
│   ├── 角色大致是个什么样的人？（年龄/性别）
│   │   → 社会身份：职业/阶层/所属势力
│   │   → 出身背景：家庭/成长环境/来处
│   └── 这个角色最吸引人的地方是什么？
│       （成长逆袭/神秘感/反差萌/读者共鸣）

├── D2.2 性格与动机
│   ├── 性格偏向哪边？
│   │   （话多还是话少？做事靠逻辑还是直觉？偏执固执还是挺随意？）
│   ├── 角色行动的最大动力是什么？（复仇/守护/求知/权力/情感/生存）
│   ├── 性格上有什么弱点或缺陷？
│   ├── 角色内心最深处的恐惧是什么？
│   └── 角色有什么死也不想让人知道的秘密？（可跳过）

├── D2.3 关系网
│   ├── 与[已有角色]的关系定位？
│   ├── 有预设的 CP 或对立关系吗？
│   └── 有哪些必须建立的关系线？

├── D2.4 角色变化弧线（可跳过）
│   ├── 你希望这个角色在故事中有什么样的成长或改变？
│   ├── 促成这种转变的关键事件有预想吗？
│   └── 角色在故事开头和结尾大概有什么不同？

└── D2.5 编辑与调整（当修改请求模糊时展开）
    ├── 当前角色的内容是：[摘要]
    ├── 你看了之后，整体感觉怎么样？
    │   （基本符合/部分不对/完全不对/说不上来）
    ├── [差异定位] 性格/背景/关系/设定，哪方面不对？
    ├── [修正方向] 你希望改成什么样？（微调/中等改写/大幅调整）
    ├── [影响告知] 这个修改会影响已有章节和关联关系，你了解了吗？
    │   （知情接受/没想到影响这么多先不改了/先改目标其他后面再说）
    └── [执行] 先出修改方案给你看 / 直接改改完 review
```

**交互规则**：
- 如果有已有角色且用户意图是"修改"而非"新建"，直接进入 D2.5
- 快速模式问 D2.0–D2.2 核心 3 问，其余跳过
- 编辑分支总问题数 ≤ 5
