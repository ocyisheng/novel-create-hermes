# 叙事策略设计指导

在 P4.5 叙事策略设计阶段，定义整本书的叙事规则。输出见 `assets/narrative_strategy.yaml`。

---

## 1. 视角选择

### 主视角类型对比

| 类型 | 特点 | 适合 | 不适合 |
|------|------|------|--------|
| **第三人称限制** | 跟着一个角色走，读者只知道 ta 知道的信息 | 网文 90% 的情况，代入感强 | 需要多线同步推进时受限 |
| **第三人称全知** | 上帝视角，知道所有角色的想法 | 群像剧、史诗题材 | 悬疑类（会暴露信息） |
| **第一人称** | "我"的视角，代入感最强 | 悬疑、言情、轻小说 | 宏大的多线叙事 |
| **客观视角** | 仅记录可观察的行为和对话 | 极简主义、特殊风格 | 常规网文（缺乏内心戏） |

### 选择建议

| 故事类型 | 推荐主视角 | 原因 |
|---------|-----------|------|
| 玄幻/仙侠 | 第三人称限制 | 主角成长线 + 世界探索，代入感最佳 |
| 悬疑/探案 | 第三人称限制 / 第一人称 | 信息受限制造悬念 |
| 都市/职场 | 第三人称限制 | 主角中心叙事 |
| 群像/史诗 | 第三人称全知 | 多条故事线需要上帝视角协调 |
| 言情/轻小说 | 第一人称 | 情感代入最大化 |

### 辅助视角使用规则

```yaml
辅助视角:
  - 角色: "陈玄"
    功能: "提供反派视角，展示主角看不到的阴谋布局"
    使用频率: "每卷 2-3 章"

切换规则:
  每章最多切换次数: 2        # 前 1/3 固定主视角，中段可增加切换
  切换方式: "场景分隔"        # 用空行或章节分隔标记切换
  禁止行为: "同一场景内切换视角"  # 会让读者感到混乱
```

**关键原则**：主视角是读者的锚点。前 10 章尽量不切换视角，等读者锚定后再引入辅助视角。

## 2. 叙事手法

### 时序选择

| 手法 | 说明 | 使用场景 |
|------|------|----------|
| **顺序叙事** | 按时间线推进 | 主线叙事，默认选择 |
| **倒叙** | 先展示结果再回溯原因 | 开篇悬念、角色背景揭示 |
| **插叙** | 主线中插入过去片段 | 世界观补充、伏笔铺垫 |
| **多线并行** | 同时推进多条时间线 | 复杂情节、群像剧 |

### 闪回与闪前的控制

```yaml
辅助手法:
  - 手法: "闪回"
    使用场景: "角色背景揭示"
    频率限制: "每卷不超过 3 次"     # 过多闪回打断叙事节奏
    标记方式: "通过场景分隔 + 时间标记"  # 如 "=== 三年前 ==="

  - 手法: "闪前"
    使用场景: "悬念营造"
    频率限制: "每卷不超过 2 次"
    标记方式: "通过场景分隔 + 模糊化处理"
```

**闪回的反模式**：
- ❌ 每章都用闪回交代背景 — 读者会分不清当下主线
- ❌ 关键时刻切闪回 — 打断高潮张力
- ❌ 闪回内容太长（超过一章的 30%）— 读者会忘记主线到哪里了

## 3. 信息分配

### 戏剧反讽

让读者知道角色不知道的信息，制造紧张感。

```yaml
戏剧反讽:
  启用: true
  使用场景: "反派阴谋布局时，读者知道反派在谋划，主角不知道"
  标注方式: "在分纲中标注 [读者优势]"
  限制: "每卷不超过 5 处"
```

**最佳实践**：
- 在反派视角或旁白中透露信息
- 在主角即将踏入陷阱前制造"读者着急"的效果
- 反讽信息与主角发现真相之间的时间差不宜超过 1 卷

### 悬念管理

```yaml
悬疑管理:
  每卷主要悬念数量: 3             # 太多读者记不住
  悬念解答周期: "2-3 卷"         # 设悬念后必须在合理范围内解答
  章节钩子: "每章结尾必须有下一步行动的暗示"
```

**悬念分类**：

| 类型 | 解答周期 | 示例 |
|------|---------|------|
| 章节钩子 | 下章 | "门后站着一个人——" |
| 卷级悬念 | 本卷内或下卷 | "神秘人的真实身份是什么？" |
| 全书悬念 | 结局 | "主角的身世之谜" |

### 误导策略

```yaml
误导策略:
  启用: true
  使用场景: "通过角色视角限制制造误解"
  揭示方式: "后期通过其他视角或事件揭示真相"
  限制: "误导必须有合理解释，不能为了反转而反转"
```

**有效误导的条件**：
- 误导的信息在角色视角下是合理的（角色真的那么认为）
- 揭示真相时读者能回想"原来如此"
- 误导不能欺骗读者（读者看到的也是角色视角），而是角色自己被误导

## 4. 展示与讲述

| 手法 | 定义 | 效果 | 适用场景 |
|------|------|------|----------|
| **展示（Show）** | 通过动作、对话、感官描写呈现 | 代入感强，画面感好 | 情感高潮、动作场景、角色转变、世界观首次展现 |
| **讲述（Tell）** | 通过叙述者概括、角色独白 | 效率高，信息密度大 | 背景交代、时间跳跃、过渡段落、次要情节概括 |

### 比例建议

| 节奏阶段 | 展示 : 讲述 | 说明 |
|---------|:----------:|------|
| 开篇（前 10 章） | 80:20 | 展示为主建立世界 |
| 中段 | 70:30 | 可适当讲述加速节奏 |
| 高潮 | 85:15 | 展示最大化 |
| 过渡 | 50:50 | 讲述可提高效率 |

## 5. 笔法控制

冷笔和热笔控制叙事温度。

### 冷笔场景

速度快、信息密集、情感克制。用于推进情节。

```yaml
冷笔场景:
  - "动作场景"      # 战斗、追逐——节奏快不拖沓
  - "紧张时刻"      # 谈判、对峙——克制情感突出对抗
  - "信息传递"      # 揭示真相、情报交换——聚焦内容
  - "章节开头"      # 默认从冷笔切入，再根据需要切换
```

### 热笔场景

慢速、情感饱满、氛围浓烈。用于强化体验。

```yaml
热笔场景:
  - "情感高潮"      # 生离死别、重逢——全力渲染
  - "内心独白"      # 角色反思、成长感悟——深入内心
  - "氛围营造"      # 风景描写、环境烘托——建立沉浸感
  - "角色回忆"      # 闪回、往事——情感放大
```

### 切换规则

```
冷→热：通过情感触发事件（回忆、感悟）切换
热→冷：通过动作/对话打断情感，切换到客观叙述
禁止：连续 3 段以上同一笔法无变化  → 读者会疲劳
```

**节奏变化示例**：

```
第 5 章：战斗追逐（冷笔）→ 倒下时看到故人之物（热笔：回忆）→ 站起来继续战斗（冷笔）
```

## 6. 按类型的策略参考

| 类型 | 视角 | 叙事手法 | 信息分配特点 |
|------|------|----------|-------------|
| **玄幻/仙侠** | 第三人称限制（主视角=主角） | 顺序叙事为主，少量闪回 | 世界观信息逐步释放，每次章节透露 1-2 条新规则 |
| **悬疑/探案** | 第三人称限制或第一人称 | 顺序叙事+倒叙开篇 | 误导策略密集，读者优势和角色限制结合使用 |
| **都市/职场** | 第三人称限制 | 顺序叙事 | 信息分配偏平实，戏剧反讽在主配角冲突中使用 |
| **史诗/群像** | 第三人称全知为主，分卷切换锚定角色 | 多线并行 | 需要主索引管理多条线的信息交汇节奏 |
