# 详细大纲模板

本文件包含详细分纲的标准模板和字段定义。实际写入时以 `assets/chapter.yaml` 为模板源。

---

## 开篇契约设计模板

在 P4 总纲阶段，设计开篇契约以建立读者期待。

### 1. 类型契约

| 字段 | 说明 | 示例 |
|------|------|------|
| 小说类型 | 这是什么类型的小说？ | 玄幻/仙侠/都市/科幻/历史 |
| 读者期待 | 读者应该期待什么？ | 升级/冒险/爱情/悬疑 |
| 类型特征 | 开篇 3 章内必须体现的类型特征 | 修炼体系/异能/系统 |

### 2. 风格契约

| 字段 | 说明 | 示例 |
|------|------|------|
| 叙事基调 | 整体叙事风格 | 轻松/严肃/热血/黑暗 |
| 节奏快慢 | 更新节奏和叙事节奏 | 日更/周更/快节奏/慢热 |
| 风格标记 | 开篇 3 章内建立的风格预期 | 幽默对白/热血战斗/细腻情感 |

### 3. 主角契约

| 字段 | 说明 | 示例 |
|------|------|------|
| 主角身份 | 主角是谁？ | 少年/穿越者/重生者/普通人 |
| 核心困境 | 主角面临什么挑战？ | 修炼瓶颈/家族危机/生存压力 |
| 代入理由 | 读者为什么关心他？ | 逆袭潜力/悲惨遭遇/独特能力 |

### 4. 世界契约

| 字段 | 说明 | 示例 |
|------|------|------|
| 世界规则 | 基本力量体系/社会规则 | 修炼等级/科技水平/社会阶层 |
| 主角位置 | 主角在世界中的位置 | 底层/中层/顶层/边缘 |
| 世界特征 | 开篇 2 章内建立的世界特征 | 宗门体系/家族制度/国家格局 |

### 5. 契约检查清单

- [ ] 开篇第 1 章：主角身份 + 核心困境
- [ ] 开篇第 2 章：世界规则 + 主角位置
- [ ] 开篇第 3 章：类型特征 + 风格标记
- [ ] 前 10 章：兑现主要承诺（升级/冒险/情感）

## 必填字段清单

| 字段路径 | 类型 | 必填 | 说明 |
|---------|------|------|------|
| `索引信息.章节号` | 数字 | 是 | 如 46 |
| `索引信息.所属分卷` | 数字 | 是 | 对应卷号 |
| `摘要.一句话描述` | 字符串 | 是 | ≤30 字 |
| `摘要.出场角色` | 列表 | 是 | 本章出场角色名 |
| `摘要.核心情节点` | 列表 | 是 | ≥2 条 |
| `完整档案.基本信息.字数目标` | 数字 | 是 | 默认 3000 |
| `完整档案.结构规划` | 对象 | 是 | 开篇/发展/转折/收尾 |
| `完整档案.伏笔处理` | 对象 | 是 | 回收/新设/延续 |

## 总纲阶段对应参考

| 总纲阶段 | 章节类型 | 情节点特点 |
|----------|----------|------------|
| 第一幕-建置 | 第1-25%章 | 日常建立、触发事件、跨越门槛 |
| 第二幕-对抗 | 第26-75%章 | 上升行动、中点、失败、灵魂黑夜 |
| 第三幕-解决 | 第76-100%章 | 最终对决、问题解决、回归 |

## 情节点设计要点

### 每个章节应包含的情节点类型：

1. **建置阶段**（第一幕）：
   - 日常场景
   - 触发事件
   - 门槛跨越

2. **对抗阶段**（第二幕）：
   - 上升行动
   - 中点转折
   - 失败挫折
   - 灵魂黑夜

3. **解决阶段**（第三幕）：
   - 最终对决
   - 问题解决
   - 回归日常
