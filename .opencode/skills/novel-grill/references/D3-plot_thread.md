# D3. 情节线设计 — 需求发现树

根节点：你想设计一条什么样的故事线？

用于 focus_type=plot_thread（情节线设计/调整）前置需求发现。Grill 通过 novel-tool 自行查询已有总纲、分卷概要、已有情节线。

```
├── D3.0 锚定已有情节线（有已有情节线时展开）
│   ├── 已有的情节线：[列表]
│   ├── 你想在新情节线上推进，还是调整已有的线？
│   └── 和现有情节线的关系是？（主线/支线/暗线/并行）

├── D3.1 情节线定位
│   ├── 这条线在整个故事中占什么比重？
│   │   （主线≥70% / 重要支线 30-50% / 轻量支线 <20%）
│   ├── 核心冲突偏向哪种？
│   │   （个人 vs 个人/个人 vs 社会/个人 vs 自然/个人 vs 自我）
│   └── 这条线的目标读者感受是什么？
│       （紧张刺激/感动落泪/悬疑烧脑/轻松调剂/深思回味）

├── D3.2 起承转合
│   ├── 有没有预设的起点或关键事件？
│   ├── 这条线的转折点大概在什么时候？
│   └── 结局方向预想？（达成目标/失败告终/开放/模糊留白）

├── D3.3 交叉与关联
│   ├── 这条线和哪些角色线交叉？
│   ├── 和其他情节线在什么节点交汇？
│   └── 交汇方式是？（紧密交织/阶段性交叉/各自独立）

├── D3.4 伏笔规划
│   ├── 这条线有没有预设的伏笔？
│   ├── 伏笔在什么节点设下、什么节点回收？
│   ├── 伏笔的载体是？（物品/对话/事件/设定/角色行为）
│   └── 回收方式偏向？
│       （惊喜反转/情理之中/多重用途层层深入/开放式可续可解）

└── D3.5 编辑与调整（当修改请求模糊时展开）
    ├── 当前情节线内容是：[摘要]
    ├── 哪方面需要调整？（走向/节奏/伏笔/冲突强度/关联关系）
    └── 改动幅度？（微调/重写/合并到其他线）
```

**交互规则**：
- 快速模式问 D3.0–D3.1，其余可跳过
- 情节线调整时优先展示当前内容摘要再问差异

## 与 thematic_motif 的边界

- **plot_thread 的伏笔**：情节层面的因果伏笔——"这条线索什么时候设下、什么时候回收"，是情节设计的一部分，对应 D3.4
- **thematic_motif 的象征呼应**：主题层面的意象呼应——"这个意象在故事中如何演变、在什么节点获得新意义"，是母题设计的一部分
- 当用户的意图是"设计伏笔/埋伏笔"时，编排层应路由到 plot_thread；当意图是"设计象征/意象呼应"时，路由到 thematic_motif
