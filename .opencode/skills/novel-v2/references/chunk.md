# 焦点类型：chunk — 质量检测与修订指南

## 适用任务

| 路由映射 | 描述 |
|---------|------|
| 润色/精修 | 改善文笔、风格一致性、细节密度 |
| 质量检测 | 7路并行检测 + 综合报告 |
| 重写/修订 | 根据检测报告定向修复 |

## 质量检测7路维度

### 1. AI味道检测（含语言尸体）

AI味的本质是**描述程序与观察程序脱节**。

9类AI特征（按严重程度排列）：
| # | 特征 | 严重程度 | 检测方法 |
|---|------|---------|---------|
| 1 | **语言尸体** | 最高 | 这个描述是真切的观察，还是通行修辞模板？ |
| 2 | 角色不一致 | 高 | 角色言行与设定不符 |
| 3 | 情节逻辑空隙 | 高 | 因果关系断裂 |
| 4 | 旁白叙述过多 | 高 | Show not tell 缺失 |
| 5 | 情感空洞 | 中 | 情感描写模板化 |
| 6 | 缺乏细节 | 中 | 场景描写模糊 |
| 7 | 重复套路 | 中 | 情节模式单一 |
| 8 | 风格过于正式 | 低 | 对话不够口语化 |
| 9 | 句式单调 | 低 | 句子结构单一 |

**语言尸体检测方法**：逐句定位看起来"通顺但空洞"的描述，问：这个句子有没有暴露出写作者自己的观察角度？如果它可以在任何小说中通用，极大概率是尸体。

### 2. 情节逻辑检测（含因果律批判）

5+2检测维度：
1. 因果合理性
2. 转折动机检测（是否有足够铺垫和动机）
3. 伏笔逻辑检测
4. 节奏逻辑检测
5. 结局逻辑检测（是否具有必然性和说服力）
6. ★ 故事/情节判别：这段叙事以"然后呢"还是"为什么"驱动？
7. ★ 因果律安全装置检测：情节推进是否过于"顺畅安全"？

### 3. 角色一致性检查（含扁平vs圆形检验 + 自动性检验）

6+2检测维度：
1. 性格一致性
2. 行为一致性
3. 语言风格（对话是否符合角色身份）
4. 能力边界
5. 关系动态
6. 状态连续性（与上一次出场时的状态是否连续）
7. ★ 扁平vs圆形定位：如果是圆形，它有没有"令人信服地意外"？
8. ★ 自动性检测：角色有没有表现出超出作者操控的言行？

### 4. 世界观漏洞检测

5个维度：
1. 规则一致性
2. 物理法则
3. 势力逻辑
4. 时间线
5. 文化自洽

区分"创新设定"与"逻辑漏洞"；区分"开放区的矛盾"与"粗心的矛盾"。

### 5. 节奏分析（意志速度检验）

4+1维度：
1. 节奏扫描（快/中/慢）
2. 高潮分布
3. 情感曲线
4. 疲劳点检测
5. ★ 意志速度检验：慢节奏来源于角色意志（好）还是啰嗦（差）？快节奏来源于意志碰撞（好）还是仓促收尾（差）？

### 6. 读者体验评估（主题曲检验）

4+1维度：
1. 可读性：段落长度50-120字、句子长度20-30字
2. 情感节奏：情感强度曲线1-10、每章≥1小高潮
3. 悬念管理：每章结尾必须有钩子、每卷≥3个主要悬念
4. 信息密度：每章2-3个新信息点
5. ★ 主题曲检验：主题像音乐动机通过重复-展开-变奏起作用，还是孤立的"中心思想"？

### 7. 风格一致性检查

对比章节正文与活跃风格文件的7维度定义：
narrative_tone / sentence_structure / pacing / dialogue_style / vocabulary_register / rhetorical_features / forbidden_patterns

## 润色/修订原则

1. **最小修改**：只改用户指定的内容，不附加"顺便优化"
2. **保护修正痕**：叙述者的自我纠正、记忆的不确定性、视角的有限性是叙事深度来源，不是错误
3. **保护起居注细节**：看起来"不推进情节"的生活细节——三级判断：发现级(可删)→设计级(谨慎)→发明级(保护)
4. **扁平化风险**：修改后角色变得更可预测、不再让读者意外 → 如是圆形人物→退步信号
5. **风格一致性**：基于活跃风格的7维度定义，但允许偏离容忍度范围内的自然即兴
