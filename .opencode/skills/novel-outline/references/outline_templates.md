# 详细大纲模板

本文件包含详细分纲的标准模板和字段定义。

---

## 单个章节分纲模板（YAML）

```yaml
章节号: "第X章"
章节标题: "章节标题内容"
 对应总纲阶段: "第一幕-建置"  # 根据总纲.yaml 故事结构.幕列表填写

本章情节点:
  - "情节点1描述"
  - "情节点2描述"
  - "情节点3描述"

出场角色:
  - "角色1"
  - "角色2"

预计字数: 2000

关键转折: "本章关键剧情转折描述"

备注: "可选备注内容"
```

---

## 总纲阶段对应参考

| 总纲阶段 | 章节类型 | 情节点特点 |
|----------|----------|------------|
| 第一幕-建置 | 第1-25%章 | 日常建立、触发事件、跨越门槛 |
| 第二幕-对抗 | 第26-75%章 | 上升行动、中点、失败、灵魂黑夜 |
| 第三幕-解决 | 第76-100%章 | 最终对决、问题解决、回归 |

## 情节点设计要点

### 每个章节应包含的情节点类型：

1. **建置阶段**（第一幕）：
   - 日常场景
   - 触发事件
   - 门槛跨越

2. **对抗阶段**（第二幕）：
   - 上升行动
   - 中点转折
   - 失败挫折
   - 灵魂黑夜

3. **解决阶段**（第三幕）：
   - 最终对决
   - 问题解决
   - 回归日常

---

## 必填字段清单

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 章节号 | 字符串 | 是 | 第X章 |
| 章节标题 | 字符串 | 是 | 本章标题 |
| 对应总纲阶段 | 字符串 | 是 | 所属幕数 |
| 本章情节点 | 列表 | 是 | 至少2个 |
| 出场角色 | 列表 | 是 | 本章出场角色 |
| 预计字数 | 数字 | 是 | 默认2000 |
| 关键转折 | 字符串 | 是 | 本章核心转折 |
| 备注 | 字符串 | 否 | 补充说明 |
