# novel-create-hermes

**跟 AI 聊着天，就把小说写了。**

像发微信一样说出你的想法，AI 自动完成从创意构思到章节写作的全部流程。

---

## 安装

### 1. 装 Python
去 [python.org/downloads](https://python.org/downloads) 下载最新版，安装时勾 **Add Python to PATH**。已有 Python 的跳过。

### 2. 装 OpenCode
**桌面版（推荐）：** 去 [opencode.ai](https://opencode.ai) 下载 → 打开 → **设置 → 插件** → 添加 `oh-my-openagent` → 启用

**命令行版：**
```bash
npm install -g @opencode/cli
opencode plugin add oh-my-openagent
```

### 3. 打开项目
```bash
cd Desktop\novel-create-hermes
opencode
```
按 Tab 键切换到 `Novel-writer` Agent。

## 使用

像聊天一样说话即可，**不需要记命令**。

### 👋 第一次使用

```
你： 新建项目"龙渊" 类型：玄幻
AI： ✅ 项目创建完成！接下来想做什么？
```

这样就开始了。接下来 AI 会问你想做什么，你直接说就行。

### ✍️ 创作流程（不用按顺序）

你可以从任意一步开始，不需要先做创意再做世界观、先写大纲再写章节。想到哪写到哪，AI 会自动判断上下文。

| 你想做的事 | 你就说 |
|------------|--------|
| **新建小说** | `新建项目"书名" 类型：玄幻/仙侠/都市/科幻` |
| **没灵感** | `帮我想个创意` |
| **搭建世界观** | `搭个世界观` 或 `建个力量体系` |
| **创建角色** | `创建主角林渊` 或 `创建反派` |
| **写大纲** | `设计故事大纲` |
| **设计情节** | `设计主线` 或 `设计伏笔` |
| **写分纲** | `写分纲` |
| **写章节** | `写第1章` 或 `写第3章到第5章` |
| **修改** | `润色第3章` 或 `把主角改得更果断一些` |
| **检查质量** | `检测AI味` 或 `看看写得怎么样` |
| **切换风格** | `用凡人修仙风来写` |
| **导出** | `导出为TXT`（也支持 EPUB、PDF、HTML、DOCX） |
| **看进度** | `当前进度怎么样` |
| **换项目** | `切换到龙渊` |
| **导入书** | `把凡人修仙传加入知识库 C:\书.epub` |
| **查知识库** | `知识库里有什么书` |
| **参考知识** | `参考星辰变的力量体系搭世界观` |

> 所有步骤可以任意跳序，不用按顺序来。

### 📚 知识库（可选）

把你喜欢的书导入成结构化知识，写小说时可以直接引用它的力量体系、叙事节奏等

支持 PDF、EPUB、TXT、DOCX、HTML、MOBI、AZW3。

> **先导入再引用** 是常规用法，但也可以直接说 "参考星辰变的力量体系"，AI 发现书还没导入时会先帮你导入。

### 🎨 写作风格（可选）

说一句就能换风格：

```
用凡人修仙风来写第3章
用金庸武侠风
切换成古龙风
```

内置 20+ 风格：凡人修仙风、金庸武侠风、古龙武侠风、古典名著风、悬疑推理风……

## 常见问题

**写出来能直接用吗？**
初稿。建议读一遍，用 `检测AI味` 找出 AI 痕迹过重的地方，再改一改。

**换电脑了怎么办？**
把整个 `novel-create-hermes` 文件夹拷走就行。`novels/` 是你的小说，`knowledge/` 是你的知识库。

**导入的书存在哪？**
存在 `knowledge/` 目录下，纯 markdown 文件，你可以直接打开看。
