# D1. 创意构思 — 需求发现树

根节点：我推荐几个方向，你看看哪个有感觉

用于 P1 创意构思前置需求发现。执行前编排层已注入 `{已有创意方向}` 上下文槽位（如有）。

```
├── D1.0 方向推荐（新增）
│   ├── 我先根据你已有的信息（项目类型/已有设定），推荐 2-3 个方向：
│   │   → 选项 A：[具体方向简述]
│   │   → 选项 B：[具体方向简述]
│   │   → 选项 C：[具体方向简述]
│   ├── 或者你大致说一个方向，我再细化？
│   └── 以上都不对？那我换个角度重新推荐

├── D1.1 类型与基调（用户选完方向后细化）
│   ├── 你选了这个方向，具体想写什么类型？（玄幻/科幻/都市/悬疑/历史/其它）
│   ├── 整体基调是什么？（热血/深沉/轻松/悬疑/史诗）
│   └── 有没有参考作品？

├── D1.2 核心元素
│   ├── 在这个方向上，有什么特别想写的元素？
│   ├── 主角大概是什么样的角色？
│   └── 已经有一些片段想法了吗？

├── D1.3 篇幅与节奏 + 读者定位（可跳过）
│   ├── 大概想写多长？（短篇/中篇/长篇/超长篇）
│   ├── 节奏偏好？（快节奏/慢热/张弛有度）
│   ├── 这篇打算给谁看？（老白读者/大众读者/自己写着玩）
│   └── [如选"自己写着玩"则跳过] 有商业发布的打算吗？（有/随缘/没有）

└── D1.4 排除项（可跳过）
    ├── 有什么是你绝对不想写的元素或套路？
    ├── 有没有哪些常见的写法是你想避免的？
    └── 有没有特别不想参考的作品或不想走的方向？
```
