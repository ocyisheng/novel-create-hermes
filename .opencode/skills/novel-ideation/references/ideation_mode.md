# 模式 A：创意需求分析（ideation）

> **本文档整合了以下内容**：输出格式示例。

**适用阶段**：P1（无创意）

## 分析维度

| 维度 | 说明 | 示例值 |
|------|------|--------|
| 类型与融合 | 主类型 + 可选子类型 | 玄幻/仙侠融合 |
| 创作基调 | 故事氛围 | 黑暗深沉/轻松幽默/史诗宏大 |
| 主题方向 | 核心主题 | 成长/复仇/救赎/探索 |
| 核心元素 | 必须包含的创意要素 | 系统流/反套路/群像 |
| 排斥元素 | 绝对要避免的方向 | 后宫/重生/虐主 |
| 创新诉求 | 突破常规的程度 | 保守/适度/大胆 |

## 执行流程

```
1. 确认小说类型与融合方向
2. 确定创作基调
3. 明确主题方向
4. 收集核心创意要素
5. 了解排斥元素
6. 确定创新诉求程度
7. 生成创意需求简报
```

## 产出格式

```yaml
创意需求简报:
  类型与融合: [主类型 + 子类型/融合方向]
  创作基调: [基调类型]
  主题方向: [主题列表]
  核心元素: [创意要素列表]
  排斥元素: [禁忌方向列表]
  创新诉求: [保守/适度/大胆]
  创意约束: [与基调/主题/创新诉求一致的约束方向]
```

## 创意方向输出格式

```yaml
创意方向:
  - 编号: 1
    一句话概述: "修仙版饥饿游戏，宗门选拔中的生存竞赛"
    核心冲突: "底层弟子对抗宗门高层的阴谋"
    主角设定: "林默，外门弟子（表面）/ 古魔传承者（真实）"
    亮点卖点: "将生存竞技与修仙结合，反转传统套路"
    适用约束: ["三幕结构", "系统副作用", "身份颠覆"]

  - 编号: 2
    一句话概述: "..."
    核心冲突: "..."
    主角设定: "..."
    亮点卖点: "..."
    适用约束: [...]
```

## 创意深度开发格式

```yaml
创意深度开发:
  世界观设定:
    核心规则: "灵气会衰退，每百年一次大衰退"
    地理版图: "九州大陆，九大势力割据"
    时代背景: "末法时代，上古大能陆续苏醒"
    势力格局: "正道联盟 vs 魔道复苏 vs 古魔传承"

  角色档案:
    主角:
      姓名: "林默"
      身份: "外门弟子（表面）/ 古魔传承者（真实）"
      目标: "在选拔中活下来并揭露阴谋"
      冲突: "使用古魔力量会被正道追杀，不用就会死"

  情节大纲:
    序章: "宗门选拔开始，林默险些丧命"
    发展: "林默发现古魔传承，实力大增但被追杀"
    高潮: "选拔决赛，林默揭露阴谋，正魔大战爆发"
    结局: "林默选择第三条路，建立新秩序"

  主题方向:
    核心主题: "在绝境中寻找第三条路"
    情感基调: "压抑中带着希望，黑暗中闪烁光明"
    价值取向: "不盲从正邪二分，走自己的道"
```
