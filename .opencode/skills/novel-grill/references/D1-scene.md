# D1. 场景/章节写作 — 需求发现树

根节点：已读分纲，你想按计划推进还是有特别调整？

用于 focus_type=scene（场景/章节写作）前置需求发现。Grill 通过 novel-tool 自行查询分纲、出场角色等上下文。

```
├── D1.0 展示分纲摘要（新增/已存在时）
│   ├── 根据当前设定，这章的核心是：[场景目标摘要]
│   ├── 出场角色：[角色列表]
│   ├── 你觉得这个方向 OK 吗？还是想做一些调整？
│   │
│   ├── [OK，按这个写] → 跳过所有后续分支，直接持久化
│   │
│   └── [想调整] → 展开以下按需分支：

├── D1.1 章节侧重（按需）
│   ├── 你想调整哪个方面？（节奏/视角/内容侧重/开头结尾/其他）
│   ├── [选节奏] 希望比分纲更快还是更慢？
│   ├── [选视角] 希望换成谁的视角？
│   ├── [选侧重] 侧重动作/对话/心理/环境？
│   ├── [选效果] 这一章你想让读者看完后有什么感受？
│   │   （紧张/感动/大笑/震撼/烧脑/放松/没特别要求）
│   └── 有想好这章怎么开头吗？
│       （直接场景切入/对话开场/内心独白/动作场面/叙事引入/你来帮我定）

├── D1.2 衔接说明（按需）
│   ├── 和上一章的衔接有特别注意的地方吗？
│   ├── 这章结尾需要为下一章做什么铺垫？
│   └── 有什么"绝对不能出现"的写法？

└── D1.3 编辑与调整（当修改请求模糊时展开）
    ├── 你读着感觉哪方面不太对？
    │   （节奏/对话/描写叙事/人物行为/情节逻辑/说不上来但感觉怪）
    ├── [修改方向] 希望更快还是更慢？谁的对话有问题？场景感不够？
    │   └── 要不要我先出一个诊断，你再决定怎么改？
    └── [执行方式] 直接改，改完你看 / 先出修改方案，确认后再改
```

**交互规则**：
- 快速模式仅问 D1.0 和 D1.3（如果有编辑意图），其余跳过
- 编辑分支（D1.3）仅当用户修改意图模糊时展开；明确指令（"第3段对话改自然"）跳过
- 总问题数快速模式 ≤ 3，深度模式 ≤ 8
