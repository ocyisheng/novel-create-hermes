# 写作原则

章节写作必须遵循的核心原则。

---

## 1. 忠实分纲

- 不添加分纲未定义的重大情节
- 不改变关键转折和伏笔
- 在分纲框架内丰富细节

**原则**：分纲是骨架，正文是血肉。骨架不变，血肉可丰。

---

## 2. 角色一致

- 对话符合角色语言风格
- 行为符合角色性格设定
- 能力使用不超出设定边界

**原则**：每个角色有自己的声音和行为模式，不要让角色"失忆"或"变性格"。

---

## 3. 避免AI味道

- 拒绝抽象情感词（非常/十分/特别）
- 用具体感官细节代替旁白叙述
- 对话自然，避免"地说/地想"重复结构

**具体规则**：
```
❌ 非常生气 → ✅ 拳头捏得发白
❌ 十分悲伤 → ✅ 眼泪眶眶地流
❌ 她美丽动人 → ✅ 她睫毛颤了颤
```

详见 [AI味道检测规则](../novel-quality/references/ai_flavor_rules.md)

---

## 4. 节奏控制

- 重要情节点详写
- 过渡段落略写
- 对话与描写交替

**节奏公式**：
```
紧张段 + 缓冲段 + 紧张段
   ↓
长短交替形成波浪
```

---

## 5. 伏笔与悬念

**伏笔原则**：
1. 隐蔽性 - 不引起注意
2. 多重暗示 - 同信息多次出现
3. 延迟回收 - 足够时间间隔

**悬念原则**：
1. 章节结尾设置悬念钩子
2. 重要性 × 不确定性 × 延迟 = 悬念强度
3. 适时揭示，不要拖延太久

---

## 6. 感官描写

每个场景至少包含2种感官：

| 感官 | 示例 |
|------|------|
| 视觉 | 颜色、光线、形状 |
| 听觉 | 声音、静默 |
| 嗅觉 | 气味、香气 |
| 味觉 | 味道、口感 |
| 触觉 | 温度、质感 |
