# D3. 角色设计 — 需求发现树

根节点：你想要一个什么样的角色？

用于 P3 角色创建前置需求发现。执行前编排层注入 `{已有角色列表}` 和 `{故事背景摘要}`。

```
├── D3.0 故事背景锚定（新增）
│   ├── 根据当前故事[总纲概要]，这个角色大概在什么位置？
│   ├── 目前已创建的角色：[列表]
│   └── 这个角色和已有角色有关系吗？

├── D3.1 角色定位
│   ├── 这个角色在故事中负责推动哪部分剧情？（主线核心/支线补充/关系张力/气氛调节）
│   ├── 角色大致是个什么样的人？（年龄/性别）
│   │   → 社会身份：职业/阶层/所属势力
│   │   → 出身背景：家庭/成长环境/来处
│   └── 这个角色最吸引人的地方是什么？（成长逆袭/神秘感/反差萌/读者共鸣）

├── D3.2 性格与动机
│   ├── 性格偏向哪边？
│   │   （话多还是话少？做事靠逻辑还是直觉？偏执固执还是挺随意？）
│   ├── 角色行动的最大动力是什么？（复仇/守护/求知/权力/情感/生存）
│   ├── 性格上有什么弱点或缺陷？
│   ├── 角色内心最深处的恐惧是什么？
│   │   （怕失去力量/怕被背叛/怕暴露真实身份/怕平庸一生/怕孤身一人/其他）
│   ├── 角色有什么死也不想让人知道的秘密？（可跳过）
│   └── 紧张或激动时有什么小动作或口头禅？（可跳过）

├── D3.3 关系网（锚定后问）
│   ├── 与[已列出的角色]的关系定位？
│   ├── 有预设的 CP 或对立关系吗？
│   └── 有哪些必须建立的关系线？

└── D3.4 角色在故事中的变化（可选，标记为"可以先不考虑"）
    ├── 你希望这个角色在故事中有什么样的成长或改变？（可跳过，后续再定）
    ├── 促成这种转变的关键事件有预想吗？（可跳过）
    └── 角色在故事开头和结尾大概有什么不同？（可跳过）
```
