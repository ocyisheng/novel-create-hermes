# D7. 世界观建设 — 需求发现树

根节点：你这个世界大概是什么样的？

用于 P2 世界观建设前置需求发现。执行前需确认 P1 创意方案中是否已有世界观概述。如有，自动跳过 D7.0，展示已有摘要后直接进入 D7.1。

```
├── D7.0 已有背景锚定（如创意方案已有世界观概述 → 展示摘要后直接跳过）
│   ├── 根据之前的设定，这个世界已经有：[世界观概述]
│   ├── 是在这个基础上细化，还是想调整方向？
│   └── （如无已有设定）→ 展开以下分支：
│       ├── 故事发生在一个什么样的世界？
│       │   （现实世界隐藏另一面/完全虚构的异世界/未来星际时代/过去历史时期/其他）
│       └── 这个世界的整体氛围是？
│           （光明热血/黑暗压抑/灰色地带人性博弈/幽默搞笑/史诗庄严）

├── D7.1 世界观规模
│   ├── 世界的物理规模大概多大？
│   │   （一片大陆/多块大陆多个国家/星际多星球/平行宇宙/箱庭小世界/跟现实世界差不多）
│   ├── 地图需要多详细？
│   │   （粗略几个重要地名就行/要有完整的地理体系/想到哪写到哪不用提前规划）
│   └── 有没有现实世界的文化或地理原型？
│       （参考真实历史时期/参考特定文化圈/完全原创/混搭融合）

├── D7.2 核心规则体系
│   ├── 力量体系是哪一类？
│   │   （等级晋升体系/血脉或血统觉醒/科技装备/没有超自然力量/混搭融合多种）
│   │   ├── [选等级晋升] → 境界划分需要我帮你设计，还是已经有参考？
│   │   ├── [选混搭] → 哪些元素混在一起？大概什么比例？
│   │   └── [选没有超自然力量] → 跳过后续规则类问题，进入 D7.3
│   ├── 读者需要知道多少设定？
│   │   （完全量化清楚，每个境界每个法术都明明白白/部分可知，保留一些神秘感/读者和角色一起慢慢探索发现）
│   └── 力量有什么限制或代价？
│       （消耗体力或灵力/有反噬风险/需要特定条件触发/没有什么明确限制）

├── D7.3 势力与格局（依赖 D7.1：小规模→2-3方，大规模→3-5方+）
│   ├── 主要势力有几个？
│   │   （两到三方对峙/多方势力博弈/一家独大主角挑战/单一势力内部斗争）
│   ├── 这些势力之间的关系是什么基调？
│   │   （公开战争/和平共存暗中角力/表面和谐实际紧张/各自为政互不干涉）
│   └── 主角与这些势力的关系是？
│       （加入其中一方/独立于势力之外周旋/亲手建立自己的势力/还没想好）

└── D7.4 特殊偏好（可跳过）
    ├── 有什么是你绝对不想在这个世界里出现的设定？
    ├── 有什么是你一定要包含的设定？
    └── 用一句话说，这个世界最特别的地方是什么？
```

**分支规则**：
- D7.0 有已有世界观概述时自动跳过（避免重复询问 P1 已确认信息）
- D7.1 规模影响 D7.3 势力数量的默认推荐值
- D7.2 选"没有超自然力量"时，D7.3 后续关于力量体系的追问自动收缩
- D7.4 整段可跳过（标记为"这些可以先不管"）
- 总问题数：10-12 个（含分支展开），快速模式下压缩为 3 个核心问题（D7.1 规模 / D7.2 规则 / D7.3 势力）
