# 焦点类型：plot_thread — 情节与伏笔设计指南

## 适用任务

设计主线/支线情节、规划伏笔系统。

## 情节线结构

情节线写入 graph 时，content 字段为 JSON 结构化：

**索引信息：**
- 实体ID、名称、类型（main/sub/character_arc）、状态（active/resolved/on_hold）
- 起始章节、起始时间、结束时间

**摘要（P7/P8 快速加载用）：**
- 一句话描述(≤30字)、当前境况(≤50字)、核心特质(≤5)
- 当前目标、关键关系、当前区间、区间情节点(≤5)、关联角色

**完整档案：**
- 描述(100-200字)、冲突核心
- 关键事件列表：章节号/事件/影响
- 关联支线、终局设计
- **伏笔清单**：计划埋设的伏笔（编号/描述）+ 计划回收的伏笔（编号/描述）
- **角色参与**：涉及角色 + 角色推动作用 + **出场节奏**（角色名/首次出场/关键章节/不活跃区间/出场密度）
- 创作笔记：注意事项、节奏提示

## 伏笔规划要点

伏笔不必全部"兑现"。支持4种回收类型：

| 类型 | 回收方式 | 效果 |
|------|---------|------|
| **精准型** | 如约兑现，因果清晰 | 满足读者期待 |
| **落空型** | 预示但未发生 | 荒谬/讽刺效果 |
| **误解型** | 读者/角色理解偏差 | 意外的真实 |
| **悬置型** | 开放式不回收 | 保持开放 |

**松散与巧合的正当性：**
- 情节中的偶然性不是缺陷
- 巧合是传奇的识别证，伏笔是巧合的掩护——"假'前'为因，假'后'为果"
- 在情节线中标记每章的"松散度"许可区间

## 情节线设计决策

**底层驱动力判别：**
- **故事驱动（"然后呢"）**：悬念驱动，适合冒险型支线、悬疑主线。伏笔密度高，按时回收
- **情节驱动（"为什么"）**：因果驱动，适合社会派、心理向主线。伏笔可以有落空/误解型回收

注意：因果律超出界限时人物沦为牺牲品。精密情节可能成为"盲目崇拜"——人物有自己的"秘密生活"，会抗拒情节的逻辑约束。

**复调结构：**
在情节线上层叠两重意义——表面情节（读者以为这是A）与反讽潜流（实际指向B）：
- 主线：高大叙事/卑微现实并置形成反讽对照
- 支线：作为主线的反讽镜像——同一事件的不同视角彼此拆解
- 伏笔：对应"反讽型伏笔"——回收时揭示真相与表面认知的落差
