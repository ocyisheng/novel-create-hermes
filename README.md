# novel-create-hermes

一个**用 AI 帮你写小说**的工具。像聊天一样说出你的想法，AI 就会帮你完成从创意构思到章节写作的全部流程。

[**开发者：了解架构 →**](DEVELOPER.md)

---

## 快速开始

### 1. 安装 Python

> 已安装 Python 可跳过。

1. 访问 [python.org/downloads](https://python.org/downloads)
2. 下载最新版本
3. 安装时勾选 **Add Python to PATH**
4. 点击 **Install Now**

### 2. 安装 OpenCode

**选项 A：桌面版（推荐新手）**

1. 访问 [opencode.ai](https://opencode.ai) 下载桌面版
2. 打开 OpenCode → **设置 → 插件**
3. 添加插件 `oh-my-openagent`，启用
4. 通过 **"打开文件夹"** 选择 `novel-create-hermes` 文件夹

**选项 B：命令行版**

```bash
npm install -g @opencode/cli
opencode plugin add oh-my-openagent
```

### 3. 启动

```bash
cd Desktop\novel-create-hermes
opencode
```

> 使用 Tab 键切换到 Novel-writer Agent。

### 4. 开始写作

像发微信一样输入你的想法：

```
你： 新建项目"星辰变" 类型：玄幻
AI： ✅ 项目创建完成！

你： 帮我构思一下创意方向，我想写一个少年逆袭的故事
AI： 🤔 好的，我生成了 3 个创意方向……
```

## 创作流程

| 步骤 | 你说 | AI 做 |
|------|------|-------|
| **新建项目** | `新建项目"书名" 类型：玄幻` | 创建项目文件夹 |
| **创意构思** | `帮我构思一下创意方向` | 生成故事点子 |
| **搭建世界观** | `搭建世界观` | 创建力量体系等设定 |
| **创建角色** | `创建主角张小凡` | 创建角色档案 |
| **写大纲** | `设计故事大纲` | 规划故事结构 |
| **设计情节** | `设计主线和支线情节` | 搭建情节框架 |
| **写分纲** | `写分纲` | 为每章写详细提纲 |
| **写章节** | `写第1章` | 生成章节正文 |
| **质量检查** | `检测一下AI味` | 检查写作质量 |
| **导出** | `导出为TXT` | 保存到文件 |

> **不需要按顺序。** 你可以跳过任意步骤，AI 会自动判断该做什么。

## 常用说法

| 你想 | 你说 |
|------|------|
| 不知道怎么用 | `你能帮我做什么` |
| 新建小说 | `新建项目"书名" 类型：玄幻/仙侠/都市` |
| 换个项目 | `切换到另一本项目` |
| 看进度 | `当前进度怎么样` |
| 没灵感 | `帮我想个创意` |
| 写框架 | `写大纲` |
| 创建角色 | `创建主角XXX` |
| 写章节 | `写第5章` / `写第3章到第5章` |
| 改章节 | `润色一下第3章` |
| 改角色 | `把主角改得更冷酷一些` |
| 检查质量 | `检测AI味` |
| 换风格 | `用凡人修仙风来写` |
| 导出 | `导出为TXT` |

## 常见问题

**Q：AI 写的东西能直接用吗？**
A：AI 生成的是初稿，建议读一遍再确认。用 `检测AI味` 可以找出 AI 痕迹过重的地方。

**Q：换电脑了怎么办？**
A：所有内容都在 `novels/` 文件夹。把整个 `novel-create-hermes` 文件夹拷到新电脑即可。

**Q：怎么知道写了多少字？**
A：说 `当前进度怎么样`，AI 会告诉你。

**Q：怎么修改已写的章节？**
A：说 `润色一下第3章` 或 `修改第5章`，AI 会按你的要求修改。
