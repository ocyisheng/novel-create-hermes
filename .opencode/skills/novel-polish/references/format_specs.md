# 格式化规范说明

本文件包含从 SKILL.md 移出的格式化详细内容。

---

## 格式化项目

### 1. 章节标题格式

| 格式项 | 说明 | 示例 |
|--------|------|------|
| 标题格式 | 统一为"第X章 章名" | 第1章 山村少年 |
| 序号位数 | 补齐2位（01）或不补齐 | 第1章 / 第01章 |
| 标题与序号 | 中文数字或阿拉伯数字 | 第一章 / 第1章 |

### 2. 段落格式

| 格式项 | 说明 | 示例 |
|--------|------|------|
| 段落缩进 | 全角2字符首行缩进 | 　文字... |
| 段落间距 | 段落间空行 | 段落间空一行 |
| 对齐方式 | 左对齐 | - |

### 3. 对话格式

| 格式项 | 说明 | 示例 |
|--------|------|------|
| 引号风格 | 「」中文引号 | 「有何贵干？」 |
| 引号风格 | ""英文引号 | "有何贵干？" |
| 引号风格 | 『』双引号 | 『有何贵干？』 |
| 对话位置 | 单独一行 | 「...」 |
| 动作位置 | 对话前/后 | 他笑了笑：「...」 |

### 4. 标点符号

| 格式项 | 说明 |
|--------|------|
| 全角标点 | ，。！？：「」『』——…… |
| 半角标点 | ,.!?:"' |
| 混排规则 | 中文用全角，英文/数字用半角 |

---

## YAML 配置示例

```yaml
publishing:
  格式设置:
    标题格式: "第X章 章名"
    序号位数: 2  # 01或1
    段落缩进: "全角2字符"
    对话引号: "「」"
    标点: "全角"

  样式设置:
    字体: "默认"
    行距: 1.5
    字号: "小四"
```
