# 小说创作工作流计划

## 多项目协作须知

所有小说项目共用小说根目录下的 `.venv` 环境。
切换项目时 Agent 按 novel-writer.md §二 项目发现与选择 协议更新 `.omo/notepads/novel-context.md`。

```
小说根目录/
├── .venv/              ← 共享环境
├── 小说1/              ← 每个项目独立
├── 小说2/
├── 小说3/
└── ...
```

## 阶段检查清单

> 按 novel-writer.md 触发优先级排列。P-1 先于所有阶段执行。

### P-1：环境初始化

- [ ] Python 环境检测
- [ ] .venv 虚拟环境创建（小说根目录下）
- [ ] 依赖安装
- [ ] setup.py 验证

### P-2：项目管理

- [ ] 新建/导入/切换/续写/查看状态/删除
- [ ] config.yaml 生成
- [ ] 标准目录结构创建
- [ ] 多项目共存检查

### P1：创意构思

- [ ] 需求分析完成（mode=ideation）
- [ ] 约束应用
- [ ] 类型分析（如需要）
- [ ] 模板生成
- [ ] 创意发散（3-5 个方向）
- [ ] 创意评估
- [ ] 整合输出创意方案 YAML

### P2：故事大纲规划

- [ ] 故事结构规划（三幕/五幕）
- [ ] 总纲撰写 → `outline/总纲.yaml`
- [ ] 分卷规划 → `outline/分卷/卷{N}_{名称}.yaml`

### P3：主/支线情节构建

- [ ] 主线设计 → `outline/情节线/主线.yaml`
- [ ] 支线穿插 → `outline/情节线/支线_{名称}.yaml`

### P4：世界观建设（按 worldview.yaml 模板）

- [ ] 基本信息 / 核心规则
- [ ] 力量体系 / 势力格局
- [ ] 地理位置 / 历史 / 文化
- [ ] 各实体写入 `worldbuilding/` 目录

### P5：角色创建（按 character.yaml 模板）

- [ ] 主角档案（基本信息 / 性格 / 背景 / 目标 / 能力 / 关系 / 弧线）
- [ ] 重要配角档案
- [ ] 各角色写入 `characters/` 目录

### P6：分纲构建

- [ ] 分纲撰写 → `outline/分纲/卷{卷号}/第{N}章.yaml`
- [ ] 各实体运行 `rebuild_project_index.py` 索引

### P7：章节写作

- [ ] 分纲读取
- [ ] 角色档案读取
- [ ] 章节正文生成
- [ ] 元数据更新（auto_update.py）

### P8：质量检测

> 全章写作完成后自动触发。检测项目同 P1，附加修订调度。

- [ ] 检测项目同 P1（AI 味道 / 情节逻辑 / 角色一致性 / 世界观漏洞）
- [ ] 节奏分析（条件执行）
- [ ] 风格一致性检查（条件执行）
- [ ] 综合质量报告
- [ ] 根据报告调度 novel-writing 修订

### P9：风格提取

- [ ] 用户提供参考文本
- [ ] 7 维度风格分析 → write styles/{名称}.yaml
- [ ] style_manager.py validate → register → activate
- [ ] config.yaml active_style 已设置

### P10：意图澄清

> 用户输入不匹配任何已注册触发词时触发。

- [ ] 询问用户意图
- [ ] 引导到 P1-P9 之一

---

> **说明**：P-1/P-2 由 Agent 通过 skill() 直接执行；P1-P10 创作阶段由 novel-writer.md 按触发词自动识别，Agent 通过 task() 调度对应技能。
> 发布导出为 novel-writing 技能的能力之一，不属于独立创作阶段。
