# 分纲设计指导

在 P7 分纲撰写阶段，为每章输出完整分纲。模板见 `assets/chapter.yaml`。

---

## 1. 分纲核心要素

每章分纲围绕三个层次构建：

| 层次 | 内容 | 对应模板段 |
|------|------|-----------|
| **索引层** | 实体ID、章节号、所属分卷、状态 | `_meta` + `索引信息` |
| **摘要层** | 一句话描述、当前境况、故事时间、核心特质 | `摘要` |
| **内容层** | 场域规划、张力曲线、对话规划、关联情节线 | `内容` |

---

## 2. 场域规划

每章 3-5 个场域，每个场域是一个场景单元。

### 场域结构

| 要素 | 说明 | 示例 |
|------|------|------|
| 场域名 | 场景定位 | "城主府密室对峙" |
| POV 角色 | 谁的眼睛看 | "林渊" |
| 持续时间 | 预期字数 | "约 1500 字" |
| 故事内时间 | 故事世界中的时间 | "午时三刻" |
| 功能 | 叙事目的 | "揭示反派身份的线索" |
| 氛围 | 情感基调+感官锚点+环境要素 | "压抑，阴雨，摇曳的烛光" |
| 节奏控制 | 开场/中场/高潮张力（1-10） | "3→5→7" |
| 进入方式 | 主角如何进入场景 | "推门而入" |
| 退出方式 | 主角如何离开场景 | "被卫兵押走" |
| 涉及角色 | 角色名+状态 | "林渊(愤怒)、陈玄(冷漠)" |

### 场域编排原则

- **节奏交替**：动作场域后接对话场域缓冲，避免连续 2 个高强度场域
- **视角一致**：除非明确切 POV，一个场域只从一个角色视角展开
- **功能清晰**：每个场域至少承担一个叙事功能（推进情节 / 揭示信息 / 塑造角色 / 营造氛围）
- **进出有据**：每个场域有明确的进入和退出方式，不要在场景间跳跃

## 3. 张力曲线

量化本章节奏指标：

```
张力
  ↑
10│
  │
 8│              ● 章节高潮
  │           ↗
 6│    ● 中点转折
  │  ↗
 4│ ● 第一场域高潮
  │↗
 2│● 开场
  │
 1│                                ● 下章悬念
  └─────────────────────────────────────→
  开场  第一场域  中点转折  章节高潮  结尾
```

| 节点 | 典型值 | 说明 |
|------|--------|------|
| 开场 | 2-4 | 承接上章末的状态 |
| 第一场域高潮 | 4-6 | 本章第一次小高潮 |
| 中点转折 | 5-7 | 本章转折点 |
| 章节高潮 | 7-9 | 本章最高张力点 |
| 结尾 | 3-6 | 留有余韵，为下章铺垫 |
| 下章悬念 | — | 一句话描述吊胃口 |

### 不同类型章节的张力模式

| 章节类型 | 张力特点 | 模式 |
|----------|----------|------|
| 开篇章 | 快速引入→小高潮→悬念结尾 | 快速抬升，平缓结束 |
| 过渡章 | 中低张力为主 | 平缓起落 |
| 高潮章 | 持续高张力 | 快速抬升→持续高位→骤降 |
| 收束章 | 高潮后回落 | 高位开场→逐步下降 |
| 埋伏笔章 | 前半平淡，结尾陡升 | 低位→骤然拉升结尾 |

## 4. 对话规划（可选）

仅对话密集的场域使用：

| 要素 | 说明 | 示例 |
|------|------|------|
| 对话节拍 | 回合式对话拆解 | "质问→辩解→揭露真相→沉默" |
| 意图 | 说话者每句的潜台词 | "表面关心，实则试探" |
| 要点 | 本段对话透露的关键信息 | "暗示主角的身份另有隐情" |
| 声线提醒 | 角色→说话风格映射 | "林渊：简洁锋利；陈玄：迂回圆滑" |
| 潜台词提示 | 真实意图与表面话术的差距 | "陈玄说'为你着想'，实际在打探虚实" |

---

## 5. 关联情节线（可选）

直接声明本章归属的情节线实体 ID：

```yaml
关联情节线:
  - "主线-龙渊觉醒"
  - "支线-家族往事"
```

用于全量重建时精确匹配，替代基于角色交集的 fallback 逻辑。

---

## 6. 常见分纲组合

| 组合方案 | 适用场景 | 特点 |
|----------|----------|------|
| **3 场域全规划** | 高潮章/关键章 | 每个场域详细规划，连对话都标注 |
| **2+1 混合** | 普通推进章 | 2 个详细场域 + 1 个概要场域 |
| **张力曲线优先** | 过渡章 | 标注张力点和功能，场域简写 |
| **问题驱动** | 解谜/悬疑章 | 每个场域围绕一个问题设疑→解答 |
