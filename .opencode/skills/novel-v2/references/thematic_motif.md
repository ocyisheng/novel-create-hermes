# thematic_motif — 主题意象方法论

## 定位

主题意象（THEMATIC_MOTIF）焦点类型的方法论文档。追踪反复出现的象征性元素——不是"中心思想"，是像音乐动机一样运作的意象。

## 何时加载

- FOCUS TYPE=thematic_motif 时自动加载

## 结构由脚本保障

content JSON 的字段结构由 `schemas.py` 自动校验：
- 意象（必填）、象征意义（必填）、变奏方式（可选）、出现章节（可选）、相关角色（可选）

你不必记忆字段清单——脚本会提示。

## 创作方法论（需 LLM 判断）

### 动机而非主题

意象通过重复→展开→变奏起作用。检验：
- 意象反复了至少三次吗？（少一次不精简，多一次不丰富）
- 每次出现时情境是否不同？意象的意义是否随之深化？
- 最终亮相是否反过头来点染前文？

### 意象生命周期

| 阶段 | 特征 | 行动 |
|-----|------|------|
| 出现 | 意象第一次亮相，可为无意或背景 | 不要太刻意，让读者不经意间记住 |
| 变奏 | 在不同情境中变化出现，关联不同角色/情绪 | 改变描摹角度——同一意象在不同人眼中不同 |
| 沉淀 | 读者开始对意象建立自己的理解 | 可以沉默几章，让意象在读者脑中发酵 |
| 呼应 | 最终亮相，形成闭合或开放 | 不必解释含义——让意象自己说话 |

### 倒置与反向定位

意象的位置决定其效果：
- **瞻之在前**：开篇即亮出意象，后续逐渐赋予重量
- **忽焉在后**：篇末才暴露意象，反过头来重新点染前文
- **时隐时现**：意象断续出现，读者需要自己发现线索

### 意象 vs 象征

- 意象不必每次都有"象征意义"——有些意象只是意象
- "兴"的诗学——所见在此，所得在彼。意象提供联想的范围，不规定准确的解释
- 意象可以是自然物（风、雨、剑）或人造物（金鹧鸪、手表、照片），甚至可以是颜色、气味、声音

### 跨章节追踪

- 意象不必出现在每一章——间隔出现让读者"发现"它
- 意象的缺席有时比出现更有力（期待落空也是一种变奏）
- 两个意象可以形成对照（剑的锐利 vs 水的柔韧），在暗处对话

### 意象设计自问清单

- 这个意象为什么属于这部小说？换一部小说还能用吗？
- 意象第一次出现时，读者会注意到它吗？
- 意象最后一次出现时，同样一句话是否有了完全不同的分量？
- 意象是服务于"主题思想"还是拥有独立的生命？

## 按作用范围的方法论差异

`子类型` 参数决定意象在小说中的战略定位——不是所有意象都用同一套策略。

### 贯穿性意象

从头到尾反复出现，是小说美学的脊梁。

- 出现频率：不必每章都有——但每次出现应标记一个叙事拐点（开篇、转折、高潮前、收束后）。检验：如果把所有出现点编成一个序列，意象的意义是否在递进？
- 变奏设计：同一个意象需要在不同情境中呈现不同面貌。检验：第一次出现和最后一次出现，同样的描述词是否有了完全不同的重量？
- 贯穿性意象不需要"解释"——如果读者能说出"这个意象象征什么"，它就是死的。如果读者说不出来但被触动了，它活着。

### 局部性意象

只在某一卷或某个角色线内出现，不跨卷。

- 与角色的联帮关系：意象的意义由角色的处境定义，而非反过来。检验：换一个角色看到同样的意象，意象的意义应该不同。
- 收束节奏：局部意象应在该卷/该线完结时最后一次出现——不是"亮相"，是"道别"。检验：这个意象的最后一笔有没有让读者觉得这一卷确实结束了？
- 局部性意象不必担心与贯穿性意象冲突——它们在不同层起作用。贯穿性意象是背景音，局部性意象是独奏。

### 装饰性意象

只出现在一两个场景中，不承担结构功能。但"装饰"不是"随便"——好的装饰性意象是一个独立的审美瞬间。

- 检验：这个意象即便与全文其他意象无关，是否仍有独立的审美能量？
- 装饰性意象的核心风险是"过度包装"——如果它太漂亮但没有任何重量，读者会注意到作者在炫耀。留三隐七。
