# D6 大纲系列 — P4-P7 分阶段检查点

> 不采用单一决策树。每个子阶段独立触发，通过 `skill("novel-grill")` 在主循环中执行。
> 每个检查点不超过 3 个问题，走完即输出注入对应 task() 的 CONTEXT。

## D6.1 — P4 总纲撰写

用于 P4 总纲撰写前置模糊检测。编排层注入 `{故事背景摘要}`（创意方案摘要）。

```
├── 故事结构有偏好吗？（三幕式/起承转合/多线叙事/让 AI 推荐）
├── 核心冲突偏向哪种？（个人 vs 个人/个人 vs 社会/个人 vs 自然/个人 vs 自我）
└── 对结局有预想吗？（HE/BE/开放式/还没想好）
```

## D6.2 — P6 分卷大纲

用于 P6 分卷大纲前置模糊检测。编排层注入 `{总纲概要}`。

```
├── 各卷之间你希望节奏递增还是保持平稳？
├── 有没有哪一卷是你有特别想法的？
├── 当前的分卷数量符合你的预期吗？
└── 每卷大概想写多少字？（可跳过）
```

## D6.3 — P5 情节构建

用于 P5 情节构建前置模糊检测。编排层注入 `{总纲概要}` + `{分卷概要}`。

```
├── 主线比重占总情节的大概比例？（70%/50%/30%）
├── 支线数量偏好？（1-2 条/3-4 条/越多越好）
└── 几条故事线之间的关系？（紧密交织互相影响/各自独立发展/阶段性交汇再分开）
```

## D6.4 — P7 分纲构建

用于 P7 分纲构建前置模糊检测。编排层注入 `{分卷概要}` + `{已有角色列表}`。

```
├── 当前章节总数符合你的预期吗？
├── 有没有特定章节是你想重点描写的？
└── 每一章的字数目标有要求吗？
```

## D6.5 — P4.5 叙事策略

用于 P4.5 叙事策略设计前置模糊检测。编排层注入 `{总纲概要}` + `{创意方案类型}`。

```
├── 你希望用什么视角讲述故事？
│   推荐：第三人称限制（网文主流，兼顾亲密感和灵活性）
│   选项：[第一人称] [第三人称限制] [第三人称全知] [多视角切换]
│
├── 是否需要多视角？
│   推荐：主角视角为主，关键配角视角为辅
│   选项：[单视角] [双视角] [多视角(≤3)] [群像]
│
├── 主要使用什么叙事手法？
│   推荐：顺序叙事（网文主流，读者友好）
│   选项：[顺序] [倒叙] [插叙] [多线并行]
│
├── 如何处理角色背景？
│   推荐：闪回 + 对话透露（避免大段独白）
│   选项：[闪回] [对话透露] [内心独白] [第三方叙述]
│
└── 如何处理读者与角色的信息差？
    推荐：悬疑为主（读者和角色一起发现）
    选项：[悬疑(读者跟随角色)] [戏剧反讽(读者知道更多)] [误导(角色犯错)] [混合]
```
