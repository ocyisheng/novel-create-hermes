# 悬疑推理类型指南

本文档提供完整的悬疑推理类型创作参考。

## 核心元素

```yaml
元素:
  - 推理模式: 逻辑推理/心理分析/证据收集
  - 谜题类型: 身份谜/不在场证明/密室/动机
  - 氛围类型: 心理惊悚/社会派/日常推理
```

## 推理模式详解

### 逻辑推理

| 模式 | 特点 | 代表作 |
|------|------|--------|
| 演绎推理 | 从一般到特殊的逻辑推导 | 福尔摩斯 |
| 归纳推理 | 从特殊到一般的归纳总结 | 名侦探柯南 |
| 类比推理 | 通过相似案例寻找线索 | 金田一 |

### 心理分析

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| 行为分析 | 通过行为推断心理 | 嫌疑人画像 |
| 微表情分析 | 通过表情说谎 | 审讯场景 |
| 记忆重构 | 还原案发过程 | 记忆模糊 |

### 证据收集

| 类型 | 说明 |
|------|------|
| 物证 | 指纹、DNA、凶器 |
| 书证 | 日记、信件、文档 |
| 证人证言 | 目击者陈述 |
| 监控视频 | 影像证据 |

## 谜题类型

### 经典谜题

| 类型 | 描述 | 难度 |
|------|------|------|
| 密室杀人 | 不可能犯罪的经典 | 高 |
| 不在场证明 | 时间悖论类 | 中 |
| 身份之谜 | 真实身份隐藏 | 中 |
| 宝藏谜题 | 寻找隐藏宝藏 | 低 |
| 密码解密 | 密码/暗号破解 | 中 |

### 现代谜题

| 类型 | 描述 |
|------|------|
| 网络犯罪 | 黑客/数据追踪 |
| 心理操控 | 暗示/催眠 |
| 意外事故伪装 | 他杀伪装成意外 |
| 完美犯罪 | 高智商犯罪 |

## 推理结构

### 基本结构

```
开始 → 立案 → 调查 → 推理 → 验证 → 解决
```

### 经典结构（起承转合）

```
起：事件发生，发现谜团
承：初步调查，收集线索
转：推理受挫，出现新线索
合：真相大白，揭示真凶
```

### 多视角结构

```
视角1：侦探调查
视角2：嫌疑人行动
视角3：受害者经历
视角N：旁观者观察
```

## 常见情节模式

### 社会派推理

```yaml
特点:
  - 案件背后是社会问题
  - 犯罪者有令人同情的理由
  - 推理服务于社会批判
  - 探讨制度性不公

主题:
  - 校园暴力
  - 职场不公
  - 家庭矛盾
  - 社会歧视
```

### 心理悬疑

```yaml
特点:
  - 重点是心理而非案件
  - 主角有心理创伤
  - 记忆不可靠
  - 现实和幻觉混淆

元素:
  - 精神分析
  - 催眠术
  - 双重人格
  - 记忆移植
```

### 日常推理

```yaml
特点:
  - 没有凶杀案
  - 解决日常生活中的谜团
  - 推理过程比结果重要
  - 温情向，治愈系

场景:
  - 找东西
  - 消失的物品
  - 奇怪的声响
  - 人的去向
```

## 角色模板

### 侦探类型

| 类型 | 特点 | 适合风格 |
|------|------|---------|
| 名侦探 | 天才头脑，超强推理 | 传统硬核 |
| 日常侦探 | 普通人，细致观察 | 温情日常 |
| 心理侦探 | 洞察人心，分析动机 | 心理悬疑 |
| 技术侦探 | 依赖证据，科技辅助 | 现代都市 |

### 嫌疑人类型

| 类型 | 特点 |
|------|------|
| 明知真相 | 故意隐瞒 |
| 记忆缺失 | 自己也不记得 |
| 被嫁祸 | 无辜卷入 |
| 共犯 | 知道但不全是 |

### 受害者类型

| 类型 | 特点 |
|------|------|
| 死者已逝 | 需要通过线索还原 |
| 受害者存活 | 第一视角叙述 |
| 象征性受害者 | 代表某种社会问题 |

## 诡计设计

### 叙述性诡计

```yaml
类型:
  - 视角欺骗: 利用读者视角预设
  - 时间欺骗: 时间线错位
  - 身份欺骗: 读者不知道的真实身份
  - 记忆欺骗: 角色的记忆出错

要点:
  - 必须合理
  - 有伏笔
  - 二刷能发现
```

### 物理诡计

```yaml
类型:
  - 密室: 物理上不可能进入
  - 不在场证明: 时间 manipulation
  - 凶器消失: 证据处理
  - 身份替换: 伪装/假死

要点:
  - 必须可行
  - 有线索
  - 不过于复杂
```

### 心理诡计

```yaml
类型:
  - 误导: 故意引导错误方向
  - 伪证: 假的证据
  - 心理盲区: 大家都忽略的点
  - 共识偏见: 都被误导的集体错觉

要点:
  - 符合心理
  - 有暗示
  - 不牵强
```

## 创作建议

### 布局技巧

- **伏笔**：提前暗示，结尾回收
- **误导**：合理引导，但不过分
- **反转**：出人意料，但合乎逻辑
- **高潮**：推理的关键突破

### 节奏控制

- **开篇**：制造悬念，吸引读者
- **铺垫**：收集线索，铺陈事实
- **高潮**：推理突破，真相大白
- **收尾**：余韵悠长，发人深省

### 质量检查

- [ ] 推理逻辑是否严密？
- [ ] 线索是否公平？
- [ ] 诡计是否可行？
- [ ] 动机是否合理？
- [ ] 结局是否出人意料又在情理之中？
