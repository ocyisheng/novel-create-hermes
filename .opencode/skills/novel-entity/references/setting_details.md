## 势力格局设计

### 势力数量控制

| 推荐数量 | 原因 |
|----------|------|
| 3个 | 基础三角关系 |
| 4个 | 两两对立+中立 |
| 5个 | 复杂博弈 |

### 势力关系类型

| 关系 | 说明 |
|------|------|
| 对立 | 正邪对抗 |
| 合作 | 联盟关系 |
| 中立 | 隔岸观火 |
| 依存 | 互相依赖 |
| 竞争 | 利益冲突 |

### 势力构成要素

## 地理版图设计

### 地理要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 主要区域 | 势力范围 | 九州 |
| 中心地点 | 重要城市 | 青云城 |
| 险地秘域 | 危险区域 | 万魔渊 |
| 交通要道 | 连接通道 | 传送阵 |

### 地图设计原则

1. **层次分明**：核心区→外围→险地
2. **功能明确**：每个区域有独特设定
3. **服务剧情**：地理服务于情节需要

## 历史沿革设计

### 时间线设计

| 时代 | 特征 | 关键事件 |
|------|------|----------|
| 上古 | 盛世/繁荣 | 万仙大战 |
| 近古 | 变化/衰退 | 灵气衰退 |
| 现代 | 当前/危机 | 主线事件 |

### 历史事件设计原则

1. **影响深远**：改变世界格局
2. **与角色相关**：影响主角命运
3. **伏笔回收**：前文铺垫的后文揭示

## 规则闭环检查

### 常见漏洞

| 漏洞 | 解决方案 |
|------|----------|
| 力量膨胀 | 设置上限/代价 |
| 无限制能力 | 增加限制条件 |
| 物资无限 | 稀缺设计 |
| 时间线矛盾 | 仔细校验 |

### 闭环检查清单

- [ ] 境界提升有明确条件？
- [ ] 力量使用有代价？
- [ ] 资源是否稀缺？
- [ ] 时间线是否一致？
- [ ] 势力关系是否合理？
- [ ] 地理设定是否矛盾？
