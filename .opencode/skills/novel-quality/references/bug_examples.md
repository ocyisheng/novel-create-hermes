# 世界观漏洞示例

## 输出格式

### 漏洞检测报告（YAML）
```yaml
漏洞检测报告:
  检测时间: 2026-05-05 10:00
  检测范围: "第5-8章"
  发现问题数: 3

  问题列表:
    - 问题ID: BUG_001
      问题: "[问题描述]"
      位置: "[出现位置]"
      维度: "[规则/物理/势力/时间线/文化]"
      严重程度: "[致命/重要/轻微]"
      建议: "[修复方案]"
```

### 单问题报告格式
```
问题：[问题描述]
位置：[出现位置/涉及设定]
维度：[规则/物理/势力/时间线/文化]
严重程度：[致命/重要/轻微]
建议：[修复方案]
```

---

## 问题示例

### 示例1：规则一致性

```yaml
- 问题ID: BUG_001
  问题: "灵气消耗规则前后不一致"
  位置: "第5章第3节 vs 第7章第1节"
  维度: "规则一致性"
  严重程度: "致命"
  建议: "统一灵气消耗计算公式，建议设定为每提升一层需要消耗当前总量10%"
```

### 示例2：物理法则

```yaml
- 问题ID: BUG_002
  问题: "重力规则矛盾，仙山设定为轻如羽毛但主角御剑飞行却需要庞大灵气"
  位置: "worldbuilding/修炼体系.yaml"
  维度: "物理法则"
  严重程度: "重要"
  建议: "修正重力设定，或调整灵气消耗逻辑"
```

### 示例3：势力逻辑

```yaml
- 问题ID: BUG_003
  问题: "北域势力范围标注矛盾"
  位置: "worldbuilding/地图.yaml"
  维度: "势力逻辑"
  严重程度: "重要"
  建议: "修正势力范围标注，保持与基本信息.yaml一致"
```

### 示例4：时间线

```yaml
- 问题ID: BUG_004
  问题: "历史事件时间冲突，千年前的大战与王朝建立时间矛盾"
  位置: "outline/时间线.yaml"
  维度: "时间线"
  严重程度: "致命"
  建议: "统一时间线，调整大战发生时间或王朝建立时间"
```

### 示例5：文化自洽

```yaml
- 问题ID: BUG_005
  问题: "祭祀习俗前后描述不统一"
  位置: "第6章 vs 第8章"
  维度: "文化自洽"
  严重程度: "轻微"
  建议: "统一为'春祭'季节"
```
