# 焦点类型：world_rule — 世界观建设指南

## 适用任务

建设世界观设定：力量体系、势力格局、地理、历史、文化等。

## 方法论选择

根据小说类型预设方法论，但允许创作者自由选用：

| 路径 | 适用场景 | 方式 |
|------|---------|------|
| **体系化建置** | 玄幻、西幻、科幻 | 按10个模板输出完整体系 |
| **笔记传统** | 现实主义、文艺向 | 散点随笔组织，一点切入、神韵全出 |
| **混合方案** | 多数长篇 | 宏观架构体系化 + 微观细节笔记传统 |

## 10种子类型/文件

世界观可按以下维度独立创建，每维度一个文件（不强求一次全部完成）：

| 文件 | 核心字段 |
|------|---------|
| 基本信息 | 世界名称、类型、时间背景、空间背景、核心设定 |
| 核心规则 | 物理法则、魔法/科技体系、禁忌与限制、因果规律、特殊机制 |
| 力量体系 | 体系名称、等级划分、晋升条件、力量来源 |
| 势力格局 | 势力列表（名称/性质/核心目标）、势力平衡、隐藏势力、冲突焦点 |
| 地理位置 | 版图总览、主要区域、交通要道、危险区域、资源分布 |
| 历史 | 纪元划分、重大事件、传说与秘辛、历史遗留问题 |
| 文化 | 种族/民族、宗教与信仰、社会结构、风俗习惯、语言与文字 |
| 经济体系 | 货币体系、经济结构、贸易网络、资源分配、经济矛盾 |
| 政治制度 | 政权结构、治理模式、政治势力、外交关系、政治冲突 |
| 社会阶层 | 阶层划分、流动机制、社会矛盾、文化认同 |

## 自洽性标准

- 判断标准：**"在这个世界里它是否自洽"**替代"在现实中它是否可能"
- 区分"开放区的矛盾"（刻意保留的未知/洪荒状态）与"粗心的矛盾"（失误）
- 在核心规则中声明哪些区域是"开放区"

## 延迟创建原则

- 核心设定（力量体系、基本规则）建议早些完成
- 扩展设定（经济体系、政治制度）可以在实际需要时再创建
- 写作第3章时才意识到需要地理设定 → 第3章时再补
